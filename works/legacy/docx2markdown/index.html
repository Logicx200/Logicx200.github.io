LEGACY · 早期项目 / DOCUMENT TOOL

DOCX 转 Markdown 转换器

原程序是 Tkinter 桌面工具，用 mammoth 把 Word 文档转成 Markdown。网页版把整条链路搬进了浏览器：原生 DecompressionStream 解开 .docx 的 ZIP 包，DOMParser 解析 word/document.xml，再按 WordprocessingML 语义生成 Markdown。文件不离开本机，无需安装任何东西。

与原 Python 版的差异

  • 原程序用 mammoth + Tkinter；网页版不依赖任何库，ZIP/XML/转换全部自己实现。
  • 图片选项：原程序「忽略图片 / 尝试 base64」，网页版真正实现了 Base64 内嵌与图片另存（原版 mammoth 受限时只能忽略）。
  • 不支持的 Word 特性：浮动图片与文本框、脚注/尾注、域代码、修订标记（删除内容跳过、插入内容保留）、SmartArt、图表、公式（OMML）、嵌入对象。
  • 合并单元格会退化为空单元格或重复列；复杂表格的对齐与列宽不保留。
  • 需要浏览器支持 DecompressionStream（Chrome/Edge 103+、Firefox 113+、Safari 16.4+）；.doc（旧二进制格式）无法处理。
  • 超过约 50 MB 的文档、或使用 ZIP64 / 非 deflate 压缩的文档可能失败，会在日志中说明原因。
