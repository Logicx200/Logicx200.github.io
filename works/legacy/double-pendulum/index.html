模型与移植说明

运动方程与源码逐项一致（θ 为相对竖直向下的摆角，δ = θ₂ − θ₁）：
θ̈₁ = [ m₂L₁θ̇₁²sinδcosδ + m₂g sinθ₂cosδ + m₂L₂θ̇₂²sinδ − (m₁+m₂)g sinθ₁ ] / [ (m₁+m₂)L₁ − m₂L₁cos²δ ]
θ̈₂ = [ −m₂L₂θ̇₂²sinδcosδ + (m₁+m₂)( g sinθ₁cosδ − L₁θ̇₁²sinδ − g sinθ₂ ) ] / [ (L₂/L₁)·((m₁+m₂)L₁ − m₂L₁cos²δ) ]
位置换算同样取自源码：x₁ = L₁sinθ₁，y₁ = −L₁cosθ₁，x₂ = x₁ + L₂sinθ₂，y₂ = y₁ − L₂cosθ₂。

网页版新增：① 可选的速度阻尼项 −γθ̇（原版为无阻尼理想模型，默认 γ = 0 与源码等价）；② 大角度宽散布初值模式；③ 颜色按 matplotlib plasma 色带映射初始偏移量大小，与源码一致。
