根据 F:\Project\电磁阻尼.py 里的原始 Python 程序移植，原作 2025-10（代码最后修订 2025-11）。 原版是 Tkinter 参数面板 + Matplotlib 求解并导出 GIF 的桌面程序，默认参数与三条 Rext 工况与源码一致；网页版把数值积分、动画与曲线都搬进浏览器实时完成，ODE 与磁通耦合项逐项照搬，未做模型简化。

模型与移植说明（ODE、磁通耦合项、与原版的差异）

源码中的状态方程（y 为磁铁偏离线圈中心的位移，i 为线圈电流，z_coil 为线圈中心位置）：

y' = v v' = ( -k·y + N·i·dΦ/dz(y − z_coil) ) / m i' = ( -R_tot·i − N·dΦ/dz(y − z_coil)·v ) / L R_tot = R_coil + R_ext, R_ext = 5 Ω / 0.5 Ω / ∞（断路，i ≡ 0） dΦ/dz(z) = −3·μ0·m_dip·a²·z / [ 2·(a² + z²)^(5/2) ], μ0 = 4e-7·π

能量记账与源码一致：机械能 = ½mv² + ½ky²，磁能 = ½Li²，焦耳热 = ∫i²R_tot dt（梯形积分），总能量 ≈ 常数。感应电动势按源码动画中的定义计算：EMF = −N·(dΦ/dz)·v。

与原版差异：① 原版用 Matplotlib 逐帧导出 GIF，网页版用 requestAnimationFrame 实时播放，可在任意时刻暂停/重播、切换显示工况；② 原版一次跑完 5 Ω、0.5 Ω、断路三种工况后只对其中一个出动画，网页版三条曲线同时叠加显示（可关闭）；③ 原版“快速模式”会减小步长上限换取速度，网页版固定 h = 5×10⁻⁵ s 的 RK4（已与 h = 2×10⁻⁶ s 的参考解核对，末态能量偏差 < 0.01%）；④ 等效阻尼比 ζ 与包络拟合是网页版为读图方便新增的量，原版没有。
