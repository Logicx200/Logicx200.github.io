根据 F:\Project\Tracker on Opencv.py 里的原始 Python 程序移植，原作 2025-12。 原版是命令行菜单 + OpenCV 窗口的桌面程序（加载视频 → 标定坐标系 → 选择标志物 → 光流跟踪 → 显示结果 → 保存结果 → 阻尼分析）；网页版把这些步骤改成页面按钮，并用内置合成动画作为无视频时的演示数据。

移植说明（算法对照、简化与差异）

原版跟踪核心是 cv2.calcOpticalFlowPyrLK（15×15 窗口、2 层金字塔）；浏览器没有内置光流，网页版改为在上一帧位置附近的搜索窗内做归一化互相关（NCC）模板匹配，并对相关峰做抛物线亚像素修正——它同样逐帧给每个标志物一个位置，NCC 峰值直接作为置信度。原版置信度是「与上一位置的像素距离换算」的启发式，网页版用真实的匹配得分，因此在图上更直接可读。

原版的阻尼分析对竖直位移 y−y₀ 直接拟合 A·e^(−b·t)+y₀（scipy curve_fit）。网页版保留这个「原版直接拟合」，另外提供更稳定的「包络拟合」：取 |位移| 的局部极值做 ln(A)=ln(A₀)−b·t 线性拟合，对欠阻尼振动能给出更可靠的 b；两种结果都会显示 b、A₀、y₀ 与 R²。

简化：标定坐标系改为「点两点 + 输入实际距离」的页面交互；原版的逐帧重新标记（R 键 + A/D 切帧）简化为「回到首帧重新点选后重新跟踪」；保存结果改为导出 CSV（浏览器不能直接写本地文件，用下载代替）。内置演示动画为 640×480、600 帧、30 fps 的合成弹簧振子，真实阻尼系数 b=0.10 s⁻¹，可在面板里直接验证拟合结果。
