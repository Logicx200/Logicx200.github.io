它在算什么？

拉瓦尔喷管先把气流加速到超音速。如果喷管出口压力高于环境压力（欠膨胀），射流离开喷口后会继续膨胀，并被环境压力挤回，形成交替的膨胀扇与斜激波——沿轴线看就是一串钻石形的“马赫环”。真实流动里这些密度突变会让尾焰明暗交替，伪纹影正是把密度梯度画成黑白画面来复现这种观感。

数值方法（与原程序相同）

求解无量纲二维欧拉方程：

∂U/∂t + ∂F/∂x + ∂G/∂y = 0
U = [ρ, ρu, ρv, E]ᵀ
  • 有限体积 + HLLE 近似黎曼通量（Einfeldt 1988）
  • 显式时间推进，按 CFL 条件逐帧自适应 Δt
  • 边界：入口超音速入流、出口/上下无反射透射、喷管内滑移壁
  • 上下与右侧加海绵层（sponge）吸收反射波
  • 伪纹影：log10(|∇ρ|)，按 5%–99.5% 分位归一化
  • 马赫环：中心线伪纹影局部极大值 + 最小间距筛选

网页版与原 Python 版的差异

  • 计算量：原程序 720 × 240、CFL 0.55；网页版默认 240 × 72、CFL 0.8，用降网格 + 更快时间步换取浏览器里的即时反馈，激波更“厚”、细节更少。
  • 工作流：原程序先算完 2400 帧（约 5–15 分钟）再播放；网页版边算边显示进度，算完约 240 帧（每 0.5 个物理时间单位采样一次）自动回放，播放约 30 fps。
  • 原程序输出 mach_ring.mp4；网页版用 Canvas 2D 逐帧绘制，可切换伪纹影 / 密度场，可暂停、拖进度、调速度。伪纹影的归一化与源码一致（log10(|∇ρ|) + 5%–99.5% 分位），仅在显示时加了轻微 S 曲线对比度增强以便观察。
  • 参数面板沿用源码里的默认值（P_JET=3.0、T_JET=2.0、M_JET=2.4、γ=1.4、Lx=160、Ly=20 等）。
  • 局限：网格较粗时马赫环自动检测可能漏掉弱激波；数值解并非工程级 CFD，仅用于教学与可视化。
