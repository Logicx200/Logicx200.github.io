实现说明与限制

与原 Python 版的对应关系

  • 原程序是「读 .md → 找 Base64 图片 → 上传 SM.MS → 替换链接」；网页版保留了这个模式，并新增更常用的反向功能「图片 → Base64 Markdown」（原程序没有）。
  • Base64 正则、清洗、校验与「自动修复」逻辑照搬原程序：去掉空白字符、去掉 data: 前缀、用 atob 校验。
  • SM.MS 上传：POST https://sm.ms/api/v2/upload，Header Authorization: Token，multipart 字段 smfile，失败自动重试 3 次，与原程序一致。
  • 原程序的「备份原文件 / 覆盖原文件 / 同目录另存」在浏览器里改为：下载替换后的 .md，以及下载原文件备份。

限制与注意

  • SM.MS API 的 CORS 策略可能拒绝来自 file:// / 静态页面的直连请求；被拦截时页面会明确报错，此时请使用本地 Base64 模式或官方客户端。
  • 本地模式不压缩图片；Base64 体积约为原图的 4/3，大图会让 Markdown 变得很大，可在其它工具里先压缩尺寸。
  • 不支持 SVG 之外的矢量格式内嵌预览；EMF/WMF 等 Word 矢量图片在浏览器中无法显示。
  • 「下载 .md」使用浏览器下载，文件名基于当前日期生成。
