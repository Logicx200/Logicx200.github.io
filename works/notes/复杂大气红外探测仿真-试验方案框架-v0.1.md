## 零、定方案之前，先看清两件事

### 0.1 官方软件是什么、不是什么

[COSSIM（复杂光学场景仿真软件）](http://www.xggdkj.com/index.php/product_show/cid/170/nid/3.html) 是**场景 + 成像级**仿真工具，官方定位对标 SE-WORKBENCH-IR：

- 可见光/红外**场景要素建模、构建仿真、分析仿真、想定规划**；
- 模型库覆盖大气特性、目标特性、材质处理、设备特性、气动效应；
- 能按波段重新计算光谱响应度、透过率等设备效应，实时生成**带辐射定量值**的红外图像；
- 面向光电制导武器性能评估、光电对抗半实物/全数字仿真、光电探测系统总体设计。

| 强项（用它） | 边界（别指望它） |
|---|---|
| 高保真场景/材质/目标/大气要素建模 | 脚本化、批量工况扫描能力弱（GUI 想定式操作） |
| 图像级辐射定量、波段配置、设备效应 | MRTD / P_d / DRI / 作用距离等性能指标不是现成输出 |
| 想定演示、对比图，评委看得见 | 不确定度量化、敏感性分析、优化闭环基本没有 |
| 工程文件可交付、可复现 | 大气模型的内部细节与可导出量不透明（需实测） |

**结论**：COSSIM 适合当"高保真锚点"，不适合当"批量统计工具"。这不是它的缺陷，而是联合仿真分工的依据。

补充（2026 年半年报口径，[来源](http://stock.stockstar.com/notice/SN2026082500045465.shtml)）：COSSIM 全国产化，分基础版/专业版/扩展版；具备 AI 场景建模、"实测数据反演 → 智能建模推演 → 可见光/红外图像生成"闭环，以及面向半实物仿真的高动态红外场景生成能力。**若拿到的版本支持导入实测数据/图像序列，"实测—仿真"闭环对比会是很强的加分项**，值得优先确认。

### 0.2 竞赛规则是硬约束

依据[大赛通知](https://www.csoe.org.cn/detail/2199.html)（中国光学工程学会首届"芯光杯"，2026-10-08 发布）：

| 提交物 | 工程文件包 + 案例仿真报告 + 汇报 PPT | 试验方案要按"能产出这三样"来设计，不是按论文设计 |

## 一、总体策略：锚点保真 + 机理外推

三层结构：

1. **COSSIM 锚点层（少而精，3–5 个工况）**：建场景、出图像、给高保真辐射/图像证据；
2. **Python 机理层（多而快，几十个工况）**：大气传输 + 传感器模型 + 指标模型，批量算；
3. **对标层**：在锚点上比较 Python 与 COSSIM 的中间量（τ、图像对比度、SNR）和最终指标；偏差可接受 → 外推可信；不可接受 → 修模型或缩小适用范围。

**映射竞赛四环节：**

| 竞赛环节 | COSSIM 负责 | Python 负责 |
|---|---|---|
| 场景化光电系统建模 | 场景/目标/材质/大气/设备建模、想定 | 参数表管理、批量配置生成、参数敏感性 |
| 仿真计算 | 锚点工况成像（图像级辐射定量） | 批量工况 τ、路径辐射、SNR、MRTD、P_d 计算 |
| 性能评估 | 图像指标（对比度、SNR、可分辨性） | MRTD/P_d/R_max/DRI、置信区间、误差预算 |
| 方案优化 | 优化后方案的成像验证（收尾锚点） | 代理模型 + 多目标优化、帕累托前沿 |

**为什么这样设计**：保真度与覆盖度不可兼得。评委既看"软件用得好"（15% + 资格线），又看"案例有创新价值"（40%）——锚点保真 + 批量外推两头都占，而且是能讲清楚的方法论，不是拼凑。

## 二、指标：把"分辨能力"变成可计算、可判定的量

| 层级 | 指标 | 含义 | 用途 |
|---|---|---|---|
| L1 任务级 | 探测/识别概率 P_d(R)、P_rec(R)；最大作用距离 R_max；DRI 距离 | 给定任务判据下"能看多远" | 最终结论、答辩主图 |
| L2 传感器等效级 | MRTD(f)、MDTD、SNR、对比度传递函数 | 传感器"分辨温差/空间频率"的能力 | 跨系统比较、COSSIM 校验量 |
| L3 链路支撑级 | τ(λ)、路径辐射 L_path(λ)、视在对比度 ΔL、NETD、MTF 分量 | 误差分解与诊断 | 解释"为什么是这个距离" |

**几条可落地的公式关系（自写模型时用，完整推导见配套调研底稿）**：

- 尺度链：N = Dₜ/(R·θ)，θ = p/f（p 像元间距，f 焦距）；
- Johnson/DRI：N₅₀ ≈ 2.0 / 8.0 / 12.5 cycles（探测/识别/辨认，50%）；部分文献用 1.5/6/12，差异来自目标集与观察者实验——**引用前必须绑定来源（STANAG 4347 或 Johnson 原文）**，且只适用于人眼、线性外推；
- 概率模型（TTPF）：P_d = (N/N₅₀)^E / [1+(N/N₅₀)^E]，E≈1.5–2.7 需标定；R₅₀ 令 N=N₅₀ 反解；
- TTP 链：TTP = ∫√(CTF_sys/CTF_eye)df；N = TTP·√Aₜ/R；R = TTP·√Aₜ/V₅₀；
- MTF 链：MTF_sys = MTF_opt·MTF_det·MTF_elec·MTF_disp·MTF_atm·MTF_turb·MTF_aerosol·MTF_jitter；
- 湍流 MTF（长曝光）：exp[−3.44(λf/r₀)^(5/3)]，r₀ = 0.185·λ^(6/5)·(Cn²L)^(−3/5)；
- MRTD 近似：MRTD(f) = k·NETD/MTF(f)（k 与人眼/显示模型有关，需标定）；
- 作用距离：由"V 达到任务阈值"反解 R，或由 P_d(R) 曲线取阈值概率对应的距离。

> 建议双轨：任务级主指标（P_d 或 DRI 距离）+ 物理级副指标（MRTD/SNR）。

- DRI 必须绑定**目标临界尺寸 + 判据**（Johnson 周期数，或 TTP 值→P_d），不能只报"识别距离 xxx m"。
- MRTD 用标准 4-bar 条靶，与具体目标脱钩，适合跨系统比较，也最可能和 COSSIM 图像对上。
- 若加"算法检测"视角（CNN/匹配滤波/自适应阈值），报告 ROC/AUC 与 P_d(R)，作为创新点而非唯一结论。
- 判据提前写死：目标等效尺寸、观察者模型或算法、P_d 阈值（如 50%/90%）、置信水平。

## 三、工况空间：分层设计，并明确"谁跑"

### 3.0 先把"环境"参数化（比按环境名列因子更科学）

"不同环境对应的主要是参数不同"这个判断是对的。环境名称不是正交的：都叫"乡村"的场景，能见度可以从 5 km 到 30 km，湿度、气溶胶成分也不同。按名称设因子，主效应和交互会混在一起；而参数化之后：①可以做方差分解（Morris/Sobol）和代理模型，②参数可标定、可溯源，③同一套模型能外推到没枚举过的环境。

**大气状态向量（建议）：a = (MOR / β₅₅₀, α, w, Cn²)**

| 参数 | 物理作用 | 影响指标 | 典型范围 | 来源 |
|---|---|---|---|---|
| MOR / β₅₅₀ | 550 nm 消光，控制整体透过率 | 对比度、P_d、R_max | 0.5–23 km | Koschmieder；气象观测 |
| α（Ångström 指数） | 消光光谱斜率 β(λ)=β₅₅₀(550/λ)^α | MWIR/LWIR 相对性能、波段选择 | 雾≈0；霾 1.0–1.5；沙尘 0.2–0.5；雨≈0 | 气溶胶文献/OPAC |
| w（可降水量） | 水汽连续吸收与窗区边缘 | LWIR 透过率、远距离 | 0.5–5 cm | 探空/再分析 |
| Cn² | 湍流折射率结构常数 | 分辨率/MTF、边缘模糊 | 1e−16 ~ 1e−13 m^(−2/3) | 边界层观测 |
| （可选）g / ω | 气溶胶前向散射/单次反照率 | 气溶胶 MTF、veiling 光 | 雾 0.8–0.9；霾 0.6–0.75 | OPAC/Mie 计算 |
| （结构）云、几何、太阳 | 不能化成能见度 | 遮挡/背景/昼夜差异 | — | — |

> 一句话：能见度只回答"总衰减多少"，不回答"哪个波段吃亏、图像糊不糊、背景电平多高"。所以至少还要 α（光谱形状）与 Cn²（分辨率）；LWIR 再加 w。

**环境名 → 参数向量映射（典型值，引用前需核实）**：

| 环境 | MOR (km) | α | 备注 |
|---|---|---|---|
| 晴空乡村 | 15–30 | 1.2–1.5 | 基准工况 |
| 城市霾 | 5–15 | 1.3–1.6 | 吸光气溶胶多，ω 偏低 |
| 海洋 | 10–25 | 0.5–1.0 | 海盐大粒子，g 高 |
| 沙尘 | 2–10 | 0.2–0.5 | 大粒子、前向散射强 |
| 平流雾 | 0.2–1 | 0–0.2 | 灰消光，ω≈1 |
| 雨（1–25 mm/h） | 5–20（等效） | ≈0 | 灰消光；湿地面背景会变 |
| 雪 | 1–5（等效） | ≈0 | 大粒子 + 遮蔽 |

这就是"环境名只是参数空间里的一个典型点"：**讲故事用环境名，做实验用参数向量**。一个直接例子：α=1.3 的霾在 4 μm 的消光是 10 μm 的 (10/4)^1.3 ≈ 3.3 倍——同样的能见度，MWIR 比 LWIR 吃亏得多；雾（α≈0）则两波段接近。这正是 α 必须单列为参数的原因。

### 3.3 三周可行的收敛版：6 个连续因子（距离作评估轴）

上面的 18 项是"完整清单"，三周做不完；按 3.0 参数化后收敛为 6 个连续因子（d=6）：

| 因子 | 水平 | 说明 |
|---|---|---|
| A 能见度 MOR | 20 / 10 / 5 / 2 / 0.5 km | 对应 β₅₅₀，控制总衰减 |
| B 光谱斜率 α | 0 / 0.5 / 1.0 / 1.3 / 1.6 | 雾≈0、沙尘≈0.2–0.5、霾/乡村≈1.3–1.5；决定 MWIR/LWIR 谁吃亏 |
| C 水汽柱 w | 0.5 / 1.5 / 3 / 5 cm | 主要影响 LWIR 窗口边缘与水汽连续吸收 |
| D 湍流 Cn² | 1e−16 / 1e−14 / 1e−13 | 与路径长度合成 r₀，控制 MTF/分辨率 |
| E 目标温差 ΔT | 3 / 6 / 10 / 20 K | 与 τ 一起决定视在对比度 |
| F 波段 | MWIR / LWIR | 与 α、w 强交互 |

- 距离 R（2/4/6/8 km）**不作因子**，而是评估轴：算 P_d(R)、R₅₀；
- 目标类型固定一个主目标（如 2.3 m 坦克），人员/车辆作鲁棒性抽查；
- 环境名称（乡村/城市/沙尘/雾）只用于选 COSSIM 锚点和讲故事，**不作因子**。

**计算量与流程（三段式）**：

1. Morris 筛选：r(d+1) ≈ 70 次，先看每个因子的主效应强弱；
2. LHS 300 点 + 高斯过程（GP）代理模型（经验 10d，200–500 点即可）；
3. Sobol 分解：N(2d+2)，取 N=1024 → 约 1.4 万次**代理模型**调用（秒级，可承受）；
4. COSSIM 锚点：从上面工况里挑 3–5 个（基准 + 中等 + 极端），做高保真成像与对标。

> 这样"样本量爆炸"和"三周时间"的矛盾就解了：COSSIM 负责少而精的锚点，Python 代理模型负责大规模统计。

### 3.4 参数相图（热力图/等值线图）——把工况空间画出来

不枚举天气，而是用二维切片把"大气参数 → 结果"画成场，天气区域作标注叠加。本质是响应面/设计图（nomogram），很适合汇报与论证。

**图集设计（建议 3 张主图）**：

| 图 | 横轴 | 纵轴 | 颜色（主结果） | 等值线/标注 | 用途 |
|---|---|---|---|---|---|
| A 大气衰减相图 | MOR（对数） | α | 波段透过率 τ（固定 R）或等效红外能见度 V_IR | 天气区域：雾/霾/沙尘/雨/晴空 | 证明"同一能见度、不同天气，红外表现不同" |
| B 系统能力相图 | MOR（对数） | 距离 R | P_d（固定 ΔT、波段） | P_d=0.5 等值线即 R₅₀ 曲线；COSSIM 锚点 | 最终一句话结论的可视化 |
| C 分辨能力相图 | Cn²（对数） | 距离 R | MTF 限制下的可分辨周期数 N / 可分辨尺寸 | N=N₅₀ 等值线 | 说明"探测≠分辨" |

- 波段（MWIR/LWIR）、ΔT（3/6/10 K）作为**面板维度**，不要塞进同一张图；
- 颜色只承载**一个**明确定义的量；第二指标用等值线叠加，避免"颜色含义混乱"。

**三条实现要点**：

1. 不做全网格计算：LHS 200–300 点 + GP 代理 → 渲染 100×100 平滑场；置信区间大的区域用点纹/阴影标出。
2. 锚点叠加：COSSIM 3–5 个工况以标记点画在图上，旁边标"仿真 vs COSSIM 偏差 x%"——一张图同时完成覆盖展示与验证，评委最买账。

## 四、仿真链路与接口

```
[COSSIM 泳道]  场景建模 → 想定配置 → 锚点成像 → 图像(辐射定量) → 图像指标
                    │            │                                    │
                    ▼            ▼                                    ▼
[COSSIM 参数层] 大气/设备参数  波段/响应度/透过率        图像层接口：元数据 + 16bit 图像
                    │                                                  │
                    ▼                                                  ▼
[Python 泳道]   大气传输(τ, L_path) → 传感器模型(NETD/MTF/噪声) → 指标模型(MRTD/P_d/R_max)
```

**两条接口（方案的关键设计）：**

1. **图像层接口（主接口）**：COSSIM 输出 16-bit 辐射图像 + JSON 元数据（波段、积分时间、增益、距离、能见度、温度、目标真值）→ Python 计算 ΔL、SNR、MTF、对比度 → 反推指标。
2. **参数层接口（辅接口）**：COSSIM 的大气/设备参数表 ↔ Python 大气传输与传感器模型；COSSIM 内部大气简化的地方，用 Python 精算模型补。

**离散化与数据规范**：图像统一 16-bit；光谱按波段积分或 0.05 μm 网格；采样因子 Q=2λF#/p ≥ 2；所有工况参数落一张 CSV/JSON 总表（可追溯）。

**Python 侧工具链（已核查，2026-10）**：

| 环节 | 首选 | 备选/注意 |
|---|---|---|
| 大气传输 | **libRadtran**（GPL，2.0.6，uvspec 命令行 + Python subprocess 封装，含热发射与自定义 Mie 气溶胶表） | ARTS（GPL，被动红外，曲线陡）；LBLRTM+hapi（逐线最准但慢，hapi 需 API key 且有每日限额） |
| 大气模型商用件 | — | MODTRAN 闭源商业（教育版约 $3000 起 + 年维护，禁嵌入再分发），只宜做少量终检；Py6S/6S **无热发射项，算不了 MWIR/LWIR**；PyRTlib 面向微波，不适合红外 |
| 气溶胶 Mie | miepython（MIT，活跃） | PyMieScatt（停更但可用）；气溶胶谱分布可用 OPAC |
| 目标热模型 | scipy `solve_ivp` + 一维有限差分（集总参数/热平衡） | 无成熟通用库，自写并用解析平板解验证 |
| 传感器/指标 | 自写 MRTD/TTP/P_d 模型 | pyradi（ryplanck/ry3dnoise/rystare 等 NVESD 组件，适合交叉对照；老代码、无 PyPI 包）；NVESD 模型无公开源码 |
| 发射率数据 | ASTER / ECOSTRESS 光谱库、USGS v7 | 多为**半球反射率**，用 Kirchhoff 关系 ε=1−ρ 换算；8–14 μm 覆盖有限 |
| 湍流 | 自写 Cn² 相位屏 / 湍流 MTF 模块 | 湍流不在任何辐射传输软件内，必须单独建模 |

**能见度换算（易错）**：Koschmieder 关系 V=3.912/β(550 nm)；跨波段用 β(λ)=β₅₅₀(550/λ)^α（雾 α≈0，霾 α≈1–1.5）。**能见度只定义在 550 nm，直接拿 V 算 10 μm 消光会错**。

## 五、验证与不确定度（V&V + UQ）

### 5.1 三层验证

| 层级 | 做法 | 通过标准（示例，待定） |
|---|---|---|
| V1 代码验证 | 黑体/均匀背景极限、Beer–Lambert 单层路径、能量守恒、数值收敛（光谱/空间加密后稳定） | 极限情形相对误差 <1% |
| V2 交叉验证 | ① 两套实现互比（简化带模型 vs 精算）② 与公开文献数据比 | 中间量偏差 <10% |
| V3 锚点对标 | COSSIM 锚点工况：比 τ/图像对比度/SNR 与最终指标 | 最终指标偏差 <15%（需给依据） |

> V&V 与不确定度表述可引 NASA-STD-7009B、AIAA G-077、GUM；判据建议：与官方软件比 MRTD/TTP/R₅₀ 偏差 ≤15%，且差距落入 U(k=2) 区间。第二实现可参考 Kitware pyBSM（MTF 链/噪声/GIQE，需核实版本与许可证）做交叉校验。

### 5.2 对标设计（资格线 + 加分点）

> 叙事反过来写：**COSSIM 结果是基准，Python 增强实现是被校验对象**。既满足"依托指定软件"，又把交叉对比做成加分项。

- 选点：A + 1–2 个 B 中等 + 1 个 D 极端，覆盖正常/退化/失效；
- 比什么：三层都比（τ 谱与积分、图像对比度/SNR、最终 MRTD/P_d/距离）；只比最后一位数字说明不了问题；
- 怎么报：偏差百分比 + 误差棒 + 原因（模型差异/参数假设/离散化）。

### 5.3 不确定度与敏感性

- 输入不确定度：温度 ±2 K、发射率 ±0.05、水汽 ±20%、能见度 ±10% 等；
- 传播：蒙特卡洛/拉丁超立方 → 输出 95% 置信区间；
- 敏感性：Sobol 主指数+总指数（先用 Morris 筛选），找出主导因子；
- 误差预算：δτ/τ → δSNR → δR_max，量化"哪个输入最值得精化"。

## 八、常见坑（评审高概率追问）

1. 只报"识别距离"，不报概率和判据 → 不可复现。
2. 工况参数无来源、水平随意 → 可信度打折。
3. 大气模型波段用错（如 6S 只到 4 μm，算不了 LWIR）。
4. 目标当黑体、背景当均匀 → 对比度失真。
5. 没有误差分析，结论给成"精确值"。
6. 官方软件只对最终数字、只对 1 个点 → 更像凑数。
7. 只讲模型先进，不讲适用边界。
8. 工程文件包不完整、参数对不上报告 → 资格线风险。
9. 能见度（550 nm 定义）直接用于 10 μm 波段 → 消光系数错。
10. ASTER/USGS 光谱库给的是反射率，忘了 Kirchhoff 换算；Blender 的 RGB 图像不等于辐射亮度，别直接当 MWIR/LWIR 数据用。
11. 湍流只算 MTF 不算相位屏 → 图像级仿真里纹理/闪烁不真实。
12. N₅₀、E、GIQE 系数等"通行业经验值"版本混用且不标来源 → 复现失败、被追问。
13. 忽略 NUC/固定图案噪声/非均匀性；验证点专挑好工况 → 不可信。
