# 复杂大气环境红外目标探测仿真：性能评价、验证与试验设计（调研底稿）

## 0. 一句话结论

评价链应为：**大气辐射传输（MODTRAN）→ 传感器 MTF/噪声/MTF 链 → MRTD 与 TTP → N（周期数）→ TTPF 得 P_d → R50**。
仿真可信度靠 **三级校验（解析极限 / 官方软件交叉 / 文献或外场实测）+ 误差预算 + U(k=2) 区间** 支撑；试验设计用 **Morris 筛选 → LHS+GP → Sobol** 的三段式，计算量可控在万级代理调用。

## 1. 探测/识别性能指标

### 1.1 尺度链（所有判据的公共基础）

目标在焦平面上占的周期数：

```
N = D_t / (R · θ_IFOV)，  θ_IFOV = p / f   （rad）
```

- `D_t`：目标临界尺寸（常用 √A_t，A_t 为迎光面积，m）
- `R`：作用距离（m）；`p`：探测器像元间距（m）；`f`：焦距（m）
- 若用 mrad：θ_IFOV[mrad] = 1000·p/f；R 用 km 时 N = D_t/(R·θ_IFOV) 需统一单位

【待核】该式是几何投影近似，忽略斜视投影、大气抖动与运动模糊；工程上常乘 cos(视角) 修正。

### 1.2 Johnson / DRI 判据

- 原始思想（Johnson 1958）：以“目标临界尺寸上可分辨的线对数（cycles on target）”判定任务等级。
- 通行 50% 概率阈值：**探测 2.0、识别 8.0、辨认 12.5 cycles**（部分文献用 1.5/6/12，差异来自目标集与 observer 实验条件）。【待核：具体数值以 NATO STANAG 4347 或 Johnson 原文为准】
- 适用条件：人眼观察、目标对比度高于阈值、目标至少覆盖若干像元、线性外推；**对高分辨率/现代成像系统与自动检测算法偏差大**（这是评委常抓的点，需在报告中主动声明并给出 TTP 对照）。

### 1.3 MRTD / MDTD

- **MRTD(f)**：标准 4 条靶，观察者“刚好能分辨”所需的最小温差（K），是 f 的函数；由 NETD、MTF、噪声、显示器与人眼共同决定。
- **MDTD**：圆形（非周期）靶“刚好能发现”的最小温差，用于探测而非分辨。
- 用途：实验室标定传感器；与目标-背景 ΔT 联立反解 `f_max`，再折算 N 与距离。
- 【待核】MRTD 的实验室测量受观察者主观性影响大，报告须给出测量条件（靶尺寸、帧频、显示亮度、观察者人数）。

### 1.4 MTF 链

```
MTF_sys(f) = MTF_opt · MTF_det · MTF_elec · MTF_disp · MTF_atm · MTF_turb · MTF_aerosol · MTF_jitter
```

- 光学：衍射限 `MTF_opt = (2/π)[arccos(ν) − ν√(1−ν²)]`，ν = f/f_c，f_c = 1/(λF#)。
- 探测器：像元积分 `sinc(π f p)`；离散采样另有 aliasing，需在仿真中显式建模。
- 电路/显示：RC 低通、显示像素 sinc。
- 抖动：`exp[−2π²σ_j²f²]`。

**大气湍流 MTF（长曝光）**【已核验：与 Fried 1966 的理论形式一致，常数由 r0 定义推出】

```
MTF_turb(f) = exp[ −57.4 · f^(5/3) · Cn² · L · λ^(−1/3) ]
```

- 单位：f [cycles/m]，Cn² [m^(−2/3)]，L [m]，λ [m]；换成 cycles/mrad 时 f→f/1000，常数同比缩放。
- 等价形式：`exp[ −3.44 (λ f / r0)^(5/3) ]`
- Fried 参数：`r0 = 0.185 · λ^(6/5) · (Cn² L)^(−3/5)`；视宁度 FWHM ≈ λ/r0。
- 短曝光需另加斑点传递函数（speckle transfer function），长曝光场景可只用上式。

**气溶胶 MTF**【不确定：解析式版本多，建议调库而非自写】

- 物理：多次前向散射把高频信息“搬移”到低频，形成低频平台 + 高频快速滚降。
- 关键参数：散射系数 σ_s、吸收系数 σ_a、截止频率 `f_c ≈ a/λ`（a 为粒子半径尺度）。
- 工程做法：低频近似 `MTF_a ≈ exp(−σ_s·L)` 作为对比度平台，`f > f_c` 后按 `exp[−(f/f_c)²]` 型滚降；**具体系数请以 Kopeika 模型原文或 MODTRAN 气溶胶透过率 + 实测 MTF 拟合为准**。
- 参考：Kopeika, *A System Engineering Approach to Imaging*, SPIE Press, 1998（CIS/RIT 课程讲义可检索到）。

### 1.5 TTP / NVThermIP

```
TTP = ∫_{f_low}^{f_cut} sqrt( CTF_sys(f) / CTF_eye(f) ) df      [cycles/mrad]
N   = TTP · sqrt(A_t) / R
R   = TTP · sqrt(A_t) / V50
```

- `CTF_sys`：系统对比度传递函数（含 MTF、噪声、显示器）；`CTF_eye`：人眼对比度阈值函数。
- 优点：显式含噪声与人眼，适用于高分辨率、欠采样系统；NVThermIP 用 `V50`（50% 概率所需周期数）替代 Johnson 的固定 N50。
- 【已核验】函数形式见中文综述与 NVThermIP 文献；【不确定】积分上下限、CTF 归一化系数各实现不同，跨软件比较前须统一。
- 开源实现参考：Kitware **pyBSM**（含 MTF 链、噪声、GIQE/NIIRS），可作交叉校验的“第二实现”。

### 1.6 NIIRS / GIQE

- NIIRS 为 0–9（军用 1–9）序数尺度，按目标可解读性分级；不是任务概率。
- GIQE 一般形式【已核验：RIT 讲义给出通式；系数随版本变化】：

```
NIIRS = c0 + c1·log10(GSD) + c2·log10(RER) + c3·H + c4·G + c5·SNR
```

- GSD 为地面采样距离，RER 为相对边缘响应，H/G 为调制传递函数补偿项。
- 版本：GIQE 4.0 / 5.0 的系数不同，公开版见 NGA GIQE-5 文档（Kitware pyBSM 仓库 docs 内附）。
- 【不确定】具体系数与适用传感器类型强相关，报告须注明版本。

### 1.7 P_d 与作用距离

**目标传递概率函数（TTPF）**【已核验：FOI 报告式(8)给出该形式】

```
P_d = (N/N50)^E / [ 1 + (N/N50)^E ]  ≡  1 / [ 1 + (N50/N)^E ]
```

- `E` 为经验指数，控制曲线陡峭度；NVESD 系列模型中随任务/数据集标定（常见 1.5–2.7 区间）。【不确定：具体取值须引所用模型手册】
- `R50`：令 N = N50 反解；`R_d` 给定 P_d 目标反解。
- 经典距离估算（NVESD/ACQUIRE 思路）：由 MRTD 或 N50 + 大气透过率 + 目标 ΔT 迭代求最大可分辨频率，再换算距离。
- 注意：P_d 是**任务概率**，须与“探测/识别/辨认”定义严格对应；不同文献的 N50 定义不一致是复现失败的主因之一。

## 2. 复杂大气环境的影响机理与可量化参数

### 2.1 消光与能见度

```
Beer–Lambert:  τ(R) = exp(−β·R)
Koschmieder:   V = 3.912 / β(0.55 μm)      【已核验：3.912 为通行常数】
Ångström:      β(λ) = β(0.55) · (λ/0.55)^(−α)
```

- `V` 即气象光学视程 MOR（km）；β 单位 km⁻¹。
- α 典型值：霾 ≈1.3（0.5–1.6）；雾 ≈0（大粒子，中性消光）；雨 ≈0–0.5；沙尘偏大。【待核：α 随气溶胶模态变化，报告应给出取值依据】
- 红外波段必须用 MODTRAN/Mie 计算，不能直接套可见光 MOR。

### 2.2 路径辐射与对比度衰减

```
L_app = L_t·τ + L_path
C = (L_t − L_b)·τ / (L_b·τ + L_path)
```

- 路径辐射 `L_path` 随距离与气温/湿度上升，是**远距离对比度反转（目标比背景暗）**的根源。
- 结论：只用 τ 衰减会高估性能；必须同时给 `L_path`。

### 2.3 湍流

- Cn² 典型：10⁻¹⁷（弱）～10⁻¹³（强）m^(−2/3)；近地面白天可达 10⁻¹³。
- 派生量：r0、视宁度 ε≈λ/r0、greenwood 频率（自适应光学用）。
- 对成像：长曝光模糊 + 短曝光畸变/闪烁；对探测：能量扩散降低峰值 SNR。

### 2.4 雨、雪、水汽

- 雨：大粒子 Mie 散射，消光近似与雨强线性（≈0.3–0.5 dB/km per mm/h，随波长变）；【不确定：系数随雨滴谱/波长变化大】
- 雪：强散射 + 目标遮蔽，等效对比度骤降；
- 水汽：8–12 μm 边缘吸收，PWV（可降水量）与湿度廓线决定 LWIR 透过率；MWIR 受影响小但受高温背景辐射影响大。

### 2.5 波段选择

- MWIR（3–5 μm）：受太阳反射与高温目标辐射共同作用，雾/霾透过率相对好；
- LWIR（8–12 μm）：常温目标辐射强，但水汽吸收与路径辐射大；
- 方案中应把“波段”作为因子而非固定假设。

## 3. 仿真可信度与验证范式（V&V）

### 3.1 术语与标准

- **Verification**：代码/数值是否实现方程（单元测试、网格/收敛、解析解对比）。
- **Validation**：模型是否表征真实世界（与实验/观测比）。
- **Credibility**：面向具体决策的置信度（NASA-STD-7009 系列）。
- 可引标准：
  - NASA-STD-7009B（2024）Models and Simulations 标准【已核验链接】
  - AIAA G-077-1998 V&V Guide【已核验 DOI】
  - ASME V&V 20（流体/传热不确定度）【待核】
  - DoD Instruction 5000.61（M&S VV&A）【待核】
  - JCGM 100:2008（GUM）不确定度表示【待核链接】

### 3.2 三级校验（建议写入报告）

| 层级 | 对象 | 方法 | 通过判据 |
|---|---|---|---|
| L1 解析 | 单模块 | Beer-Lambert、Koschmieder、黑体/普朗克、sinc MTF | 相对误差 <1% |
| L2 交叉 | 整链 | 官方软件（MODTRAN/NVThermIP/DIRSIG 等）同工况 | 关键量偏差 ≤10–15% |
| L3 实证 | 结论 | 文献外场数据、公开试验数据集 | 落在 U(k=2) 区间内 |

### 3.3 误差预算（四层）

1. **输入**：大气廓线、能见度、Cn²、目标 ΔT/发射率、背景温度；
2. **模型**：MTF 近似、线性叠加假设、TTPF 指数、气溶胶 MTF 形式；
3. **数值**：采样/混叠、卷积核截断、蒙特卡洛收敛；
4. **统计**：样本量、代理模型误差、外推风险。

合成：`u_c = sqrt(Σ u_i²)`，报告 `U = k·u_c (k=2)`；对系统性偏差单列“bias”而非并入 u。

### 3.4 评委/审稿人常见质疑与应答

| 质疑 | 应答策略 |
|---|---|
| 循环验证（只跟自己比） | L1 解析 + L2 官方软件 + L3 文献三级 |
| 无不确定度 | 每个结论给 U(k=2)，给样本量与置信水平 |
| 大气参数“拍脑袋” | 引 MODTRAN 标准廓线/实测气象，给范围与来源 |
| Johnson 外推高分辨率 | 同时给 Johnson 与 TTP 两套结果，说明差异 |
| N50 与目标不匹配 | 明确任务定义（探/识/辨）与目标临界尺寸 |
| 忽略 NUC/坏元/噪声 | MTF 链 + 噪声等效温差 + 非均匀性建模 |
| 验证点挑“好工况” | 角点+中心+最恶劣工况，预注册验证点 |
| 指标定义不一致 | 统一 N、P_d、R50 的定义与单位表 |

## 4. 试验设计（DOE）与敏感性分析

### 4.1 方法选择

| 目的 | 方法 | 成本 | 备注 |
|---|---|---|---|
| 因子筛选 | Morris 筛选（一次一因子轨迹） | r(d+1)，r≈10 | 先降维，识别主导因子 |
| 空间填充 | 拉丁超立方 LHS | 200–500 | 优于正交表的投影性质 |
| 代理模型 | GP/Kriging、PCE | 与 LHS 共用样本 | 给预测方差，便于自适应加点 |
| 全局敏感性 | Sobol 指数（Saltelli 估计） | N(2d+2) | 需大 N，宜在代理模型上跑 |
| 不确定传播 | MC / PCE | 10³–10⁴ | 与 SA 共用样本 |

### 4.2 样本量经验

- GP 的“10d 经验法则”：d 个因子至少 10d 个点；d=6 → 60 起，实际建议 200–500 以稳定相关矩阵。
- Sobol（Saltelli 方案）：总调用 = N(2d+2)；d=6、N=1024 → 14336 次，**在 GP 代理上毫秒级**，可直接承受。
- Morris：r(d+1)，r=10、d=6 → 70 次全仿真，用于首轮筛选。
- 若单次成像仿真分钟级：全仿真总量控制在 300–500 次（LHS）+ 70 次（Morris）+ 10 次（验证）。

### 4.3 计算成本权衡

- MODTRAN 单次秒级 → 大气表可预计算成网格（R、MOR、PWV、波段）插值；
- 成像仿真（卷积+噪声）分钟级 → 代理模型 + 自适应加点；
- 结论：**“少量高保真 + 大量代理”**是公开研究中主流做法。

## 5. 可直接落地的试验方案骨架

### 5.1 因子与水平（6 因子，混合水平）

| 因子 | 水平 | 说明 |
|---|---|---|
| A 天气/能见度 MOR | 20 / 10 / 5 / 2 / 0.5 km（晴/霾/雨/雪/雾） | 用 MODTRAN 生成对应廓线 |
| B 湍流 Cn² | 1e−16 / 1e−14 / 1e−13 | 弱/中/强，对应 r0 |
| C 距离 R | 2 / 4 / 6 / 8 km | 覆盖 R50 两侧 |
| D 目标 | 坦克 2.3 m@ΔT3K / 车辆 4 m@ΔT6K / 人员 0.5 m@ΔT5K | 临界尺寸取 √A_t |
| E 波段 | MWIR 3–5 / LWIR 8–12 μm | 固定 F#、像元、NETD 便于对比 |
| F 气溶胶 | 乡村 / 城市 / 海洋 / 沙尘 | MODTRAN 气溶胶模型 |

固定条件：传感器参数（F#、像元、焦距、NETD、帧频）、观察者模型、目标发射率。

### 5.2 指标（响应变量）

`MRTD(f)`、`MTF_sys(f)`、`TTP`、`N`、`P_d`、`R50`、`NIIRS`；另记 `SNR`、`τ`、`L_path` 作为中间量便于归因。

### 5.3 设计与运行量

1. **筛选**：Morris，r=10 → 70 次；
2. **主试验**：LHS 300 点（含 6 个角点、2 个中心点）；
3. **代理**：GP/Kriging，留一交叉验证 R² ≥0.95、RMSE ≤5%；
4. **敏感性**：Sobol，N=1024 → 14336 次代理调用；
5. **验证**：10 个点（6 角点 + 2 中心 + 2 文献工况），与官方软件逐一对比。

### 5.4 验证点与判据

- 每波段 4 点：晴/霾/雨/强湍流各 1；
- 对比量：MRTD、TTP、R50；
- 判据：相对偏差 ≤15%，且官方软件结果落在仿真 U(k=2) 区间内；
- 记录：输入表、版本号、随机种子、运行日志（可复现）。

### 5.5 结论表述模板

> 在 MOR = 5 km、Cn² = 1×10⁻¹⁴ m^(−2/3)、LWIR 8–12 μm、R = 4 km 条件下，对 2.3 m×2.3 m 坦克目标（ΔT = 3 K），仿真给出识别概率 P_d = 0.78 ± 0.06（k=2），对应 R50 = 5.2 km；与官方软件同工况结果偏差 9%，通过 L2 校验。
