## 一、实验思路

### 1.1 要回答的三个问题

1. **单点能力**：在给定大气状态与目标下，该传感器在距离 R 处的探测/识别概率是多少？R₅₀（P_d = 50% 对应距离）是多少？
2. **参数规律**：大气参数（能见度、光谱斜率、水汽、湍流）各自把能力拉低多少？哪个是主导因子？相互之间有没有非线性叠加？
3. **可信度**：以上结论在多大程度上可信？与官方软件 COSSIM 的偏差多大？不确定度区间多宽？

### 1.2 基本假设与边界

- 水平均匀大气、局地热平衡；不考虑多次散射以外的复杂辐射过程（正式模型由辐射传输软件处理）；
- 目标与背景均为漫发射体（发射率光谱按库取值，镜面反射只作敏感性说明）；
- 传感器线性响应、噪声以 NETD 表征（正式版补 3D 噪声：光子/读出/1/f/固定图案）；
- 主要结论限定在：水平路径、上述目标/传感器、上述参数范围内；斜程与云作为扩展工况，不作主结论。

### 1.3 总体技术路线（四层）

```
[环境参数层]   MOR, α, w, Cn² + 目标 ΔT/尺度 + 传感器参数 + 几何
        │
        ▼
[前向仿真层]   大气传输 τ(λ), L_path(λ)  →  目标/背景视在辐射  →  传感器 MTF/噪声  →  信号或图像
        │
        ▼
[指标层]       τ_band, ΔT_app, SNR, MRTD(f), N, TTP  →  P_d(R), R50
        │
        ▼
[可信度层]     解析极限校验 → COSSIM 锚点对标 → 不确定度传播 → 敏感性分析
```

### 1.4 三阶段实验安排

| 阶段 | 内容 | 工况数 | 目的 |
|---|---|---|---|
| I 基准闭环 | 基准工况 A0，打通 Python 全链路；做解析极限校验（τ=1、均匀背景、黑体目标） | 1 | 证明链路正确，产出第一条曲线 |
| II 参数扫描 | 单因子 B、组合/极端 C、LHS 扫描（代理模型） | 17 + 6 + 300 | 出规律、出相图、做敏感性 |
| III 锚点对标 | 5 个 COSSIM 锚点，比三层量 | 5 | 证明可信度，形成最终结论 |

> 顺序不能颠倒：阶段 I 没通过解析校验，阶段 II 的扫描结果无法解释。

### 1.5 官方软件与 Python 的分工（要写进报告的分工表）

| 环节 | COSSIM | Python |
|---|---|---|
| 场景化建模 | 目标/背景/材质/大气要素建模与想定 | 参数表管理、批量配置生成 |
| 仿真计算 | **锚点工况高保真成像**（图像级辐射定量） | 批量工况 τ、路径辐射、SNR、指标计算 |
| 性能评估 | 图像对比度/SNR/可分辨性（若可导出） | MRTD、P_d、R₅₀、置信区间 |

### 1.6 创新点定位

**"图像域仿真 → 量化指标 → 参数相图 → 方案优化"闭环**：把 COSSIM 的图像级仿真接到可计算的性能评估链路上，输出"在什么大气条件下、多远、多大把握发现目标"的量化结论。多数队伍停在渲染图像，本方案落在可验证的能力数字上。

## 二、环境定义参数

### 2.1 参数化原则

不枚举"雾/霾/雨"等天气类型，而是用**连续物理参数**描述大气状态：

$$a = (\mathrm{MOR},\ \alpha,\ w,\ Cn^2)$$

理由：环境名称不正交（同名"乡村"能见度可从 5 km 到 30 km）；连续参数可标定、可做方差分解（Morris/Sobol）、可外推到未枚举环境。**环境名称只作为参数空间中的典型点**，用于挑选 COSSIM 锚点和报告叙述。

### 2.2 大气参数定义

| 符号 | 定义 | 单位 | 范围 | 默认值 | 数据来源 | COSSIM 对应项【待核实】 |
|---|---|---|---|---|---|---|
| MOR | 气象光学视程（550 nm 能见度） | km | 0.5–30 | 23 | 气象观测/标准大气 | 能见度/大气模式 |
| α | Ångström 消光指数，β(λ)=β₅₅₀(550/λ)^α | — | 0–2 | 1.3 | 气溶胶模型/OPAC/文献 | 气溶胶类型（需换算） |
| w | 可降水量（水汽柱） | cm | 0.5–5 | 1.5 | 探空/再分析 | 湿度/水汽设置 |
| Cn² | 折射率结构常数 | m^(−2/3) | 1e−16–1e−13 | 1e−14 | 边界层观测/经验模型 | 湍流参数（若无则用 Python 补） |
| g / ω | 气溶胶不对称因子 / 单次反照率（可选） | — | 0.5–0.9 / 0.5–1 | 按类型 | OPAC/Mie 计算 | 气溶胶模型隐含 |
| T_air | 近地面气温（影响路径辐射） | K | 280–310 | 300 | 气象 | 温度设置 |
| 路径类型 | 水平/斜程；天顶角 | ° | 0–60 | 水平 | 任务设定 | 几何设置 |

辅助关系：

- $\beta_{550} = 3.912/\mathrm{MOR}$（km⁻¹）；
- $\beta(\lambda) = \beta_{550}\,(0.55/\lambda)^{\alpha}$（λ 单位 μm）；
- 湍流：$r_0 = 0.185\,\lambda^{6/5}(Cn^2 L)^{-3/5}$，长曝光 MTF $= \exp[-3.44(\lambda f/r_0)^{5/3}]$。

### 2.3 环境类型 → 参数映射（典型值，引用前须核实来源）

| 环境 | MOR (km) | α | 附加参数 | 备注 |
|---|---|---|---|---|
| 晴空乡村 | 15–30 | 1.2–1.5 | w 1–2 cm，Cn² 1e−15～1e−14 | 基准 |
| 城市霾 | 5–15 | 1.3–1.6 | ω 偏低（吸光） | MWIR 相对吃亏 |
| 海洋 | 10–25 | 0.5–1.0 | g 高（海盐） | — |
| 沙尘 | 2–10 | 0.2–0.5 | g 高、粒子大 | 前向散射强 |
| 平流雾 | 0.2–1 | 0–0.2 | ω≈1、液水含量高 | 灰消光，两个波段都吃亏 |
| 雨 | 5–20（等效） | ≈0 | 雨强 1–25 mm/h，湿地面背景变化 | 灰消光+背景变化 |
| 雪 | 1–5（等效） | ≈0 | 大粒子+遮蔽 | 场景级处理 |

> 示例：MOR=5 km 时，α=1.3 的霾在 10 μm 的消光约为 4 μm 的 (10/4)^1.3 ≈ 3.3 倍；α≈0 的雾则两个波段接近。因此 α 必须单列，否则"能见度一样、红外表现不同"无法解释。

### 2.4 目标与背景参数

| 参数 | 说明 | 取值 | 来源 |
|---|---|---|---|
| Dₜ | 目标临界尺寸（√迎光面积） | 坦克 2.3 m；车 4 m；人 0.5 m | 文献/假定【待确认】 |
| ΔT | 目标与背景表观温差 | 3 / 6 / 10 / 20 K | 实测/文献【待确认】 |
| ε(λ) | 目标表面光谱发射率 | 按 ASTER/ECOSTRESS 库，注意 ε=1−ρ | 光谱库 |
| 背景类型 | 草地/沙地/沥青/水面/植被 | 草地（主） | 光谱库 |
| T_bg | 背景温度 | 与气温关联，280–310 K | 气象 |

### 2.5 几何与平台参数

- 距离 R = 1–10 km（评估轴）；
- 路径：水平为主；斜程（俯角 0°/15°/30°）作为扩展；
- 太阳几何：夜间/白天（MWIR 反射分量作敏感性）；
- 平台高度：地面/车载（主）；机载作为扩展。

### 2.6 不能参数化的结构条件及处理

| 条件 | 为什么不能化成标量 | 处理方式 |
|---|---|---|
| 云（遮挡/背景） | 取决于云底高、光学厚度、云温与几何 | 作为场景开关，只在锚点/扩展工况出现，不进主 DOE |
| 降雨背景变化 | 湿地面温度/发射率变化、雨幕时间起伏 | 用"等效 MOR + α≈0"表示消光；背景变化单列敏感性 |
| 昼夜/太阳 | 反射分量与阴影，非大气状态量 | 作为锚点场景条件 |
| 非均匀路径 | 廓线/距离不均匀 | 主结论限定水平均匀；斜程用等效路径近似 |

### 2.8 参数化依据：为什么是这四个参数（评审必问）

先明确：**没有一篇文献规定"必须用 MOR、α、w、Cn² 这四个参数"**。这四个参数是工程降维：把大气对红外探测的影响拆成三个物理通道，每个通道选可标定的参数。文献支撑的是"每个参数本身"和"这种参数化方式"，不是"恰好四个"这个数字。

| 物理通道 | 影响什么 | 选定参数 | 文献依据 | 替代掉的原始描述 |
|---|---|---|---|---|
| 光谱消光 | τ(λ) → 对比度、SNR | MOR（β₅₅₀）+ α | Koschmieder 1924；Ångström 1929；Eck 1999；OPAC（Hess 1998） | 气溶胶类型/粒径谱下拉框（离散模型连续化） |
| 热发射（含吸收） | L_path≈(1−τ)B(T)、低对比目标可用性 | w（水汽柱）+ T_air | HITRAN2020；MT_CKD（Mlawer 2012）；LOWTRAN/MODTRAN 水汽输入 | 温湿廓线（水平均匀路径下取等效值） |
| 湍流 | MTF → 分辨率、识别 | Cn²（配路径长度 L） | Fried 1966；ITU-R P.1817；Kopeika 1998 | 风速/温度梯度/边界层廓线（等效 Cn²） |

**组合方式的文献依据**：LOWTRAN/MODTRAN、6S 等标准大气辐射传输软件在工程上就是用"能见度（或消光）+ 气溶胶模型 + 湿度/水汽 + 温压廓线"描述大气（[48][49][6][22]）；OPAC/AERONET 用"气溶胶类型 + 湿度"或"AOD + α"（[5][16][17]）；湍流用 Cn²（[9][27]）。本方案只是把其中**离散的气溶胶模型按 Ångström 幂律连续化为 α**（[3][4]），于是得到"四参数"状态向量——**是标准参数化的连续化改造，不是另起一套**。

**推荐写入报告的表述**：

> 采用 LOWTRAN/MODTRAN 的能见度—气溶胶—湿度参数化体系，其中气溶胶类型按 Ångström 幂律连续化为光谱指数 α；水汽以可降水量表示；湍流按 Fried 的 Cn² 参数化。该四参数状态向量是上述标准参数化的连续化降维，适用于水平均匀、局地热平衡、Kolmogorov 湍流假设下的红外成像探测性能评估。

**必须同时声明的三个限制**：

1. **独立性**：现实中 MOR、α、w、Cn² 由同一套天气条件驱动、彼此相关（雾 = 低能见度 + 高湿 + 弱湍流）。把四者当独立因子做 DOE 是"设计空间"选择，不是统计独立性主张；敏感性结论只能限定在该设计空间内解释。
2. **不完备**：(MOR, α) 不能区分气溶胶前向散射 g 与吸收 ω。当评价指标涉及**图像级 MTF 或路径辐射绝对量**时，需要第 5 个参数（g 或 ω），或改用显式微物理模型（Mie + 谱分布）；"水平均匀"假设也忽略了温度廓线与斜程。本方案把这些作为"结构条件/锚点工况"处理，并在报告中写明适用边界。
3. **天气 ≠ 参数点**：雾/霾/雨是微物理类别，映射到参数向量是多对一的（同一组参数可能对应不同天气）；环境名称只用于选 COSSIM 锚点与叙述，不参与统计推断。

**按需要扩展**：

| 需求 | 扩展方式 |
|---|---|
| 只关心对比度 | β(λ) 足够，MOR + α 即可 |
| 关心图像级 MTF / 路径辐射 | 加 g 或 ω，或改用 Mie 微物理模型 |
| 关心斜程 / 昼夜 MWIR | 加温度廓线/气溶胶标高、太阳几何 |
| 垂直非均匀大气 | 四参数失效，直接上辐射传输软件（libRadtran/MODTRAN） |

### 2.9 最小完备组合：完备性是相对指标定义的

**结论先行**：不存在脱离评价指标的"最小完备参数集"。建议用两层表述，答辩时先讲假设、再讲参数。

**效果层（最小充分统计量，每波段 3 个量）**

| 量 | 作用 | 来源 |
|---|---|---|
| τ_band（或 β_band） | 对比度衰减 | 辐射传输/参数化 |
| L_path_band（或等效路径温度 T_eff） | 路径辐射、背景电平、绝对辐射 | 辐射传输 |
| MTF_atm（r0 或 Cn²L，含散射项） | 分辨率退化 | Fried/气溶胶 MTF 模型 |

给定制冷/非制冷传感器与目标-背景对比度，这 3 个量足以算 P_d(R)、R₅₀；任何辐射传输软件都能输出。

**驱动层（跨天气外推的最小参数集，4–6 个，取决于假设）**

| 假设程度 | 必需参数 | 说明 |
|---|---|---|
| 差分成像 + 同距离背景 + 热红外（最低要求） | **MOR、α、w、Cn²**（4 个） | τ(λ) 的消光水平（MOR）、谱形（α）、水汽吸收细结构（w），加湍流（Cn²） |
| 绝对辐射定标 / 异距离背景 / 白天 MWIR | + **T_air（或 T_eff）**（5 个） | 路径热发射电平和背景辐射 |
| 图像级 MTF / veiling 光（雾、沙尘等强散射） | + **g 或 ω**（6 个） | 前向散射与吸收比例，决定散射模糊与路径辐射 |
| 云、垂直非均匀、昼夜太阳散射 | 上述失效 | 上廓线/云参数/太阳几何，直接进辐射传输软件 |

**当前四参数集的准确定位**：在"热红外、水平均匀、同距离背景、差分成像"假设下，它是**最小完备的驱动集**；一旦涉及绝对辐射、异距离背景或图像级散射，就缺 T_air 与 g/ω。报告里必须写明这个前提，而不是笼统说"四个参数描述了大气"。

**完备性的实证判定**（比引文献更有说服力）：
1. 在 LHS 设计空间内做 Morris 筛选 + Sobol 分解；
2. 若某参数的总指数 S_Ti < 0.05（或加入它后 P_d/R₅₀ 的方差变化 <5%），判为冗余；
3. 保留参数的 S_Ti 均 ≥ 阈值，则该集合在声明范围内"完备"；
4. 报告写明"最小完备集由敏感性检验得到"，并给出阈值与检验范围。

> 这样回答"为什么是四个参数"就有两层依据：物理通道（消光/发射/湍流）保证不遗漏一阶效应，敏感性检验保证不引入冗余参数。

## 三、效果检验参数

### 3.1 指标体系

| 层级 | 指标 | 含义 | 用途 |
|---|---|---|---|
| L1 任务级 | P_d(R)、P_rec(R)、R₅₀、R₉₀、DRI 距离 | 给定判据下"能看多远、多大把握" | 最终结论、答辩主图 |
| L2 传感器级 | MRTD(f)、MDTD、SNR、MTF_sys、CTF | 传感器自身分辨温差/频率的能力 | 跨系统比较、COSSIM 对标 |
| L3 链路级 | τ(λ)、L_path(λ)、τ_band、V_IR、ΔT_app、N、TTP、r₀ | 误差分解与诊断 | 解释"为什么是这个距离" |

### 3.2 定义与计算公式

**大气与信号：**

- 波段透过率：$\tau_{band} = \dfrac{\int \tau(\lambda) W(\lambda)\,d\lambda}{\int W(\lambda)\,d\lambda}$，W 取目标-背景温差对应的 Planck 导数权重；
- 等效红外能见度（自定义量，需在报告中注明定义）：$V_{IR} = 3.912/\beta_{band}$；
- 视在温差（简化）：$\Delta T_{app} = \tau_{band}\,\Delta T$；严格式由辐射亮度差 $\Delta L = \tau(L_t-L_b)+\Delta L_{path}$ 给出；
- 信噪比：$SNR = \Delta T_{app}/NETD$（正式版用 3D 噪声模型）。

**传感器与分辨率：**

- MTF 链：$MTF_{sys} = MTF_{opt}MTF_{det}MTF_{elec}MTF_{disp}MTF_{atm}MTF_{turb}MTF_{aerosol}MTF_{jitter}$；
- 湍流（长曝光）：$MTF_{turb}(f)=\exp[-3.44(\lambda f/r_0)^{5/3}]$；
- 目标周期数：$N = D_t/(R\,\theta)$，$\theta = p/f$（可加湍流有效 IFOV 修正）；
- MRTD 近似：$MRTD(f)=k\cdot NETD/MTF_{sys}(f)$（k 需标定）；
- TTP：$TTP=\int\sqrt{CTF_{sys}/CTF_{eye}}\,df$，$N_{TTP}=TTP\sqrt{A_t}/R$。

**概率与距离：**

- 目标传递概率：$P_d = (N/N_{50})^E/[1+(N/N_{50})^E]$，E≈1.5–2.7 需标定；
- Johnson 参考值：N₅₀ ≈ 2.0/8.0/12.5（探测/识别/辨认）；部分文献为 1.5/6/12，**引用时必须绑定来源**；
- R₅₀：沿 R 反解 $P_d(R)=0.5$；R₉₀ 同理。

### 3.3 主/副/支撑指标与判据

| 角色 | 指标 | 判据 |
|---|---|---|
| 主指标 | P_d(R) 曲线、R₅₀ | 报告 50%/90% 概率距离，附 95% 置信区间 |
| 副指标 | MRTD(f)、SNR | 用于对标与解释，不单独下结论 |
| 支撑指标 | τ_band、ΔT_app、N、r₀ | 误差预算与归因 |
| 验证判据 | 与 COSSIM 偏差 | ≤15%，且差异落入 U(k=2) 区间 |
| 精度目标 | R₅₀ 的 95% CI 半宽 | ≤10%（5 km 处约 ±0.5 km） |

### 5.9 临界值 / 切片法：把 4 维以上工况降到 2 维计算

思路：不跑全网格，先定义性能阈值 Q*，用"求根"得到临界值，再用 2 维切片 + 临界线表达高维空间。理论对应等性能分析（isoperformance）[50]。

**定义**

| 概念 | 定义 | 例 |
|---|---|---|
| 性能函数 | Q(θ)，θ 为全部参数 | P_d(4 km)、R₅₀ |
| 任务阈值 | Q*，由任务需求给定 | R₅₀ = 4 km |
| 临界值 | 满足 Q=Q* 的参数取值 p*（一维求根） | 临界能见度 MOR*(α) |
| 临界线/面 | 所有临界值组成的集合（即热力图上的等值线） | R₅₀=4 km 等值线 |
| 最优值 | **仅在存在权衡时才有意义** | 大气参数通常单调，无内点最优；传感器/部署参数才有帕累托最优 |

**流程（计算量比全网格小 1–2 个量级）**

1. 固定两个"主角"参数之外的其余参数（基准值），在 2D 网格上算 Q，画热力图，取 Q=Q* 等值线 C*；
2. 以 C* 上的点为起点，对第三个参数求根 p₃*(p₁,p₂) 使 Q=Q*，得到"容限曲线"；
3. 换 2–3 组固定值（基准 / 最不利 / 最有利）重复，检查 C* 漂移；漂移大说明切片假设不成立，该固定参数必须纳入边界；
4. 对临界线做 MC 传播，给 95% 置信带；
5. 交互强的组合（雾+强湍流）不靠切片，单独作为 corner 锚点计算。

**伪代码**

```python
def critical_surface(theta_fixed, p1_grid, p2_grid, p3_range, Q, Qstar):
    Z = np.full((len(p1_grid), len(p2_grid)), np.nan)
    for i, p1 in enumerate(p1_grid):
        for j, p2 in enumerate(p2_grid):
            if Q(p1, p2, **theta_fixed) >= Qstar:
                continue                      # 直接可行，无需求根
            # 二分求第三个参数的临界值（10-20 次评估）
            lo, hi = p3_range
            if Q(p1, p2, hi, **theta_fixed) < Qstar:
                continue                      # 区间内无解
            for _ in range(20):
                mid = 0.5 * (lo + hi)
                if Q(p1, p2, mid, **theta_fixed) >= Qstar:
                    lo = mid
                else:
                    hi = mid
            Z[i, j] = 0.5 * (lo + hi)         # p3*
    return Z
```

**优点**：输出是"等性能边界/容限曲线"，可解释性远好于散点表；计算量从 O(N^d) 降到 O(N² × 20)。
**代价**：切片结论依赖固定值；必须用 2–3 个切片和 corner 锚点验证，不能只算一条临界线。

| 中间量-大气 | τ_band（谱形+积分） | 辐射传输计算 | 大气模块导出/黑体标定反演 | 相对偏差 ≤15% |
| 中间量-图像 | 目标-背景对比度、SNR | 由 ΔT_app 计算 | 图像灰度/辐射值反演 | 相对偏差 ≤15% |
| 中间量-传感器 | MTF、MRTD（若可得） | MTF 链模型 | 图像边缘/靶标反演 | 趋势一致，偏差 ≤20% |
| 最终指标 | P_d、R₅₀ | 统一指标模型 | 同模型作用于 COSSIM 数据 | 偏差 ≤15% 且落入 U(k=2) |

方法：相对偏差 = (X_py − X_cos)/X_cos；同时给 RMSE 与 Bland–Altman 一致性界限；样本仅 5 点时以"偏差方向与量级"为主，不强行做统计检验。

### 6.4 预期差异来源与处置

| 差异来源 | 预期表现 | 处置 |
|---|---|---|
| 大气模型不同（内置 vs libRadtran） | τ 谱在吸收带边缘差异大 | 比谱形；必要时用 COSSIM 大气参数反标定 |
| 气溶胶参数化 | α、g、ω 不一致 → 路径辐射/散射差异 | 用同一 MOR+α 输入；记录 COSSIM 内部气溶胶模型 |
| 路径辐射/多次散射 | 低能见度时背景电平差异 | 分项输出 L_path，单独比 |
| 目标热模型/发射率 | 目标辐射差异 | 用同一温度/发射率输入 |
| 传感器噪声/响应 | SNR、对比度差异 | 统一 NETD/响应度/动态范围 |
| 离散化/采样 | MTF、边缘差异 | 检查采样因子与图像分辨率 |
| 图像反演误差 | 对比度/MTF 提取偏差 | 固定提取算法与窗口，报告不确定度 |
