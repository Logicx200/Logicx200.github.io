HITRAN2020 大气斜程红外透过率（H₂O / CO₂ / CH₄）

场景：平台高度 8 km，地面水平距离 20 km → 斜程 s = √(20²+8²) = 21.54 km（天顶角 68.2°）。

1. 数据与方法

项目设定
谱线数据HITRAN2020（hitran.org /lbl/api 下载，2026-11 取数），H₂O / CO₂ / CH₄ 全部同位素分子，475–5025 cm⁻¹，共 825 475 条谱线
谱线参数ν₀, S(296 K), A, γ_air, γ_self, E″, n_air, δ_air
线型Voigt（多普勒 + 洛伦兹），含气压频移、线强温度修正（TIPS 配分函数）与洛伦兹半宽温度修正
同位素按 HITRAN 天然丰度加权（σ 为母体分子每分子截面）
截断线翼按线强取 25 / 12 / 6 cm⁻¹；弱线用 5 倍粗网格 + 插值加速
大气US Standard Atmosphere 1976：T = 288.15 − 6.5z K，p = 1013.25(T/288.15)^5.25588 hPa
水汽地面 7.5 g/m³，标高 2 km（ρ = 7.5·e^(−z/2) g/m³），斜程可降水量 ≈ 40 mm
CO₂415 ppmv（均匀混合）
CH₄1.9 ppmv（均匀混合）
路径分层24 层，地面附近加密（z = 8u^1.5 km），每层取中点 T、p、数密度
光谱网格主谱 500–5000 cm⁻¹，步长 0.01 cm⁻¹（45 万点）；8–14 μm 窗口 0.002 cm⁻¹；3–5 μm 窗口 0.005 cm⁻¹
计算τ(ν) = Σ_层 σ(ν;T,p)·n·Δs，T(ν) = exp(−τ)

注：仅包含三种气体的谱线吸收，未含水汽连续吸收（MT_CKD）与气溶胶/散射；因此 8–14 μm 窗口的透过率略高于真实大气（实际夏季湿大气约低 10–20%）。HITRAN 返回的 CO₂ 数据中含 2901 条 同位素号为 0 的极弱线（S ≤ 1.4×10⁻²⁵），对结果无影响，已剔除。

  • 8–14 μm 长波红外窗口平均 T ≈ 0.73，10–12 μm 最透明（T ≈ 0.90）；
  • 6.3 μm（H₂O）、15 μm / 4.3 μm（CO₂）、2.7 μm（H₂O） 在 21.5 km 斜程上完全饱和（T ≈ 0）；
  • 3.3 μm（CH₄）与 7.7 μm（CH₄） 只有部分吸收（窗口处 T ≈ 0.86–0.89），可用于 CH₄ 探测；
  • 20 km 量级斜程上，水汽是最主要的红外吸收气体，8–14 μm 窗口内主要由 H₂O 谱线翼与弱线贡献。

4. 复现

python refetch_serial.py      # 下载 HITRAN2020 谱线（串行+校验，约 10 min）
python parse_lines.py         # 解析为 npz
python run_calc.py --gmin 500 --gmax 5000 --step 0.01 --out slant_spectrum
python run_calc.py --gmin 700 --gmax 1250 --step 0.002 --out slant_zoom_8_14
python run_calc.py --gmin 2000 --gmax 3333 --step 0.005 --out slant_zoom_3_5
python make_figures.py
python export_data.py

数值验证：本程序逐线结果与 HAPI absorptionCoefficient_Voigt 在 1000–1010 cm⁻¹ （H₂O，296 K，1 atm）线心处一致（差异 < 3%，源于网格取样）。
