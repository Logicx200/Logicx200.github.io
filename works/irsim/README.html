复杂大气环境下红外目标探测的简化物理模型 Python 包：大气用 Beer-Lambert + 气溶胶幂律 + 水汽连续吸收 + CO₂ 4.3 μm 带的参数化模型，性能走 MRTD → f_max → 周期数 N → TTPF 的经典链，输出波段透过率、视在温差、MTF/MRTD、P_d(R) 与 R50/R90。experiments.py 提供工况定义、LHS/GP 代理模型、Morris/Sobol 敏感性与相图网格，所有假设与文献依据都写在源码里。

要点

  • 参数化大气模型 + MRTD/TTPF 性能链
  • 工况定义 + LHS/GP 代理 + Morris/Sobol 敏感性
  • 依赖 numpy/scipy/pandas，接口可替换为正式辐射传输模型

技术栈

Python numpy scipy pandas
