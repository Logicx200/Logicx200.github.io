# 摄影文件夹 / 文件名归档解析器

## 为什么需要它

你的归档命名"不甚规则"，但同一批照片通常共享少量模式。解析器采用**分层打分**策略：

1. **绝对年份**：`2024年`、`2024-`、`2024_`、`2024.` 等 → 直接确定年份。
2. **月日**：`10月3日`、`10-03`、`1003`、`10.3` → 确定月、日。
3. **相对年份推断**：若文件夹只有"10月3日"没有年份，则取**同级目录或祖先目录**里的年份作为候选（例如 `2024年/10月3日 杭州西湖`）。
4. **兜底**：以上都失败时，使用照片自身的 EXIF `DateTimeOriginal`。

## 位置提取规则

- 先剔除日期片段、常见噪声词（`拍摄`、`照片`、`整理`、`精选`、`原片`、`修图`…）。
- 剩余文本按分隔符（`-_·,，、 ` 等）切分，取最长的连续中文/英文片段作为 `location`。
- 支持 `2024.10.03-杭州-西湖` → 位置取 `杭州 西湖`（多段拼接）。
- 已知地名表（`src/locationHints.js`）用于把"西湖"归一化为"杭州·西湖"，并可提供坐标。

## 输出

```json
{
  "date": "2024-10-03",
  "dateSource": "folder|exif|filename",
  "dateConfidence": 0.95,
  "location": "杭州西湖",
  "locationParts": ["杭州", "西湖"],
  "coords": { "lat": 30.24, "lng": 120.15, "source": "hint|exif" },
  "tags": ["夜景"],
  "notes": "原始文件夹：2024年/10月3日 杭州西湖夜景"
}
```
