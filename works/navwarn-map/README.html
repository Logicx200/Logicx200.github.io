中国沿海禁航区 + 航空禁区地图

2026 年 11 月 NOTAM / 航警的 Leaflet 单页地图

一个 Leaflet 单页地图（index.html），把中国沿海海事禁航区与航空 NOTAM 面状禁区画在同一张底图上，并叠加火箭发射轨迹、三维轨道示意与「火箭云」观测区等自制图层（traj3d.js / rocketcloud.js / orbit3d.json）。tools/ 下有完整的 NOTAM 数据源实测记录与获取/解析脚本，数据来自民航局 eAIP China 的月度 NOTAM Summary。

要点

  • 禁航区 + NOTAM 禁区 + 轨迹/火箭云多图层叠加
  • tools/README 记录官方 NOTAM 数据源接口与解析流程
  • 含三维轨道、火箭云质量评估与城市预览图
