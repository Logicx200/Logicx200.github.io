## 十、火箭云（暮光效应）观测区预测（2026-11-12）

```bash
python rocket_cloud.py    # -> ../rocket_cloud.png（需要 matplotlib / cartopy / scipy）
```

原理：清晨发射时地面还在晨昏蒙影（太阳高度 < -6°），而火箭飞到 50–150 km 的尾迹已被阳光照亮；观测者要同时满足三个条件才能看到“火箭云”：

1. 尾迹被照亮：尾迹星下点的太阳高度 e_plume > -β(h)，β=acos(R/(R+h)) 为高度 h 处的地平俯角；
2. 地面天空足够暗：观测点太阳高度 e_obs < -6°（更佳 < -12°）；
3. 尾迹高于地平线：观测点到尾迹星下点的大圆距离 < R·β(h)。

输入为修正后的 `../trajectory3d.json`；太阳位置用 Meeus 公式（误差 <0.01°）。结果（T0=2026-11-19 06:44:30 CST）：

- 发射点太阳高度 **-7.25°**（民用晨昏蒙影）；尾迹照亮段 **06:46:50–06:49:40 CST，高度 47–152 km**；
- 理论可见区约 **313 万 km²**（95.8–116.4°E，21.4–47.2°N），最佳观测区（太阳高度 < -12°）约 **122 万 km²**；
- 典型城市（仰角/方位/观测时太阳高度，均为可见）：西安 40°/98°/-6.9°，太原 30°/189°/-6.7°，重庆 14°/47°/-7.2°，包头 12°/163°/-8.5°，呼和浩特 12°/186°/-7.2°，银川 11°/124°/-10.4°，成都 10°/68°/-9.6°，兰州 9°/107°/-11.4°，西宁 6°/106°/-13.1°，酒泉 1°/113°/-16.4°；北京（-4.2°）、上海（+3.1°）已天亮，不可见。
- 局限：假设晴空、无地形遮挡，未模拟尾迹扩散与亮度；阈值 -6° 为经验值；实际能否看到取决于尾迹亮度与天气。
