DSH 心情之眼

13 种表情 + 活动阶段联动的悬浮桌宠

DeepSeek Harness 插件47 个文件3.1 MBDSH 插件桌宠表情动画活动检测
← 返回作品列表在线试玩 ▶GitHub 源码 ↗

一组 DSH「心情之眼」插件（versions/v1–v6 六个迭代版本）：host 半边提供 set_mood 自报心情，并把标准会话事件折叠成活动阶段（thinking / research / command / reading / writing / waiting / error / idle），client 半边渲染悬浮桌宠。v6 为「活动版」，额外叠加峰谷、余额与今日消耗；gallery/bar-eyes.html 是双杠眼表情与效果的研究页，可交互切换 13 种表情与自动巡演。

要点

  • 13 种表情（neutral…dizzy）+ 活动阶段联动
  • v1–v6 六个版本迭代，v6 叠加峰谷/余额/今日消耗
  • gallery/bar-eyes.html 表情与效果研究页

技术栈

JavaScript React Node.js Canvas
