城市路网 SVG 底图生成器

29 座城市离线秒开，任意区域在线生成，可下载 SVG / PNG

在线工具：选一座城市 / 搜一个地名 / 输入任意经纬度范围，得到一张不含任何文字标注的 矢量路网底图，支持浅色 / 深色 / 透明三种配色，SVG 与 PNG 一键下载。

  • 在线版（GitHub Pages）：/works/roadmap-svg/
  • 本地预览（矢量瓦片 / Overpass 需要 http 环境；预置城市在 file:// 下也能用）：
# 在仓库根目录执行
python -m http.server 8000
# 然后打开 http://localhost:8000/works/roadmap-svg/

页面本身零依赖、零第三方 JS 库（MVT 解析器是自研的）。**预置城市读随站点分发的离线数据， 打开即秒开**；自定义区域才需要联网抓矢量瓦片；Overpass 只作兜底。

三档数据源

档位触发条件数据来源典型耗时
① 内置离线数据选择预置城市（29 城）cities/<slug>.js，构建时从 VersaTiles 矢量瓦片抓取、量化压缩后随站点分发100–450 ms（本地脚本）
② 矢量瓦片自定义 bbox / 名称搜索 / 暂无离线数据的城市VersaTiles（Shortbread schema）→ OpenFreeMap（OpenMapTiles schema）1.5–3 s（6–30 块瓦片，并发 6）
③ Overpass 兜底上面两档都不可用Overpass API 公共实例（分块、重试、换端点）数十秒起，取决于公共实例负载

页面左上角的「① 选择区域」标题处有数据源徽标（内置数据 / 矢量瓦片 / Overpass 兜底）； 「统计与图例」里的「数据源」一行会显示具体来源（如 矢量瓦片 · VersaTiles · z14）。

① 预置城市（29 座，离线可用）

北京、上海、广州、深圳、成都、重庆、西安、武汉、杭州、南京、天津、苏州、长沙、郑州、青岛、 大连、厦门、济南、合肥、福州、昆明、沈阳、太原、石家庄、洛阳、长治、晋中、邯郸、宝鸡。

  • 共 23.8 万条道路、约 10.1 MB（单城 61 KB–660 KB，gzip 后约 20–230 KB）。
  • 坐标量化 q=25000（约 3.5 m 精度），lon = w + x/q，lat = s + y/q；几何已 Douglas-Peucker 简化（3.5 m 容差）。
  • 数据文件：cities/index.js + cities/<slug>.js（动态 <script> 注入，file:// 下同样可用）。
  • 太原 7,928 条 / 338 KB；北京 16,811 条 / 626 KB；上海 16,299 条 / 652 KB。

② 矢量瓦片（自定义区域）

  • 按 bbox 尺寸自动选 zoom：跨度 ≤3 km→z15、≤8 km→z14、≤20 km→z13、≤50 km→z12、≤100 km→z11（上限 z14；块数超过 36 时自动降 zoom）。
  • 浏览器内自研 MVT 解码器（protobuf varint/zigzag + geometry 命令流），同时兼容：
    • Shortbread（VersaTiles）：streets 图层，属性 kind（含 _link 归一化，track/path/footway 等忽略）；
    • OpenMapTiles（OpenFreeMap）：transportation 图层，属性 class + subclass（minor 由 subclass 细分到街巷）。
  • 单块先请求 VersaTiles，失败自动换 OpenFreeMap；两块都失败时记录失败块，继续抓其它块；整片都失败才回退 Overpass。
  • 并发 6，进度 [progress i / N]，可取消并保留已取得的部分；跨瓦片重复几何按坐标量化哈希去重。

③ Overpass 兜底

对 bbox 分块（目标 0.09°，最多 24 块），逐块请求 way["highway"~"..."] + out geom;， 失败重试并轮换公共端点（overpass-api.de → kumi.systems → osm.ch → private.coffee）。

使用流程

  1. 选择区域（预置城市 / 名称搜索 / 自定义 bbox）。预置城市会立刻加载内置离线数据； 其它区域会显示预计使用哪个 zoom、多少块瓦片。
  2. 点「获取道路数据」：预置城市重新载入内置数据（秒开）；其它区域走矢量瓦片（失败自动回退 Overpass）。 抓取中显示 [progress i / N]，可随时取消。
  3. 右侧预览，「实际大小 / 适应」切换缩放；选配色、画布宽度、PNG 倍率。
  4. 下载 SVG / PNG 或复制 SVG 源码。导出文件请保留署名： 数据 © OpenStreetMap contributors，ODbL 1.0。

渲染与导出

  • Web Mercator 投影（x = (rad(lon)-xmin)/spanX*width，y = (ymax-ln(tan(π/4+rad(lat)/2)))/spanY*height）， 画布宽度 1600 / 2400 / 3200 可选（2400 与 Python 原版一致），高度按 bbox 比例自动计算。
  • 道路分 6 组，线宽以 2400 px 画布为基准：
组highway / MVT 属性线宽（px @2400）
快速路 / 高速motorway, trunk（含 _link）3.8
主干道primary2.4
次干道secondary1.7
支路tertiary1.15
街巷unclassified, residential, living_street, minor0.8
服务道路service0.5
  • 粗线先画、细线后画；导出 SVG 每级一个 <path>（shape-rendering="geometricPrecision"、 带 viewBox、深浅色带背景 / 透明配色不带背景、<desc> 内含 ODbL 署名），坐标保留 1 位小数。
  • PNG 用 canvas 2×/3× 导出（最长边 8192 px、总像素约 3600 万，超限自动降倍率）。

URL 参数（可分享）

/works/roadmap-svg/?city=beijing&palette=light
/works/roadmap-svg/?bbox=37.855,112.545,37.885,112.585&palette=dark
  • city= 取城市 slug（beijing、shanghai、taiyuan…，见 cities/index.js）
  • bbox= 四至坐标：南纬,西经,北纬,东经
  • palette= 取 light / dark / transparent
  • URL 参数优先于浏览器记住的上次选择；页面不会自动在线抓取（预置城市会自动加载离线数据）。

数据来源与许可

  • 路网数据：© OpenStreetMap contributors，按 ODbL 1.0 使用。二次分发请保留署名与许可链接。
  • 矢量瓦片服务：VersaTiles（Shortbread schema）、 OpenFreeMap（OpenMapTiles schema）。
  • 兜底查询：Overpass API。地名搜索：Nominatim （遵循其使用政策，只在点击搜索时发一次请求）。
  • 预置城市数据为构建时从公共矢量瓦片抓取，随站点分发。
  • 页面加载本身只请求本站静态资源；只有用户点击后才会访问上述公共服务。

自测记录（本机 2026-11，Edge headless + CDP）

  • 预置城市离线：太原 7,928 条（338 KB）约 0.4 s 出图；北京 16,811 条（626 KB）约 0.14 s；上海 16,299 条约 0.17 s； file:// 下同样可用（无 CORS 请求）。
  • 矢量瓦片：自定义 2.6×3.3 km（z14、6 块、并发 6）→ 513 条 / 1.7 s（VersaTiles）； 强制 VersaTiles 失败 → OpenFreeMap 583 条 / 1.5 s；两者都失败 → Overpass 兜底成功。
  • 导出：北京 2400 px SVG 729 KB；2× PNG 4800×4800 / 9.3 MB。全流程无 console 异常。
  • 页面加载阶段仅请求本站静态资源（cities/index.js 4 KB + 单城数据），不发出任何外部请求。

已知限制

  • 矢量瓦片 / Nominatim 是公共免费服务，可能限流或临时不可用，页面会自动切换 / 重试并提示原因。
  • 自定义范围很大（>50 km）时瓦片自动降 zoom，路网会更概略；Overpass 兜底可能很慢。
  • 只在用户点击后抓取，浏览器端不落盘缓存；重复加载同一自定义区域会重新请求瓦片。
  • 只取道路中心线，不含建筑、水系、绿地等其它要素。
  • PNG 导出受浏览器 canvas 尺寸限制，超长图会自动限制倍率。
  • works/index.html 的作品列表需要在 data/works.js 里登记本页（站点构建流程的一部分）。
