城市路网 SVG 底图生成器

选一座城市、搜一个地名，或者直接输入任意经纬度范围，得到一张不含任何文字标注的矢量路网底图。预置城市读取随站点分发的内置离线数据（秒开）；其它区域按尺寸自动选 zoom，用矢量瓦片并发抓取；极端情况下自动回退 Overpass。支持浅色、深色、透明三种配色，SVG 与 PNG 一键下载，适合做海报底纹、示意图背景或数据可视化底图。

纯静态 · 零依赖 · 无需登录 预置城市离线数据 + 任意地名搜索 + 自定义 bbox 数据 © OpenStreetMap contributors（ODbL 1.0）· 瓦片 OpenFreeMap / VersaTiles

① 选择区域 预置城市—

标「内置」的城市已随站点打包离线路网数据（秒开、file:// 也能用）；标「在线」的点「获取道路数据」走矢量瓦片。其它地方请用「名称搜索」或「自定义 bbox」。

使用 Nominatim 公共搜索服务，请勿频繁请求。
    范围越大抓取越慢；建议不超过 0.6° × 0.6°。

    三档数据源
    
        
    ① 内置离线：预置城市的路网随站点分发，选城市即秒开（file:// 也能用）。② 矢量瓦片：自定义 bbox / 地名搜索按范围自动选 zoom，并发抓取 VersaTiles（Shortbread）与 OpenFreeMap（OpenMapTiles）的 MVT 瓦片，在浏览器里自研解码，15 km 城区约 4–6 秒。③ Overpass 兜底：两档都不可用时才逐块查 Overpass。三种来源最终都用 Web Mercator 投影、按 6 级分组、以不同线宽和颜色画成 <path>，只画线、不写任何路名或地名——这正是原项目的核心卖点。
    
      
    
      
    
        
    数据来源与许可
    
        
    所有路网数据均来自 OpenStreetMap（© OpenStreetMap contributors，ODbL 1.0）。矢量瓦片由 VersaTiles（Shortbread schema）与 OpenFreeMap（OpenMapTiles schema）提供；兜底查询用 Overpass API；地名搜索用 Nominatim。二次分发请保留上述署名与许可链接。
    
      
    
      
    
        
    使用提示
    
        
    页面本身零依赖：预置城市的内置数据在 file:// 下也能直接用；但矢量瓦片 / Overpass 抓取需要联网且会被 CORS 限制，建议在站点根目录执行 python -m http.server 8000 后访问 http://localhost:8000/works/roadmap-svg/。抓取大范围时请耐心等待，或点「取消」保留已取得的部分。
    
      
    
    
    

    
    
      与原版 Python 工具的差异 & 已知限制
      
    原版是本地 Python 脚本（roadmap_svg.py）：固定城市字典、分块请求 Overpass、落盘缓存、只输出深色/浅色两种全图 SVG，城市范围写死在代码里，加一座城市要改源码。网页版保留投影/分级/无标注的渲染思路，但把数据获取升级为三档：预置城市读随站点分发的离线数据（坐标量化 q=100000，秒开）、自定义区域用矢量瓦片（浏览器内自研 MVT 解码器，兼容 Shortbread 的 streets 与 OpenMapTiles 的 transportation 两种 schema）、Overpass 只在最后兜底。区域来源扩展为预置城市 / Nominatim 搜索 / 自定义四至坐标或中心点+宽高；配色扩展为浅色/深色/透明；导出支持 SVG（含 viewBox、shape-rendering="geometricPrecision"）、PNG（2×/3× canvas）与复制源码。
    
      
    限制：① 矢量瓦片服务与 Nominatim 都是公共免费服务，可能限流或临时不可用，页面会自动切换/重试并给出原因；② 自定义范围超过约 50 km 时矢量瓦片会降到较低 zoom（更概略），Overpass 兜底则可能很慢；③ 浏览器端不落盘缓存，在线数据每次都会重新请求；④ 只取道路中心线，不含建筑、水系、绿地等其它要素；⑤ PNG 导出受浏览器 canvas 尺寸限制，超长图会自动限制倍率。
