本地余额接口，API key 不出服务器

DSH 心情之眼的配套 host-only 插件：从 $DSH_HOME/.credentials.yaml 读取 DEEPSEEK_API_KEY，调用 DeepSeek 的 /user/balance 接口，只把金额字段返回给浏览器。浏览器永远看不到 API key，超时与错误都转成可直接渲染的安全返回值。

要点

  • API key 只存在于 host 端
  • 调用 /user/balance 并只投影金额字段
  • 超时/错误均转成安全返回值

技术栈

JavaScript Node.js
