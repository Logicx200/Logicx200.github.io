目录联接迁移 + Gaia 星表离线安装 + 相图脚本

三个零散实用脚本：Move-ProgramFiles-App.ps1 把 C:\Program Files 下的单个应用目录安全迁到其它盘并留目录联接（默认干跑、-Execute 才动文件、支持回滚）；siril_gaia_local_install.ps1 下载校验并解压 Gaia DR3 星表，让 Siril 的解析与光度色彩校准不再联网；scripts/phase_maps_illustrative.py 生成红外探测参数相图示意。

要点

  • Program Files 应用迁移：干跑 / 执行 / 回滚三档
  • Siril Gaia DR3 星表离线安装（约 1.14 GB 压缩包）
  • 相图脚本：MOR / Cn² / 距离 → 透过率 / Pd / N
