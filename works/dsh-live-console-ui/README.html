控制台的顶栏按钮（client 半边）

DeepSeek Harness 插件6 个文件12.4 KBDSH 插件client 半边顶栏按钮

dsh-live-console 的 client 半边插件：通过 host 注入的模块加载器，在对话顶栏渲染一个紧凑的「控制台」按钮，点击时向 host 请求带鉴权的控制台 URL 再打开页面。包体只有 host.mjs、lib/client.js 与 cordis.patch.yml，附带一个离线渲染自检脚本。

要点

  • 对话顶栏注入按钮，按需请求鉴权后的控制台 URL
  • 不注册路由/Slot 之外的侵入，包体极小
  • test/client-check.mjs 离线自检

技术栈
