红外大气工况分类图

σ_a(550) × PWV × Ångström 指数的工况分区

红外 · 大气仿真60 个文件10.6 MB大气工况气溶胶MERRA2AERONET
← 返回作品列表GitHub 源码 ↗

把影响红外成像的大气条件投影到「550 nm 气溶胶消光 σ_a × 可降水量 PWV」二维平面上，用 Ångström 消光指数 α 做第三维颜色编码，生成红外大气工况分类图（PNG / SVG / PDF 三种输出，并含无插值版与热力图版）。配套脚本用 HITRAN 逐线截面、MERRA2 气候值与 AERONET 站点统计，还产出多站工况统计、视在温差热力图、湍流分辨率热力图与 Pd 演示图，报告在 报告/ 下。

要点

  • σ_a × PWV 二维分区 + α 着色，输出 PNG/SVG/PDF
  • 无插值 / 热力图共三种工况图表达
  • 多站统计、视在温差与湍流分辨率热力图

技术栈

Python numpy matplotlib hapi
