**对结论影响最大的六项修正**（按量级排序）：

1. **光谱截面丰度口径与数据完整性（F11c，本轮新增）**——早期 MWIR 正式截面只有 H₂O，CO₂/CH₄ 以单一温度替代数据补入，且替代数据在 Voigt 计算中对 HITRAN 线强**重复折算天然丰度**（与参考实现同源缺陷），使 ¹³CO₂ ν₃ 带（4.4–4.5 μm，落在 MWIR 窗内）强度被压低约 90 倍、CO₂ 分量虚高（透过率虚高）。校准后使用完整 HITRAN2020 六物种、丰度只折算一次：MWIR 分物种 CO₂ 0.8115→0.6283；旧数据合计 τ_band 0.6178 →（仅 H₂O/CO₂/CH₄/AER 中间态）0.4564 →（补齐 O₃/N₂O/CO 后）**0.3156**（LWIR：旧数据 0.8142 → 0.7126，约 −12%）；两条合计 MWIR 0.6178→0.3156（**−48.9%**，等效光学厚度 +0.67）。**这是全项目对 MWIR 绝对距离影响最大的数据修正。**
2. **目标/背景反射项（F5）**——校准前"目标/背景各用自己的发射率乘黑体、无反射项"的写法，在目标与背景固有温差为零时仍给出 **−1.42 K（MWIR）/ −3.04 K（LWIR）** 的虚假视在温差（无大气上限情形；基线 10 km 实际工况为 −1.10 K / −2.68 K），并把热交叉盲区中心推到 **+1.46 K / +3.19 K**；校准后热交叉严格发生在 ΔT=0，盲区中心回到 0。在热交叉附近影响最大：ΔT=5 K、10 km 时，MWIR 视在温差由 2.71 K 修正为 3.56 K（+31%），LWIR 由 1.52 K 修正为 3.96 K（+161%）。**这是对临界状态表述影响最大的公式修正。**
3. **路径辐射（F13）**——校准前逐层 `B·(1−e^(−dτ))` 求和，在总光学厚度 τ_total=1 时高估 1.56 倍、τ_total=3 时高估 3.04 倍、τ_total=10 时高估 8.85 倍（均质板理论值；强吸收线心因逐层饱和更高）。校准后改用累计光学厚度的发射-吸收积分，路径辐射自动满足 `0 ≤ L_path ≤ B(T_max)`。
4. **Rayleigh 口径（F10）**——`0.008735·λ^(−4.08)` 是 **550 nm 垂直光学厚度系数**（τ=0.100），不是每 km 消光系数；校准后除以 8 km 标高得地面消光系数，550 nm 附近数值放大 1.43 倍。但红外波段绝对增量 <3×10⁻⁵（斜程），**对 R50 无可见影响（<0.1%），属口径修正。**
5. **ISO 2533 廓线（F7）**——8 km 处气压由指数廓线的 372.7 hPa 降为 355.9 hPa（校准前高 4.7%），干气体柱含量同向减少，基线 MWIR 波段透过率约 +1%，R50 约 +1%。
6. **球面斜程几何（F6）**——地球曲率使百 km 级斜程在低空多走一段稠密大气：基线气溶胶斜程光学厚度 20 km 处 +0.3%、100 km 处 +6.6%、140 km 处 +13.4%；对应大目标 R50 影响约 1–3%。地距↔斜距换算本身 <0.1%。

> 数值口径：F11c 采用大气模块终版截面（六物种 × 四气压，missing=无）实测值；过渡态数值均标注复算条件与来源，便于逐项复核。

**结论**：全部校准均不改变"小目标分辨率锁死、大目标大气锁死、湍流构成第三边界"的机制判断；改变的是绝对距离（尤其 LWIR 热态目标、热交叉盲区位置）与若干边界情形的语义（截断不再返回假边界解）。另有两处边界细节已由临界求解模块修复并复核通过：①热交叉盲区高侧根已收敛（基线 10 km 处盲区 (−0.7707, +0.7663) K，与独立参考一致）；②目标低于几何地平线时解析天花板返回 NaN 并写 `censored="低于几何地平线"`（`horizon_below=True`）。

### 1.2 状态定义与记录格式

每条公式按统一格式记录：**编号与名称 → 所在模块/函数 → 原式（校准前实现）→ 校准式 → 物理依据 → 数值核验方法 → 对 R50/结论的影响量级 → 状态**。凡"原式"与"校准式"相同者，标明"形式未变，口径/参数/边界语义已明确"。

### 1.3 数值核验的通用手段

1. **量纲与单位闭合**：如 m/km ≡ mrad、波段辐亮度 = Σw·光谱量；
2. **解析极限**：B→0 与 T→0/∞、τ→1（无吸收体）、f→0 时 MTF→1、P(N50)=0.5；
3. **与独立参考实现对比**：与 6S/ISO 2533 标准式、HITRAN 线表参考计算、解析闭式解对比；
4. **积分/守恒恒等式**：∫B dλ=σT⁴/π、∫ρ_v dz=PWV、τ_comp 乘积 ≈ τ_lam、0≤L_path≤B(T_max)；

## 2 辐射度量（`radiometry.py`）

### F1 普朗克黑体光谱辐亮度

- **位置**：`radiometry.planck(lam_um, T_K)`
- **原式**：`B(λ,T) = c1 / λ⁵ / (e^(c2/(λT)) − 1)`，λ 以 μm 计，`c1=1.191042972e8 W·μm⁴/(m²·sr)`，`c2=14387.76877 μm·K`。实现中以 SI 形式 `2hc²/λ⁵/(e^(hc/(λkT))−1)` 计算，再乘 1e−6 换到"每 μm"。
- **校准式**：形式不变。明确常数来源：`c1 = 2hc² × 10²⁴ = 1.191042972e8`（由 h=6.62607015e−34 J·s、c=2.99792458e8 m/s 按 CODATA 2018 推出）、`c2 = hc/k × 10⁶ = 14387.76877 μm·K`（k=1.380649e−23 J/K）；指数项做 700 上限截断（仅防溢出，对物理量无影响）。
- **物理依据**：Planck 黑体辐射定律（Planck 1901）；常数取 CODATA 2018。
- **数值核验**：
  - `B(10 μm, 300 K) = 9.924033 W·m⁻²·sr⁻¹·μm⁻¹`（规范定标值 9.924）；
  - `∫₀^∞ B(λ,T) dλ = 146.199733 W·m⁻²·sr⁻¹`，与 `σT⁴/π = 146.199835` 的相对误差 **−7.0×10⁻⁷**（σ=5.670374419e−8 W·m⁻²·K⁻⁴，300 K）；
  - Wien 峰值 `λ_peak = 2897.8/T = 9.659 μm`（300 K），与 10 μm 量级一致；
  - `B(4.25 μm, 300 K) = 1.079398 W·m⁻²·sr⁻¹·μm⁻¹`。
- **影响量级**：公式数值正确性在 10⁻⁶ 级；**原规范与代码注释中曾出现的"9.19"为笔误，正确值 9.924**，不影响计算链。
- **状态**：**已验证**。

### F2 普朗克温度导数 dB/dT

- **位置**：`radiometry.d_planck_dT(lam_um, T_K)`
- **原式/校准式**：`dB/dT = B(λ,T)·x·eˣ/(eˣ−1)/T`，`x = c2/(λT)`。两版形式相同。
- **物理依据**：对 Planck 函数求 ∂B/∂T 的解析结果；小温差下 `ΔB ≈ (dB/dT)·ΔT`，这是波段对比度加权的物理基础。
- **数值核验**：与中心差分 `(B(T+h)−B(T−h))/(2h)`（h=1e−4 K）对比：`(10 μm,300 K)` 解析 0.15997157 vs 数值 0.15997157（相对差 2×10⁻¹⁰）；`(4.25 μm,300 K)`、`(4.25 μm,250 K)` 相对差 ≤1.1×10⁻¹⁰。
- **影响量级**：用于 F3 权重定义与"小温差对比度"解释，本身不直接进入结果。数值核验通过。
- **状态**：**已验证**。

### F3 波段对比度加权

- **位置**：`radiometry.band_weights(lam_um, T_ref)`、`BandContext.__post_init__`
- **原式**：`w(λ) ∝ dB/dT(λ, T_ref)·Δλ`，归一化 `Σw=1`，`T_ref` 固定 288.15 K。
- **校准式**：`w(λ) = (dB/dT(λ,T_ref)·Δλ) / Σ(...)`，**参考温度取场景背景温度**（`T_ref = params.T_REF_WEIGHT_K = 293.15 K = 20 ℃`，由 `chain.evaluate` 按 `scn.bg_temp_c+273.15` 传入）；Δλ 由相邻波长差分（等价梯形积分离散权）。波段平均定义为 `τ_band = Σw·τ(λ)`（"对比度等效波段透过率"），所有波段量（τ_band、L_path、L_target/L_bg、λ_eff、t_app 的 LUT）使用同一组权重。
- **物理依据**：探测器接收到目标-背景辐亮度差在小温差下正比于 dB/dT，故按 dB/dT 加权等价于对比度加权（Lloyd 1975、Ratches 1976 体系）；软件只给平坦波段边界、无光谱响应函数，故不引入 R(λ)（保留近似，已登记）。
- **数值核验**：
  - `λ_eff = Σwλ`：T_ref 288.15→293.15 K 时，MWIR 4.37946→4.37537 μm（−0.00409 μm，−0.09%），LWIR 9.88693→9.87607 μm（−0.01086 μm，−0.11%）；
  - 对含大气透过率形状的合成光谱，视在温度变化：MWIR +0.005 K、LWIR +0.028 K（<0.03 K）；
  - 权重与 LUT 自洽：`t_app(blackbody_band(T)) − T` 最大 1.15×10⁻⁴ K（见 F4）。
- **影响量级**：λ_eff 漂移使气溶胶 Ångström 外推变化 <0.2%；**LWIR 衍射截止 ∝ 1/λ_eff 变化 +1.26%**（30.0→30.375 cyc/mrad），对衍射受限目标 R_res/R50 约 +1.2%；MWIR 为 Nyquist 受限，无影响；视在温差影响 <0.03 K。原固定 288.15 K 属近似，校准后与"背景温度"场景自洽。
- **状态**：**已修正**（参考温度口径）；权重归一、离散权与网格无关性 **已验证**。

### F4 波段辐亮度 → 视在温度的反演（LUT）

- **位置**：`radiometry.BandContext.t_app`、`BandContext.__post_init__`
- **原式**：以固定的 288.15 K 加权生成一次 LUT（T∈[100,900] K，4001 点），`t_app(L)` 线性插值反演。
- **校准式**：LUT 随（波段、光谱网格、参考温度）缓存：`LUT_L(T) = Σw·B(λ,T)`，`T∈[100,1000] K`（4501 点，覆盖高温背景与 ΔT_app 上限）；`t_app(L)=interp(L, LUT_L, LUT_T)`，L 超出 LUT 范围时夹取端点（`LUT_L` 单调递增保证反演唯一）。目标与背景使用**同一个** `BandContext`（同权重、同 LUT），保证 ΔT_app 的差分自洽。
- **物理依据**：Planck 函数关于 T 严格单调，故波段辐亮度与等效黑体温度一一对应；等效温度定义 `t_app(L)` 满足 `Σw·B(λ,t_app)=L`。
- **数值核验**：对 T=250/293.15/350 K 的正演-反演闭环：|`t_app(blackbody_band(T))−T`| ≤1.15×10⁻⁴ K；LUT 单调性逐点检查通过；NaP/越界夹取行为在 `_LUT_T_MIN/_LUT_T_MAX` 边界测试通过。
- **影响量级**：<0.01 K，对 R50 无影响；校准重点是"同权重、同 LUT"以避免目标/背景差分中的系统偏差。
- **状态**：**已验证**（实现细节已修正）。

### F5 不透明表面辐亮度：发射 + 反射项，与对比度化简

- **位置**：`radiometry.BandContext.surface_radiance / contrast_radiance`、`chain.evaluate`
- **原式**：`L = ε·B(λ,T)·τ(λ) + L_path(λ)`，目标与背景各自用其发射率乘自身黑体，无反射项。
- **校准式**（环境辐亮度按背景黑体，`T_amb = T_b`）：
  ```
  L_t = Σ_λ w·{ [ε_t·B(λ,T_t) + (1−ε_t)·B(λ,T_amb)]·τ(λ) + L_path(λ) }
  L_b = Σ_λ w·{ [ε_b·B(λ,T_b) + (1−ε_b)·B(λ,T_amb)]·τ(λ) + L_path(λ) }
      = Σ_λ w·[ B(λ,T_b)·τ(λ) + L_path(λ) ]        （T_amb = T_b）
  ΔL  = L_t − L_b = ε_t·Σ_λ w·[B(λ,T_t) − B(λ,T_b)]·τ(λ)     （严格）
  ΔT_app = t_app(L_t) − t_app(L_b)
  ```
  实现上 `L_t` 用 `surface_radiance(t_t, ε_t, τ, L_path, t_b)`，`L_b` 用 `surface_radiance(t_b, ε_b, τ, L_path, t_b)`；`contrast_radiance()` 提供解析等价式用于交叉校核。
- **物理依据**：基尔霍夫定律（不透明表面 `ρ=1−ε`）；环境辐亮度取背景黑体是"目标四周地物与背景同温、热平衡"的均一近似（已登记）。该假设使背景辐亮度化简为 `B(T_b)τ+L_path`，与"背景=黑体"口径一致。
- **数值核验**：
  - 热交叉：`ΔT=0`、`τ=1`、`ε_t=0.90/ε_b=0.95`、背景 20 ℃ 时，校准式 `ΔT_app = +0.000000 K`；校准前实现 `−1.4244 K`（MWIR）、`−3.0376 K`（LWIR）。
  - 解析校验：校准前虚拟偏置 `≈ −(ε_t−ε_b)·B/(dB/dT)`：4.25 μm/300 K 为 −1.329 K、10 μm/300 K 为 −3.102 K，与数值 −1.42/−3.04 K 一致（差异来自波段加权与 LUT 曲率）。
  - 校准前"热交叉"位置（`ΔT_app=0` 对应的固有温差）：MWIR +1.451 K、LWIR +3.160 K；校准式严格 0。
  - 解析等价式 `contrast_radiance` 与 `surface_radiance` 两式相减在机器精度内一致（相对差 <1e−12）。
- **影响量级**：**本项目最重要的公式修正**。
  - 热交叉盲区中心从 +1.46 K（MWIR）/+3.19 K（LWIR）移到 **0**，即"目标与背景同温时识别必然失败"的物理结论被恢复；
  - 无大气上限情形（τ=1）：ΔT=20 K 时视在温差 MWIR 约 17.0→18.4 K（**+8%**）、LWIR 约 15.1→18.2 K（**+20%**）；

### F6 球面地球几何与斜程分层

- **位置**：`atmosphere.spectral_state`（几何部分）、`critical` 中的地距↔斜距换算
- **原式**：`r_slant = hypot(r_ground·1000, z_s−z_t)/1000`（平面三角）；沿高度 `z∈[z_t,z_s]` 均匀分层，层中点温度/密度按该高度取值。
- **校准式**：地心角 `φ = r_ground/R_E`（R_E=6371 km）；视线为弦，弦长
  ```
  r_slant = sqrt( (R_E+z_s)² + (R_E+z_t)² − 2(R_E+z_s)(R_E+z_t)·cos φ )
  ```
  第 i 层中点三维位置 `P_i = (1−s_i)·P_s + s_i·P_t`（s_i 为沿弦的等分参数），层高 `h_i = |P_i| − R_E`；层光学厚度用 `β(λ,h_i)·Δs`，`Δs = r_slant/n_layers`；默认 `n_layers=40`。地面距离↔斜距换算用球面关系（给定斜距与两端高度，解 φ 得地距；解析天花板与平台高度扫描使用）。
- **物理依据**：球面地球几何（WGS-84 平均半径 6371 km，不含大气折射）；沿弦分层是球对称大气中斜程积分的标准离散化。
- **数值核验**：
  - 斜距本身：球面弦长 vs 平面三角，20 km +5.4×10⁻⁴、100 km +6.1×10⁻⁴、300 km +5.4×10⁻⁴（相对差 <0.1%）；
  - 层中点高度（8 km 平台 → 地面目标）：20 km 地面距离时球面 3.992 km（平面 4.000 km）、100 km 时 3.804 km、300 km 时 2.233 km；
  - 斜程气溶胶光学厚度（基线 AOD=0.587、α=1.30、H=1.5 km，MWIR）球面/平面比值：20 km ×1.003、50 km ×1.016、100 km ×1.066、140 km ×1.134；Rayleigh 比值：100 km ×1.017、140 km ×1.033（绝对增量 <1×10⁻⁵）；
  - 分层收敛：40 层相对 20/80 层的 τ_band 相对差实测：MWIR +4.6×10⁻⁴ / −1.2×10⁻⁴，LWIR +2.6×10⁻⁴ / −6.7×10⁻⁵（均 <0.1% 验收门槛）。
- **影响量级**：20 km 内透过率影响 <0.3%（可忽略）；**100 km 地面距离处气溶胶斜程 τ +6.6%**（对应波段 τ 约 −3%，R50 约 −1~3%）；140 km 处斜程 τ +13.4%（R50 影响更大，但该距离通常已接近搜索截断）。地距↔斜距换算本身对 R_res 影响 <0.1%。
- **状态**：**已修正**。

### F7 ISO 2533 标准大气廓线

- **位置**：`atmosphere.spectral_state`（廓线部分）、`atmosphere._profile`
- **原式**：`T = T0 − 6.5·z_km`（下限 216.65 K）；`p = p0·exp(−z_km/8)`（单一指数标高近似）。
- **校准式**（ISO 2533:1975）：
  ```
  0–11 km ：T = T0 − 6.5 z ，p = p0·(T/T0)^(gM/(R·L))    指数 gM/(RL)=5.25588
  11–20 km：T = 216.65 K ，p = p11·exp[−gM(z−11 km)/(R·216.65)]
  ```
  其中 T0=288.15 K（=15 ℃，由 `t0_c` 覆盖）、p0=1013 hPa（软件默认气象）、g=9.80665 m/s²、M=0.0289644 kg/mol、R=8.314462618 J/(mol·K)、L=6.5×10⁻³ K/m。传感器与目标之间高度均≤12 km，主用 0–11 km 分支；11–20 km 分支用于高空平台扫描的上限校核。
- **物理依据**：ISO 2533:1975 标准大气；静力平衡 + 理想气体状态方程。
- **数值核验**：与指数近似对比（p0=1013 hPa）：

  | z (km) | p_ISO (hPa) | p_exp (hPa) | 校准前/后 |
  |---|---|---|---|
  | 0 | 1013.00 | 1013.00 | 1.000 |
  | 2 | 794.76 | 788.93 | 0.993 |
  | 4 | 616.26 | 614.42 | 0.997 |
  | 8 | 355.92 | 372.66 | **1.047** |
  | 11 | 226.27 | 256.13 | 1.132 |
  | 20 | 54.74 | 83.15 | 1.519 |

  8 km 处指数近似高 4.7%（与参数登记"约 4.5%"一致）；0–4 km 内差异 <0.8%。
- **影响量级**：8 km 以上气压降低 → 干气体柱含量与压力展宽降低。对基线 MWIR 的干气体光学厚度（CO₂/CH₄/O₃ 等）约 −4.5%，波段透过率约 **+1%**，R50 约 **+1%**；水汽柱含量由 PWV 归一（F8），不受气压廓线影响。属"量级 1%"的系统修正。
- **状态**：**已修正**。

### F8 水汽廓线与柱含量

- **位置**：`atmosphere._profile` / `spectral_state`
- **原式**：指数水汽廓线，柱含量由 15 ℃/50%RH 的固定值给出（PWV=1.28 cm）。
- **校准式**：`ρ_v(z) = PWV_cm·10 / (H_wv·1000) · e^(−z/H_wv)`（kg/m³），`H_wv=2.0 km`；该归一保证 `∫₀^∞ ρ_v dz = PWV_cm·10 kg/m²`（1 cm 可降水量 = 10 kg/m²）。水汽分子柱数密度 `dn = (ρ_v/M_H2O)·N_A·Δs`。
- **物理依据**：可降水量定义（整层水汽柱质量）；指数廓线为 LOWTRAN/ISO 2533 湿空气简化口径（保留近似）。
- **数值核验**：15 ℃、50%RH：e_s(15 ℃)=17.04 hPa → e=8.52 hPa → ρ_v=216.7·e/T=6.408 g/m³ → PWV=6.408 g/m³ × 2000 m = 12815 g/m² = **1.28 cm**（与软件默认气象推导一致）；数值积分 `∫ρ_v dz` 与 PWV 的误差 <1e−12（解析归一）。
- **影响量级**：柱含量守恒，标高只改垂直分布：天底方向水汽 τ 变化 <3%，L_path 的加权温度 2–5%；对 R50 影响 <2%。
- **状态**：**已验证**（保留近似：指数廓线）。

### F9 气溶胶指数廓线与 Ångström 外推

- **位置**：`atmosphere._profile` / `spectral_state`
- **原式/校准式**（形式相同，口径明确）：
  ```
  β550(z) = (AOD550 / H_aer)·e^(−z/H_aer)                （km⁻¹，H_aer=1.5 km）
  β_aer(λ,z) = β550(z)·(0.55/λ)^α                          （Ångström 幂律，λ μm）
  AOD550 = (3.912/V)·H_aer                                 （Koschmieder + 指数廓线柱积分）
  ```
  气溶胶按外消光处理（不含散射相函数与多次散射）；α 取环境类别中值（见 F34 与参数表）。
- **物理依据**：Koschmieder 1924 能见度关系、Ångström 1929 波长幂律、指数标高廓线（LOWTRAN/OPAC 口径）；外消光近似为工程简化（已登记缺口）。
- **数值核验**：基线 `β550=3.912/10=0.3912 km⁻¹`、`AOD550=0.3912×1.5=0.5868≈0.587`、等效能见度 `V_eq=3.912/β550=10.0 km`（与软件默认 10000 m 自洽）；MWIR 4.375 μm 垂直气溶胶 AOD=0.587×(0.55/4.375)^1.30=0.0738，LWIR 9.876 μm 为 0.0137；斜程 τ_aer（20 km 地面）≈0.106（球面几何，占 MWIR 总 τ 的 15–20%）。
- **影响量级**：气溶胶是霾/沙尘工况主控参数。基线 AOD 下 MWIR 气溶胶 τ≈0.1（20 km 斜程），AOD 0.6→4.0 对大型舰船 R50 约 −20~−35%（最终以 `S04` 数据为准）。
- **状态**：**已验证 / 保留近似**（指数廓线、球面均匀 α、外消光）。

### F10 Rayleigh 分子散射口径

- **位置**：`atmosphere.spectral_state`（分子散射项）
- **原式**：`β_mol(λ) = 0.008735·(0.55/λ)^4.08`，单位 km⁻¹（把 550 nm **垂直光学厚度系数**误当每 km 消光系数）。
- **校准式**：
  ```
  τ_R,vert(λ) = 0.008735·λ^(−4.08)          （λ μm，海平面垂直光学厚度，无量纲）
  β_R,0(λ)   = τ_R,vert(λ) / H_R             （H_R=8 km，地面消光系数 km⁻¹）
  层光学厚度 dτ_R = β_R,0(λ)·(n(z)/n0)·Δs    （n ∝ p/T，随高度密度缩放）
  ```
- **物理依据**：6S 标准 Rayleigh 公式（Vermote 1997）与 Bodhaine 1999 系数；`0.008735·λ^(−4.08)` 为垂直光学厚度，550 nm 处 τ_R,vert=0.100（与大气光学标准值 0.10 一致）。
- **数值核验**：
  - `τ_R,vert(0.55 μm) = 0.008735×0.55^(−4.08) = 0.10013 ≈ 0.10`；
  - 校准前 β(old)=0.008735 km⁻¹ vs 校准后 β0=0.10013/8=0.012517 km⁻¹，**放大 1.433 倍**（与"偏小 1.43 倍"一致）；
  - IR 波段绝对量：4.375 μm 处 β_new=2.981×10⁻⁶、β_old=2.080×10⁻⁶ km⁻¹（差 9.0×10⁻⁷ km⁻¹）；10 μm 处 9.08×10⁻⁸ vs 6.34×10⁻⁸ km⁻¹（差 2.7×10⁻⁸）；
  - 20 km 斜程 τ_R 差异 <3×10⁻⁵，占总透过率 <5×10⁻⁵。
- **影响量级**：红外波段分子散射本身可忽略（τ_R<10⁻⁴）；**对 R50 无可见影响（<0.1%）**，属口径修正与链路完整性登记。
- **状态**：**已修正**（口径），数值影响可忽略。

### F11 气体吸收光学厚度、截面插值与光谱网格

- **位置**：`atmosphere._XsectCache / _interp_weights / _layer_dtau / spectral_state`
- **原式**：波数网格 0.2 cm⁻¹；截面温度仅用单温度数据或两温度线性插值；**所有高度层统一用 1 atm 截面**（忽略气压分层对谱线展宽/线翼的影响）；部分物种缺失。
- **校准式**：
  ```
  dτ_gas(λ,i) = σ_g(λ,T_i,p_i)·N_g(h_i)·Δs_i
  H2O   ：N = (ρ_v/M_H2O)·N_A·Δs
  干气体 ：N = n_air(h_i)·x_g·Δs        （n_air = p/(k_B T)）
  σ_g(λ,T_i,p_i)：HITRAN2020 逐线 Voigt 截面（cm²/molecule），

  光谱网格：波数域均匀 Δν = 0.05 cm⁻¹（HITRAN 1 atm 线宽 0.05–0.1 cm⁻¹ 原生量级）
  ```
  物种：H₂O、CO₂、CH₄、O₃、N₂O、CO；干气体按气压分组、按混合比合并为等效吸收体（数学上线性可加，等价于逐物种求和，仅优化计算量）。
- **物理依据**：HITRAN2020 数据库（Gordon 2022，JQSRT 277:107949）、HAPI 1.3（Kochanov 2016）、逐线 Voigt 谱型；谱线强度不确定度 5–10%（登记）。

  - 温度节点覆盖：220/250/280/300 K 覆盖 0–12 km 层温 216.65–288.15 K（F11b）；
  - 与参考线吸收计算（独立项目 `hitran_slant` 的同几何线吸收结果）对比：在**同一丰度约定**下波段平均透过率最大差 0.07%（证明两条实现除丰度约定外一致）；与 HAPI 独立实现的逐点强吸收中位差 0.90%、p90 4.07%，窗口加权平均最大 1.70%（N25 通过）。

- **状态**：**已修正**（网格/物种/来源/气压分层）。

### F11b 气压分层吸收截面（多温度 × 多气压，本轮新增）

- **位置**：`atmosphere._XsectCache / _interp_weights / _layer_dtau`；截面文件 `07_光谱数据/xsect_{band}.npz`，键格式 `<SP>_T<温度>_P<气压>`
- **原式（校准前）**：所有高度层统一使用 1 atm 截面（键 `<SP>_T<温度>`），即把 0–12 km 范围内 1.0→0.19 atm 的压致展宽与线翼统统按地面气压处理。
- **校准式**：
  ```
  截面键：<物种>_T<温度>_P<气压>（温度 220/250/280/300 K；气压 1.0/0.6/0.36/0.2 atm）
  层内双线性插值：温度线性、气压在 ln p 坐标线性（p_atm = p_layer/1013.25）
  σ_g(λ,T_i,p_i) = Σ_{a,b} WT[i,a]·WP[i,b]·σ_g(λ,T_a,p_b)
  dτ_gas(λ,i)   = σ_g(λ,T_i,p_i)·N_g(h_i)·Δs_i
  ```
- **物理依据**：HITRAN 逐线 Voigt 的 Lorentz 半宽与远翼吸收随气压变化；饱和强线的等效宽度近似 ∝√p，低气压层若沿用 1 atm 截面会高估线心/带吸收。
- **数值核验**（同几何、同气象、同 T 节点，仅把截面键限定为 P=1.0 vs 全气压；终版截面六物种均含四气压节点）：
  - MWIR：20 km 地面 τ_band 相对差 +0.003%，100 km +0.006%，300 km +0.008%，平台 12 km +0.010%；
  - LWIR：20 km +0.002%，100 km +0.007%，300 km +0.011%；
  - 线级光谱差异显著：低气压层 dτ 在强线处可差数十 %，但波段平均近似抵消（压致展宽主要重排线翼、积分强度近似守恒）；
  - **结论：气压分层对波段平均 τ_band 的影响 <0.02%**，其主要价值是物理正确性与线级光谱（图03）的准确性，以及对 H₂O/CO₂/CH₄ 线翼形状的保真；
  - 终版截面已含 O₃/N₂O/CO 的四气压节点：全物种 A/B 实测 MWIR +0.007%、LWIR +0.0025%，分物种 dτ 均 <2×10⁻⁵；此前估计的 15–25% 是**饱和带内光学厚度**的变化量级，对 dB/dT 加权的全波段平均并不成立；
- **影响量级**：对 τ_band / ΔT_app / R50 的影响 **<0.02%（可忽略）**；不应把截面数据完整性问题（F11c）归因到气压分层。
- **状态**：**已验证 / 已修正**（气压分层实现与数值影响已核验；六物种四气压节点齐备）。

### F12 分层光学厚度累加与波段透过率

- **位置**：`atmosphere.spectral_state`
- **原式/校准式**：
  ```
  dτ_i(λ) = [β_aer(λ,h_i) + β_R(λ,h_i) + Σ_g k_g(λ,T_i)·dn_{g,i}]·Δs
  τ(λ)    = exp(−Σ_i dτ_i)
  τ_band  = Σ_λ w(λ)·τ(λ)
  τ_comp  = {H2O, CO2, CH4, O3, N2O, CO, AER, MOL} 各自 exp(−Σ_i dτ_{g,i})，满足 Π τ_comp ≈ τ
  ```
- **物理依据**：Beer-Lambert 定律、各吸收体光学厚度可加（线性介质）。
- **数值核验**：

### F13 路径辐射（累计光学厚度的发射-吸收积分）

- **位置**：`atmosphere.spectral_state`（路径辐射部分）
- **原式**：`L_path(λ) = Σ_i B(λ,T_i)·(1 − e^(−dτ_i))`（逐层"自身发射"求和，未乘层前透射率）。
- **校准式**：
  ```
  L_path(λ) = Σ_i B(λ,T_i)·[ e^(−τ_before,i) − e^(−τ_after,i) ]
  τ_before,i = Σ_{j<i} dτ_j ，τ_after,i = τ_before,i + dτ_i
  ```
  即第 i 层对传感器处辐亮度的贡献 = 该层发射 × 到达传感器前的透射率；逐层用层中点温度计算 Planck。
- **物理依据**：辐射传输方程逐层解；均匀层（温度、密度在层内近似常数）的解析解为 `B(T)(1−e^(−dτ))`，但作为**层贡献**必须再乘该层之前累计透过率 `e^(−τ_before)`。校准前的写法只在 τ 很小且层数很多时收敛到正确值。
- **数值核验**：
  - 均质板（单温度、均匀分层、总光学厚度 τ_total）与解析解 `B·(1−e^(−τ_total))` 对比，校准前/后比值：

    | τ_total | 0.1 | 0.2 | 0.5 | 1 | 2 | 3 | 10 |
    |---|---|---|---|---|---|---|---|
    | 校准前/校准后 | 1.05 | 1.10 | 1.26 | **1.56** | 2.26 | 3.04 | **8.85** |

  - 强吸收线心（单层 dτ=5、5 层）：校准前 2.431 vs 校准后 0.674（**3.61 倍**）；实际 HITRAN 强线线心逐层饱和时高估可达一个量级；
  - 界限检验：校准式恒满足 `0 ≤ L_path(λ) ≤ B(λ,T_max)`（因 Σ(e^(−τ_before)−e^(−τ_after)) = 1−e^(−τ_total) ≤1 且 B 取层内温度）；QA 抽样 5 个距离通过；
  - 波段量 `L_path = Σw·L_path(λ)` 与光谱量一致（F3 权重）。
- **影响量级**：校准前系统性高估路径辐射 → 目标/背景辐亮度整体抬高 → `t_app` 曲线在较高辐亮度处斜率（=1/(dB/dT)）变小 → **ΔT_app 偏小、识别距离偏保守**，在 LWIR 水汽吸收带与强 CO₂ 带最明显。修正后 LWIR 的 ΔT_app 上升、R50 增大；MWIR 因 4.3 μm 带强吸收也有可观修正。量级：`δ(ΔT_app) ≈ δL_path/(dB/dT)`，LWIR 10 μm 处 `dB/dT≈0.16 W·m⁻²·sr⁻¹·μm⁻¹·K⁻¹`，即 0.1 W·m⁻²·sr⁻¹ 的辐亮度误差对应约 0.6 K。**最终 R50 变化以 `03_数据` 为准。**
- **状态**：**已修正**。

### F15 几何链：IFOV、焦距、口径、Nyquist、衍射截止

- **位置**：`Sensor.ifov_mrad / f_number / f_nyq_cyc_mrad / f_cut_diffraction / f_upper`
- **公式**：
  ```
  IFOV   = FOV_h / N_h                    （mrad）
  f      = p / IFOV                       （m；p 为像元间距）
  D      = f / F#                         （m）
  f_nyq  = 1/(2·IFOV)                     （cycles/mrad）
  f_cut  = D/λ · 1e−3                     （cycles/mrad，λ 用 μm；圆孔非相干截止）
  f_upper= min(f_nyq, f_cut) if cap_nyquist else f_cut
  ```
- **原式**：形式相同；校准明确两档预设（RECOG 识别通道设定值、SEARCH 软件实测显示配置）与三式自洽要求。
- **物理依据**：几何光学与采样定理（Nyquist）；圆孔衍射截止频率 `D/λ`（角频率）。
- **数值核验**：

- **影响量级**：定义量。IFOV 是识别距离的一阶因子（R50∝f_nyq·D_eff/N50，几何受限段 R50∝1/IFOV）。
- **状态**：**已验证**。

### F16 光学衍射 MTF（Airy OTF）

- **位置**：`Sensor.mtf`（衍射项）

- **状态**：**已验证**。

### F18 视线抖动 MTF

### F19 湍流：Fried 相干直径与湍流 MTF

- **位置**：`sensor.fried_r0`、`Sensor.mtf`（湍流项）
- **公式**：
  ```
  r0 = (0.423·k²·Cn²·L)^(−3/5) ，k=2π/λ
  MTF_turb(f) = exp[ −3.44·(λ·f·1e3/r0)^(5/3) ]
  ```
  （f 单位 cycles/mrad 时 `λ·f·1e3` 为 rad⁻¹ 量纲下的空间频率，与 r0 匹配。）
- **原式/校准式**：形式相同；校准明确"均匀 Cn²、长曝光、无限外尺度"的适用范围，并作为第三类边界的物理来源。
- **物理依据**：Fried 1966（JOSA 56:1372）；Kolmogorov 湍流长曝光近场近似。
- **数值核验**：λ=4.375 μm、Cn²=1×10⁻¹⁵、L=20 km → r0≈0.18 m（与 `r0∝L^(−3/5)` 标度一致：8 km 时约 0.30 m）；f_nyq=40 时湍流 MTF≈0.04（强退化）；Cn²=0 时 r0=∞、MTF_turb≡1（极限正确）。
- **影响量级**：Cn² 是唯一能让"干净大气 + 近距离"仍然识别失败的因子；Cn²≥1×10⁻¹⁴ 后成为主控（最终以 `S07` 数据为准）。**保留近似**：均匀 Cn²、忽略外尺度 L0、长曝光。
- **状态**：**已验证 / 保留近似**。

### F22 f_max 求根与对比度地板

- **位置**：`Sensor.f_max`、`Sensor.delta_t_floor_k`
- **原式**：在 [0,f_upper] 网格（600 点）上由 `MRTD(f)=|ΔT_app|` 找最高交点并线性插值；地板条件在代码中隐含 τ_opt 折减，但文档表述为"ΔT_app ≤ k·NETD"（不完整）。
- **校准式**：
  ```
  d_eff = τ_opt·|ΔT_app|
  若 d_eff ≤ k·NETD（等价 τ_opt·ΔT_app ≤ k·NETD）→ f_max = 0      （对比度地板）
  否则求 f_max = max{ f ∈ [0, f_upper] : MTF_sys(f) ≥ k·NETD/d_eff }
  若 MTF_sys(f_upper) ≥ k·NETD/d_eff → f_max = f_upper            （饱和到 Nyquist/衍射上限）
  否则在最后一个满足的网格点与下一点之间线性插值
  ```
  等价写法：`MRTD(f_max) = τ_opt·|ΔT_app|`。
- **物理依据**：MRTD 判据（Ratches 1976；Lloyd 1975）；对比度地板即 `MRTD(0)` 与到达传感器对比度的比较。
- **数值核验**：
  - 地板：`ΔT_app = k·NETD/τ_opt = 0.0625/0.8 = 0.078125 K` 时 f_max=0.000；`ΔT_app=0.09 K`（无湍流）→ f_max=6.194，`MRTD(6.194)=0.07200=τ_opt×0.09`（相对残差 <1e−12）；0.12 K→14.524；0.2 K→24.600；
  - 饱和情形：ΔT_app 足够大时 f_max=f_upper=40（RECOG MWIR）；无湍流时 MTF_sys(40)=0.111>需求 0.078（对应 ΔT_app≈1 K），有湍流时因 MTF_turb 退化 f_max 显著减小（由链式计算）；
  - 物理意义：`τ_opt·ΔT_app ≤ k·NETD` 即"到达探测器的对比度不足噪声地板"，与是否临近无关 → 任何距离不可识别。
- **影响量级**：**条件表述修正**（文档与图注统一为 `τ_opt·ΔT_app ≤ k·NETD`；视在温差地板为 78.125 mK 而非 62.5 mK）。代码原已按 τ_opt 折减，数值结果不变。求根网格 600 点 + 线性插值的误差 <1e−3 cyc/mrad。
- **状态**：**已修正**（条件表述）；求根实现**已验证**。

### F23 视在温差与物理界限

- **位置**：`chain.evaluate`、`radiometry.BandContext`
- **公式**：`ΔT_app = t_app(L_t) − t_app(L_b)`（F5 的两式相减）；**严格上界**：`ΔT_app ≤ ΔT_intrinsic = T_t − T_b`（因 ε_t≤1、Planck 单调、t_app 单调）；**小温差线性极限**：`ΔT_app → ε_t·ΔT_intrinsic`（ΔT→0）。
- **原表述**：QA/规范曾写"ΔT_app ≤ ε_t·ΔT_intrinsic"。
- **校准式/表述修正**：严格上界取 `ΔT_intrinsic`；`ε_t·ΔT` 仅作为线性近似（在小温差下误差 <1%）。
- **数值核验**（无大气、τ=1、ε_t=0.90、ε_b=0.95、背景 20 ℃）：

  | ΔT (K) | 2 | 20 | 40 |
  |---|---|---|---|
  | ΔT_app MWIR (K) | 1.805 | 18.435 | 37.406 |
  | ΔT_app LWIR (K) | 1.802 | 18.166 | 36.577 |
  | 线性极限 ε_tΔT (K) | 1.800 | 18.000 | 36.000 |

  ΔT=20 K 时实际 ΔT_app 比线性极限高 2.4%（MWIR）/0.9%（LWIR），来源是 Planck 的凸性；均严格小于 ΔT_intrinsic=20 K。
- **影响量级**：QA 检查"ΔT_app≤ε_t·ΔT"在 ΔT≥20 K 时会以 2–4% 的幅度"失败"；应改为"ΔT_app≤ΔT_intrinsic"（严格）+"小温差 ε_tΔT（±<5%）"。**对 R50 无直接影响**（f_max 由实际 ΔT_app 驱动），属判据表述修正。
- **状态**：**已修正**（表述与 QA 判据）。

## 7 临界求解（`critical.py`）

### F29 临界距离 R50/R90 的对数域求解

- **位置**：`critical.range_for_p / solve_from_curve / r50 / range_summary`（本轮改为求解器实现）
- **原式**：在 120–180 点几何网格 `r ∈ geomspace(0.2/0.5, 250/320)` 上找 `P<0.5` 的首个网格点，再在相邻两点间**线性插值 P 对 R**；搜索边界值直接作为解返回。
- **校准式**：先做共享粗扫描定位括号，再做对数域插值型求根（Illinois/regula falsi 加速）：
  ```
  粗扫描：r ∈ geomspace(0.2, 400) km，N_SCAN=14 点（experiments 复用长表 120 点曲线
          与 5/20/50 km 辅助点作为括号）
  括号内迭代：以 ln R 为坐标做 Illinois (regula falsi) 细化，
          收敛条件 |Δln R| ≤ 1e−3（相对精度 ≈0.1%），MAX_ITER=80
  返回：r_km、censored、p_lo、p_hi、n_iter（新增；供数据质量统计）
  ```
  参数 `r_grid` 仅为向后兼容保留，新求解器不再依赖固定距离网格。
- **物理依据**：P(R) 在物理区间内随距离单调不增（分辨率与大气同时恶化），故存在唯一根；对数域对跨越 3 个数量级的距离轴更均匀，插值型求根比纯二分收敛更快。
- **数值核验**（基线 F16、MWIR）：
  - 求解器 R50=17.76166 km（终版截面下基线 F16），独立 `scipy.optimize.brentq` 参考解 17.761665 km，相对差 **−1.2×10⁻⁷**（远优于 1e−3 的求解精度要求）；解析天花板 18.5043 km、η=0.960；R10 与参考解相对差约 1e−7 量级；
  - 粗网格（geomspace(0.5,320,120)）+ 线性插值误差在解析曲线上为 <0.04%（见 N20），与二分精度相当；**校准的实际价值在截断语义**（F30）：原实现把搜索边界（如 320 km）当作临界距离返回，校准后返回 NaN + `censored` 原因；
  - R90 示例：基线 F16 在 0.2 km 处 P=0.876<0.9，故 R90 不存在，返回 NaN 且 `censored="近距离即不满足（P(0.2 km)=0.876<0.9）"`（旧实现会给边界值）。
- **影响量级**：非截断 R50 变化 <0.1%（远小于其它修正）；截断行从"假边界解"变为"NaN + 原因"，影响临界状态表、相图 NaN 留白与报告措辞。
- **状态**：**已修正**。

### F30 截断（censored）判定语义

- **位置**：`critical.solve_from_curve`、`experiments.summarize_scn`（`censored`/`censored_R10`/`censored_R90`/`censored_Rdet50`/`censored_Rident50` 列）
- **原式/校准式**：
  ```
  若 P(R_min) < P_target（R_min=0.2 km） → R=NaN，censored="近距离即不满足（P(0.2 km)=…<阈值）"
  若 P(R_max) ≥ P_target（R_max=400 km）→ R=NaN，censored="超出搜索上限（P(400 km)=…≥阈值）"
  否则返回求根结果，censored=""
  ```
  数据产品中 `censored` 列记录原因；相图/热力图中 NaN 单元留白并标注；`n_iter` 列记录迭代次数供可复现审计。
- **物理依据**：可识别性判定的边界情形必须与"数值求解失败"区分；把搜索边界当解会伪造"能识别 320/400 km"的结论。
- **数值核验**：构造两种边界工况测试（最近距离失败 / 全区间满足）返回 NaN 与原因；基线 F16 的 R90 即属近界截断（P(0.2 km)=0.876<0.9）；修复后汇总表中所有缺失 R50 行都带非空原因（QA E2）。
- **影响量级**：语义修正；避免把"搜索上限"误读为"可识别距离"，并把"截断"与"数值失败"分开统计。
- **状态**：**已修正**。

### F31 解析分辨率天花板

- **位置**：`critical.analytic_resolution_range`、`critical.spherical_ground_range`
- **原式**：`R_res = f_upper·D_eff/N50`，λ 固定 4.25/10.0 μm；地距换算 `sqrt(R_slant²−Δz²)`（平面，负数取 0）。
- **校准式**：
  ```
  λ_eff  = Σ_λ w(λ)·λ                （F3 权重，取 chain 波段量；随背景温度）
  f_upper= min(f_nyq, f_cut(λ_eff))
  R_res_slant = f_upper·D_eff/N50    （km；m/km≡mrad）
  地距    ：球面关系 cosφ = [(R+zs)²+(R+zt)²−R_slant²]/[2(R+zs)(R+zt)]，R_ground=R_E·φ
  ```
- **物理依据**：忽略大气/湍流的纯几何天花板；TTPF 的 P=0.5 对应 N=N50。
- **数值核验**（RECOG、NVESD 识别 N50=16.5，最终代码实测）：
  - MWIR λ_eff=4.3748 μm → f_cut=68.57 > f_nyq=40 → f_upper=39.999；R_res_slant/地面：悍马 9.789/5.652、F16 19.978/18.504、F22 20.900/19.495、爱国者 38.319/37.454、阿利伯克 206.054/205.778、尼米兹 388.062/387.796 km；
  - LWIR λ_eff=9.8767 μm → f_cut=30.374 < f_nyq=40 → f_upper=30.374；R_res_slant/地面：悍马 7.434 km（**小于平台高度 8 km → 无地平线内地距解**，返回 NaN + `censored="低于几何地平线"`、`horizon_below=True`）、F16 15.171/13.178、F22 15.871/13.978、爱国者 29.099/27.963、阿利伯克 156.472/156.173、尼米兹 294.684/294.417 km；
  - λ_eff 口径：LWIR 用 10.0 μm 会把 f_cut 算成 30.0，低估 1.25%（校准后 30.374）。
- **边界情形（已显式标记）**：当 `R_res_slant ≤ |z_s−z_t|`（目标低于几何地平线 / 平台高度不足以形成该斜距）时，解析天花板返回 `r_ground=NaN` 并给出 `horizon_below=True` 与 `censored="低于几何地平线"`（基线 LWIR 悍马即此情形）；η 与图件自动得到 NaN/留白，不再出现 0 km 假解。
- **影响量级**：解析天花板是 η=R50/R_res 的分母。LWIR 衍射受限目标的 R_res 因 λ_eff 口径修正 **+1.25%**；地平线边界情形已显式标记，避免 LWIR 小目标的 η 被 0 除异常污染。
- **状态**：**已修正**（λ_eff 口径、球面换算、边界建议）。

### F32 临界温差（热交叉盲区）

- **位置**：`critical.delta_t_for_p`（`BandState` 快速通道 + 概率向量化）
- **原式**：在固定 10 km 处，ΔT∈[−60,+80] K 等距 141 点（步长 1 K）扫描，取 `P<0.5` 的连续区间，端点在相邻网格点间**线性插值**。
- **校准式**：
  ```
  参考距离 r_ref = 0.5·R50（R50 截断时取 10 km 并在数据表标注）
  1) 粗扫 ΔT∈[−60,+80] K，步长 0.5 K，判断盲区是否存在并定位连续区间
  2) 细扫 [−10,+10] K，步长 0.02 K；若盲区超出该范围，向粗扫边界附近以 0.5 K 扩展
  3) 对区间两侧 P=P_target 的根在 ΔT 线性域用 Illinois 法细化（DT_TOL_K=1e−4 K）
  输出：dT_low、dT_high、blind_width_K、dT_cross_K（盲区中心）、p_min、dT_at_pmin、censored
  ```
- **物理依据**：P(ΔT) 关于 ΔT **非单调**（目标比背景冷或热都增加对比度），只能在 ΔT_app≈0 附近形成盲区；因此不能用单调二分，必须先扫描定位再对两侧根分别求根。
- **数值核验**（基线 F16、MWIR）：

- **影响量级**：盲区中心位置修正 1.5–3.2 K；端点精度由 1 K 粗扫提升到 1e−4 K 量级（两侧根均收敛）。**对"热交叉盲区"结论的叙事影响最大**（由"偏移的窄带"改为"以 ΔT=0 为中心的窄带"，且其宽度随参考距离显著变化）。
- **状态**：**已修正**。

### F36 敏感性排序的"弹性"定义

- **位置**：`plots.fig16_sensitivity`（数据来自 `experiments` 各扫描表）
- **原式（口号式）**：称各变量对 R50 的影响为"归一化弹性"。
- **校准式（定义澄清）**：本项目实际计算的是**扫描范围内的最大相对变化（fold change）**：
  ```
  E_X = median_{目标} [ max( |R50(X_max)−R50_base|, |R50_base−R50(X_min)| ) / R50_base ]
  ```
  它**不是**局部对数弹性 `dlnR50/dlnX`；在阈值/截断附近局部弹性会发散，因此工程上采用 fold change。解析弹性仅对定义式成立：`D_eff`、`f_max` 弹性 +1，`N50` 弹性 −1（严格）；AOD/PWV/Cn²/NETD 等经 τ 或 ΔT_app 间接、且仅在 MRTD/大气受限段有效。
- **物理依据**：单变量敏感性分析的工程度量；与解析弹性互为补充。
- **数值核验**：解析弹性与几何受限段数值 R50 的标度一致（R50∝D_eff、∝f_max、∝1/N50）；截断行（NaN）剔除后排序在 ±1 名内稳定（最终以图 17 数据为准）。
- **影响量级**：定义澄清，不改变数值；避免把 fold change 误读为局部导数。
- **状态**：**保留近似 / 定义澄清**。
