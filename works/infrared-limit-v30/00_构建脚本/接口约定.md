## 1 大气模块 `atmosphere.py`

### 1.1 波段与大气状态

```python
BANDS = {"MWIR": (3.7, 4.8), "LWIR": (8.0, 12.0)}      # 单位 μm

@dataclass(frozen=True)
class Atmo:
    aod550=0.587; alpha=1.30; pwv_cm=1.28; h_aer_km=1.5
    t0_c=15.0; p0_hpa=1013.0; co2_ppm=420.0; o3_ppb=35.0
    n2o_ppb=332.0; ch4_ppb=1930.0; co_ppb=100.0; cn2=1e-15
    h_wv_km=2.0; lapse_k_per_km=6.5; p_scale_km=8.0   # 末项仅向后兼容、不再用于主廓线
```

### 1.2 光谱网格与截面

- `band_grid(band, step_cm=None) -> ndarray[μm 升序]`：波数域均匀，默认步长 `params.SPECTRAL_STEP_CM = 0.05 cm⁻¹`（HITRAN 1 atm 线宽原生量级，避免漏线）。
- 截面数据：`07_光谱数据/xsect_mwir.npz`、`xsect_lwir.npz`；键 `nu`（cm⁻¹）与 `<SP>_T<温度>_P<气压>`（`H2O/CO2/CH4/O3/N2O/CO`；`SP` 为物种、温度 220/250/280/300 K、气压 1.0/0.6/0.36/0.2 atm，1 atm 时 `_P` 可省略），单位 `cm²/molecule`；生成脚本 `00_构建脚本/build_xsect.py`（可复现，含进度打印与 meta）。
- 逐层双线性插值：温度在 220/250/280/300 K 节点线性插值；气压在 ln p 坐标线性插值（层气压 `p_i` 由 ISO 2533 廓线给出，`p_atm=p_i/1013.25`）；端点箝位。多气压截面对波段平均 τ_band 的影响 <0.02%（六物种终版实测），主要价值在线级光谱保真；六物种均已含四气压节点。
- 丰度口径：每个同位素的天然丰度只折算一次（¹³CO₂ 按约 1.1% 计入线强），禁止重复折算；六物种必须齐全（缺 N₂O/CO 会使 MWIR 窗内强吸收带缺失、τ_band 虚高）。
- 弱吸收物种 O₃/N₂O/CO 若无多气压截面节点，使用最近气压节点并在 `source`/报告中声明（贡献 <1%）；干气体按混合比合并为等效吸收体（线性可加）。

### 1.3 主接口 `spectral_state`

```python
spectral_state(atmo, band, r_ground_km, z_target_m=0.0, z_sensor_m=8000.0,
               n_layers=None, with_components=True) -> dict
```
`with_components=False` 时跳过 `tau_comp` 分解（`chain.band_quantities` 链路评估默认，节省时间与内存）；调试/QA 用默认 `True`。
返回字段：

| 字段 | 含义 |
|---|---|
| `lam_um` | 波长 μm 升序 |
| `tau_lam` | 斜程光谱透过率（含气溶胶 + 气体吸收 + 分子散射） |
| `l_path_lam` | 斜程路径光谱辐亮度 W/(m²·sr·μm) |
| `tau_band` | 对比度加权波段透过率 |
| `l_path` | 波段平均路径辐亮度 W/(m²·sr) |
| `tau_comp` | `{H2O,CO2,CH4,O3,N2O,CO,AER,MOL}` 各自透过率数组（乘积 ≈ τ_lam；仅 `with_components=True` 时给出） |
| `lam_eff` | 对比度加权等效波长 μm |
| `r_slant_km` | 球面弦长（斜距）km |
| `r_ground_km` | 地面距离 km |
| `n_layers` | 分层数（默认 `params.N_LAYERS = 40`） |
| `source` | 截面数据来源（含缺失物种说明） |
| `modtran_equiv_vis_km` | 等效能见度（=3.912/β550，仅供核对） |

物理口径（校准依据见 `06_校验/公式校准报告.md`）：ISO 2533:1975 分层温压；球面地球（`R_E=6371 km`，不含折射）弦长分层、层高取层中点到地心距离减半径；气溶胶 Ångström 外消光（不含相函数/多次散射）；水汽指数廓线按 PWV 归一；Rayleigh 垂直光学厚度 `0.008735·λ^-4.08` 除以 8 km 标高；气体吸收按层温/层压双线性插值（温度线性、气压 ln p 线性）；路径辐射用累计光学厚度的发射-吸收积分。
数值实现：层数组用 `(Nλ, 层)` 连续布局，逐层光学厚度以 BLAS 矩阵乘计算；τ 重计算阶段用 float32（累计光学厚度 ≤10² 时相对精度 ~1e-7），输出转回 float64。

## 2 辐射度量 `radiometry.py`

```python
planck(lam_um, T_K)                  # W/(m²·sr·μm)，B(10 μm,300 K)=9.924033
d_planck_dT(lam_um, T_K)             # W/(m²·sr·μm·K)，与中心差分一致到 1e-10
band_weights(lam_um, T_ref=293.15)   # 对比度权重 w∝dB/dT·Δλ，Σw=1（参考温度取背景温度）
get_band_context(band, lam_um, t_ref_k=293.15) -> BandContext  # 按（波段,网格,T_ref）缓存
```

`BandContext` 方法：

| 方法 | 说明 |
|---|---|
| `band_average(spectral)` | `Σ w·(光谱量)` |
| `t_app(L_band)` | 波段辐亮度 → 等效黑体温度 K（LUT 反演） |
| `blackbody_band(T_K)` | 黑体波段辐亮度 |
| `surface_radiance(t_s, eps, tau_lam, l_path_lam, t_amb)` | **正式链路**：`L=Σw{[εB(λ,T_s)+(1−ε)B(λ,T_amb)]τ+L_path}` |
| `contrast_radiance(t_t, t_b, eps_t, tau_lam)` | 解析等价式 `ΔL=ε_tΣw[B(T_t)−B(T_b)]τ`（交叉校核用） |

## 5 链式评估 `chain.py`

```python
@dataclass(frozen=True)
class Scenario:
    target_key="F16"; target_temp_c=40.0; bg_temp_c=20.0
    aod550=0.587; alpha=1.30; pwv_cm=1.28; cn2=1e-15
    size_rule="sqrt_area"; n50_set="NVESD"; eps_t=None
    sensor: Sensor = make_sensor("MWIR")

band_quantities(scn, r_ground_km) -> (L_t, L_b, S_t, S_b, L_path, t_app_t, t_app_b,
                                      dT_app, lam_eff, tau_band, r_slant, r_ground)
evaluate(scn, r_ground_km) -> dict      # 单点全链路，见下
baseline_scenario(band="MWIR", target_key="F16", size_rule="sqrt_area",
                  n50_set="NVESD", preset="RECOG") -> Scenario
```

`evaluate` 返回字段（长表列的基础）：`r_ground_km, r_slant_km, band, target, target_name, kind, size_rule, d_eff_m, target_temp_c, bg_temp_c, dT_intrinsic_K, aod550, alpha, pwv_cm, cn2, eps_t, eps_b, tau_band, l_path, lam_eff, L_target, L_bg, t_app_t_K, t_app_b_K, dT_app_K, r0_m, f_max, theta_mrad, n_cycles, N50_set, N50_rec, P_detect, P_rec, P_ident, D_m, netd_k, f_nyq, ifov_mrad`。

辐亮度口径：`L_t=ε_t·S_t+(1−ε_t)·S_b+L_path`，`L_b=S_b+L_path`（`S=Σw·B(T)·τ`），相减严格得 `ΔL=ε_t·Σw[B(T_t)−B(T_b)]τ`，热交叉严格在 ΔT=0。
