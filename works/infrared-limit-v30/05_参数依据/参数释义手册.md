# 参数释义手册

> **配套文档**：《参数依据说明》、《参数依据登记表》、正式仿真报告与《公式校准报告》。
> **用途**：回答一个问题——**报告里出现的每个参数，物理上是什么、为什么取这个值、它影响哪个结果**。
> **参数真值源**：`04_模型代码/irrecog/params.py`；登记表由 `params.registry_rows()` 自动导出，任何取值以该文件为准。
> **口径**：本手册中的"影响/敏感性"为半定量工程估计，最终以 `03_数据` 的 OFAT 结果与 `06_校验/公式校准报告.md` 的数值为准。

## 0 阅读说明

- 依据四分类（报告中每个参数都标注其一）：
  - **软件实测 SYS**：从 XGGDCOSSim2 安装目录的配置/模型文件解析得到，可直接溯源；
  - **文献 LIT**：给出文献出处（DOI/标准号/报告号/教材）；
  - **推导 DER**：由其他已登记参数按物理公式推出，可逐步复算；
  - **设定 SET**：无直接出处但工程合理；必须写明理由、影响量级与如何被实测替换。
- 置信度：高 / 中 / 低。低置信度项在报告不确定度章节与《争议与不确定清单》单独登记。
- 单位约定：波长 μm、温度 K（输入可用 ℃）、频率 cycles/mrad（角频率）、辐亮度 W/(m²·sr)、光谱辐亮度 W/(m²·sr·μm)、距离 km（斜距/地距区分）、`m/km ≡ mrad`。

## 1 参数如何串起来：一条公式链

```
① 光谱大气：dτ(λ,i) = [β_aer(λ,h_i)+β_Mol(λ,h_i)+Σ_g σ_g(λ,T_i,p_i)·N_g(h_i)]·Δs_i
   τ(λ)=exp(−Σ_i dτ)，L_path(λ)=Σ_i B(λ,T_i)[e^(−τ_before,i)−e^(−τ_after,i)]
② 波段加权：w(λ) ∝ dB/dT(λ,T_ref)·Δλ（T_ref 取背景温度）；τ_band=Σwτ，L_path=Σw·L_path(λ)
③ 辐亮度与视在温差：L_t=Σw{[ε_tB(T_t)+(1−ε_t)B(T_b)]τ+L_path}；L_b=Σw[B(T_b)τ+L_path]
   ΔT_app=t_app(L_t)−t_app(L_b)（LUT 反演；ΔL 严格化简为 ε_t·ΔB）
④ MTF 链：MTF_sys = 衍射 × 探测器sinc × 抖动 × 湍流 × 电子学
   MRTD(f)=k·NETD/MTF_sys(f)；f_max 由 MRTD(f_max)=τ_opt·|ΔT_app| 求根，上限 min(f_nyq, f_cut)
⑤ 周期数与概率：N=f_max·D_eff/r_slant；P(N)=(N/N50)^E/(1+(N/N50)^E)
⑥ 临界状态：R50: P=0.5；R_res=f_upper·D_eff/N50；临界 AOD/Cn²/口径/NETD 与热交叉盲区用求解器反解
```

## 3 辐射度量基础

| 符号 | 参数 | 取值 | 单位 | 含义 | 依据 | 置信度 |
|---|---|---|---|---|---|---|
| B(λ,T) | 普朗克光谱辐亮度 | 按 Planck 定律 | W/(m²·sr·μm) | 整条链的起点：目标、背景、大气路径的辐射都由它给出；**B(10 μm,300 K)=9.924** | 文献 | 高 |
| dB/dT | 普朗克温度导数 | B·x·eˣ/(eˣ−1)/T，x=c2/(λT) | W/(m²·sr·μm·K) | 小温差对比度的线性系数，也是波段权重与"视在温度"反演的物理基础 | 文献 | 高 |
| t_app | 视在温度反演 | 由波段辐亮度经 Planck LUT 反演 | K | 到达传感器后"看起来"的等效黑体温度；ΔT_app 是 MRTD 判据直接比较的量 | 推导 | 高 |
| ε_t / ε_b | 发射率 | 目标 0.90 / 背景 0.95 | — | 目标与背景自身发射能力；不透明表面反射项 (1−ε)B(T_b) 计入后，对比度严格化简为 ε_t·ΔB，热交叉严格在 ΔT=0 | 文献 | 中 |

- `D_eff=√(max(W,L)·H)` 为主口径（侧向投影等效方目标，与 TTP 的 √A_t 思路一致）；`D_max=max(W,L,H)` 为备口径。口径切换使 R50 按 D_max/D_eff=1.26–2.16 倍变化。
- 包围盒由 OSG 顶点计算、按"1 单位≈1 m"解释（用公开尺寸交叉验证，偏差 ≤3%）；**未做几何标定**，是主要不确定度之一；爱国者模型疑为多车组合，置信度低。
- 目标高度 z 用于斜距计算（空中目标 500 m、海面 0 m、地面 10 m）。

|---|---|---|
| R50 / R90 | 识别概率 50% / 90% 对应的地面距离 | 临界距离主指标；截断时返回 NaN 并注明原因 |
| R_res | 分辨率天花板：忽略大气/湍流、仅由采样/衍射与判据决定的最远距离 | R_res=f_upper·D_eff/N50（λ_eff 与球面换算） |
| η = R50/R_res | 折减比 | ≈1 表示分辨率锁死；明显小于 1 表示大气/湍流折减主导 |
| τ @ R50 | 临界距离处的波段透过率 | 链路诊断量 |
| ΔT_app @ R50 | 临界距离处的视在温差 | 链路诊断量 |
| N @ R50 | 临界距离处目标上的周期数 | 应≈N50，内部自洽校核 |
| 临界 AOD / Cn² | 固定其余条件使 P=0.5 的气溶胶光学厚度 / 湍流强度 | 边界情形标注 censored |
| 临界口径 / NETD | 固定距离下使 P=0.5 的传感器参数 | 边界情形标注 censored |
| 热交叉盲区 | 使 P<0.5 的固有温差连续区间 | 中心在 ΔT≈0，宽度随参考距离变化 |
| 敏感性排序 | 各单变量在扫描范围内对 R50 的相对影响（fold change） | 不是局部对数弹性；详见公式校准报告 F36 |

## 11 双轨口径与内部一致性

- **N50 双轨**：NVESD/TTP（4.0/16.5/26.6 cycles）为主口径；经典 Johnson（2/8/16 线对）为备口径。两套相差约 2 倍，报告并列、不合并。
- **尺寸双轨**：主口径 D_eff=√(max(W,L)·H)；备口径 D_max=max(W,L,H)；口径切换 R50 变化 1.26–2.16 倍。
- **能见度常数**：Koschmieder V=3.912/β（2% 对比度阈值）；另有 3.0（5% 阈值）口径，引用必须绑定。
- **采样与衍射**：MWIR 识别通道 Nyquist 40 < 衍射截止 68.6（采样受限）；LWIR 衍射截止 30.4 < Nyquist 40（衍射受限）。
- **热交叉**：反射项计入后 ΔT_app(ΔT=0) 严格为 0，盲区中心在 ΔT=0；校准前实现的双 ε 不对称会引入数 K 的伪偏置。
