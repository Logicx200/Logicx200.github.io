# 参数依据说明

> **用途**：为本模型**每一个参数**给出取值、依据类别、可查证来源、适用范围、敏感性，以及如何被实测替换。报告与图件只允许引用参数真值源中的数值。
> **参数真值源**：`04_模型代码/irrecog/params.py`（唯一真值源，每个参数带 `basis` 标记）。
> **配套文件**：
> - `05_参数依据/参数依据登记表.csv`：`params.registry_rows()` 导出的机器可读登记表（核心参数逐项含类别、依据说明、来源、置信度、影响方向）；修改 `params.py` 后重跑 `python -m irrecog.params` 即可再生。
> - `05_参数依据/争议与不确定清单.md`：建模不确定性的展开讨论。
> - `05_参数依据/参数释义手册.md`：面向阅读的逐参数释义（物理含义、为什么取这个值、影响哪个结果）。
> - `06_校验/公式校准报告.md`：全部公式的"原式 → 校准式 → 依据 → 数值核验 → 影响量级"。
> **口径**：文中"±20% → R50 如何变"是用于设计敏感性实验的半定量工程估计，最终数值以 `03_数据` 的 OFAT 结果为准。

## 0 依据分类与置信度

| 类别 | 含义 | 典型例子 |
|---|---|---|
| **软件实测 SYS** | 从 XGGDCOSSim2 安装目录的配置/模型文件解析得到 | 波段边界、FOV、像元数、帧频、平台高度、俯仰、目标包围盒、背景温度、默认气象（温度/湿度/气压/能见度） |
| **文献 LIT** | 有可查证 DOI/标准号/报告号出处 | N50 判据、ISO 2533、Koschmieder、Ångström、Fried、HITRAN2020、Eck 气溶胶分类、Salisbury 发射率 |
| **推导 DER** | 由实测/文献值经明确的物理或几何关系推得，可逐步复算 | IFOV=FOV/N、f=p/IFOV、D=f/F#、AOD550、PWV、D_eff、λ_eff、r0、R_res |
| **设定 SET** | 无直接出处、由工程判断给定；必须写明"为什么合理 + 影响多大 + 如何被实测替换" | NETD、τ_opt、抖动、MRTD 系数 k、发射率、Cn²、痕量气体本底、指数标高 |

**置信度**：高 = 可直接引用（软件字段 / 多源一致 / 推导无争议）；中 = 单源或依赖设定链一环；低 = 纯工程设定且对结果有可观影响（已逐项登记）。

**来源编号约定**：`[n]` 对应本文 §11 参考文献编号；软件来源统一写"软件 DefaultPlanFile / Config.ini / ModelData"，与 `软件参数提取` 解析文件同源。

## 1 模型链与参数通道

### 1.1 链式关系

```
输入：软件实测目标包围盒 + 背景温度 + 两档传感器 + 默认气象（AOD/PWV 由能见度与温湿推导）
大气：HITRAN 逐线吸收（多温度 × 多气压）+ 气溶胶 Ångström 消光 + 分子散射
      → 斜程 τ(λ)、L_path(λ)（球面弦长几何、ISO 2533 廓线）
辐射：L_t = Σw{[ε_t·B(T_t)+(1−ε_t)·B(T_b)]·τ + L_path}；L_b = Σw[B(T_b)·τ + L_path]
      → ΔT_app = t_app(L_t) − t_app(L_b)（对比度加权、权重参考温度=背景温度）
传感器：IFOV/f_nyq、MTF 链、NETD → MRTD(f)=k·NETD/MTF(f) → f_max（Nyquist/衍射/对比度三重限）
判据：N = f_max·D_eff/r_slant（m/km≡mrad）；P(N)=(N/N50)^E/(1+(N/N50)^E)
临界：R50/R90、解析天花板、热交叉盲区、临界 AOD/Cn²/口径/NETD（对数域求解）
```

### 1.2 三条参数通道与弹性

R50 只通过三条通道受参数影响：

| 通道 | 参数 | 弹性 dlnR50/dlnX | 说明 |
|---|---|---|---|
| ① 目标尺寸 | D_eff | **+1** | 尺寸 ±20% → R50 ±20%（严格线性） |
| ② 系统分辨率 | f_max（受 f_nyq / 衍射 / MRTD 限） | **+1** | f_max ±20% → R50 ±20% |
| ③ 判据 | N50 | **−1** | N50 ±20% → R50 ∓16.7%～+25%（严格反比） |
| 其他 | AOD/α/PWV/NETD/k/τ_opt/ΔT/ε/Cn² 等 | 经 ② 或 ΔT_app 间接 | 仅当系统处于 MRTD/大气受限段时有效；几何受限段影响趋近 0 |

### 1.3 两段式行为（用于解释敏感性）

- **几何受限段**（近—中距）：ΔT_app ≫ MRTD ⇒ f_max≈f_nyq ⇒ R50≈f_nyq·D_eff/N50，只对 D_eff、f_nyq、N50 敏感；
- **MRTD/大气受限段**（远距或大目标）：ΔT_app 衰减到与 MRTD 同量级 ⇒ f_max 由 MRTD 决定 ⇒ 对 NETD、k、τ、PWV、ΔT、ε、Cn² 敏感。

| MWIR 波段 | 3.7–4.8 μm | SYS | 模型 Config.ini 波段字段；位于 IR II 窗（2.7–4.3、4.5–5.2 μm）内 |
| LWIR 波段 | 8.0–12.0 μm | SYS | 目标模型 Config.ini 的波长范围；位于 IR III 窗（8–14 μm）内 |
| 光谱网格步长 | 0.05 cm⁻¹（波数域均匀） | DER | HITRAN 1 atm 线宽原生量级 0.05–0.1 cm⁻¹；过粗漏线。收敛性校核见 `06_校验/光谱校验` |
| 波段对比度权重 | w(λ) ∝ dB/dT(λ,T_ref)·Δλ，Σw=1 | DER | 小温差下目标-背景辐亮度差 ∝ dB/dT；红外波段平均标准做法（Lloyd 1975 / Ratches 1976） |
| 权重参考温度 T_ref | 293.15 K（场景背景温度，默认 20 ℃） | DER | 权重应与场景热状态自洽；由场景背景温度覆盖。λ_eff 对 T_ref 不敏感（±10 K → λ_eff 漂移 <0.02 μm） |
| 有效波长 λ_eff | MWIR ≈ 4.375 μm；LWIR ≈ 9.877 μm | DER | 按对比度权重加权（Σw·λ）；用于 f_cut=D/λ_eff 与气溶胶外推 |
| 光谱响应 | 平坦硬边界（无 R(λ)） | SET/缺口 | 软件无光谱响应函数；有实测 R(λ) 后可令 w=R(λ)·dB/dT 替换 |

**影响**：λ_eff 每变化 0.1 μm，气溶胶消光约变 1.3–2.9%（α 相关）；LWIR 衍射截止 f_cut ∝ 1/λ_eff，λ_eff 变化 1% 即 R_res 同向变化约 1%。**如何被实测替换**：用实测光谱响应与波段边界替代平坦假设。

### 3.2 自洽性与合理性

- **几何自洽**：FOV=N_px·p/f、IFOV=p/f、D=f/F# 三式在 0.2% 内闭合；
- **工程合理性**：1024×768 @ 15 μm pitch、F/4、NETD 25 mK 是当代制冷 MWIR 识别通道的典型组合；搜索通道保留软件实测显示口径用于工况对齐；
- **受限类型**：MWIR 识别通道 f_nyq=40 < f_cut=68.6 → **采样受限**；LWIR 时 f_cut=30.4 < f_nyq=40 → **衍射受限**（长波更适合探测、不自动更适合识别的根源）；
- **设定值影响**：NETD、τ_opt、抖动、k 均为设定（已登记低/中置信），报告中通过 NETD/口径/IFOV 单变量扫描与不确定度章节说明。

### 3.3 相关公式（详见公式校准报告 F15–F23）

```
IFOV=FOV_h/N_h；f=p/IFOV；D=f/F#；f_nyq=1/(2·IFOV)；f_cut=D/λ
MTF_sys = Airy(ν=f/f_cut) × sinc(π f·IFOV) × exp(−2π²σ_j²f²)
          × exp[−3.44(λ f·1e3/r0)^(5/3)] × 1/(1+(f/f_elec)²)
MRTD(f)=k·NETD/MTF_sys(f)；f_max 由 MRTD(f)=τ_opt·|ΔT_app| 求根，上限 min(f_nyq,f_cut)
对比度地板：τ_opt·ΔT_app ≤ k·NETD（即 ΔT_app ≤ 78.125 mK）时 f_max=0
```

## 5 目标、背景与热状态

### 5.1 六个软件实测目标（`TARGETS`，OSG 顶点包围盒，1 单位 = 1 m）

| key | 名称 | 类别 | 包围盒 W×L×H (m) | z (m) | D_eff=√(max(W,L)·H) (m) | D_max (m) |
|---|---|---|---|---|---|---|
| F16 | F16 战斗机 | 空中 | 9.660×14.848×4.574 | 500 | 8.241 | 14.848 |
| F22 | F22 战斗机 | 空中 | 13.498×18.601×3.996 | 500 | 8.622 | 18.601 |
| NIMITZ | 尼米兹级航母 | 海面 | 85.730×340.656×75.223 | 0 | 160.079 | 340.656 |
| ALBK | 阿利伯克级驱逐舰 | 海面 | 20.273×151.324×47.744 | 0 | 85.000 | 151.324 |
| HM | 悍马车 | 地面 | 2.814×5.091×3.203 | 10 | 4.038 | 5.091 |
| AGZFSC | 爱国者导弹发射车 | 地面 | 10.237×22.567×11.072 | 10 | 15.807 | 22.567 |

- **尺寸口径**：主口径 `D_eff=√(max(W,L)·H)`（侧向投影等效方目标，与 TTP 的 √A_t 思路一致）；备口径 `D_max=max(W,L,H)` 作敏感性对照。口径切换使 R50 按 D_max/D_eff=1.26–2.16 倍变化。
- **单位假设**：`.osg` 无单位标注；用 F16/F22/驱逐舰公开尺寸交叉验证（偏差 ≤3%），按 1 单位≈1 m 解释；**包围盒未做几何标定**，是主要不确定度之一（爱国者模型疑为多车组合，置信度低）。
- **发射率**：目标 ε_t=0.90、背景 ε_b=0.95（金属涂装/植被土壤典型值，[15][16]）；不透明表面按基尔霍夫定律补反射项 `(1−ε)·B(T_b)`，对比度严格化简为 `ε_t·ΔB`（热交叉严格在 ΔT=0）。
- **目标热状态**：软件 Config.ini 温度范围 0–60 ℃，取 20/40/60 ℃ 三档；基线目标 40 ℃、背景 20 ℃（ΔT=20 K）。
- **背景**：软件唯一实际背景模型"与那国岛"，环境温度 20 ℃、温度范围 0–60 ℃；背景温度均一假设（已列为不确定度）。

## 6 大气参数

### 6.1 基线自洽推导链（软件默认气象 → 物理参数）

```
软件默认：T0=15 ℃、RH=50%、p0=1013 hPa、能见度 V=10 km、气溶胶=干净大陆、标准大气
① 能见度 → 550 nm 消光：β550=3.912/V=0.3912 km⁻¹            [Koschmieder + WMO-No.8]
② 地面消光 → 柱 AOD：AOD550=β550·H_aer=0.3912×1.5=0.587      [指数廓线柱积分]
③ 水汽：e_s(15 ℃)=17.04 hPa → e=0.5e_s=8.52 hPa → ρ_v=6.41 g/m³
        PWV=ρ_v·H_wv=6.41×2000 g/m²=1.28 cm                   [Magnus + 指数水汽廓线]
④ 等效能见度回算：V_eq=3.912/β550=10.0 km（与软件默认一致 ⇒ 自洽）
```

| 数据文件 | `07_光谱数据/xsect_mwir.npz`、`xsect_lwir.npz`（键 `<SP>_T<温度>_P<气压>`，cm²/molecule） | 生成 | 由 `00_构建脚本/build_xsect.py` 可复现生成 |

### 6.7 湍流

| 参数 | 取值 | 类别 | 说明 |
|---|---|---|---|
| Cn²（基线） | 1×10⁻¹⁵ m^(−2/3) | SET/文献 | 弱—中等湍流；分级 1e−17…1e−12（1e−13 极强）；ITU-R P.1817-1 只给定性描述、无 Cn² 数值表 [18] |
| Fried 直径 r0 | r0=(0.423 k²Cn²L)^(−3/5) | LIT | Fried 1966 [7]；λ=4.375 μm、Cn²=1e−15、L=20 km → r0≈0.18 m |
| 湍流 MTF | exp[−3.44(λf/r0)^{5/3}] | LIT | 长曝光、均匀 Cn²、无限外尺度（近似已登记） |

### 6.8 大气缺口

- **水汽连续吸收 MT_CKD 未显式建模**：LWIR 透过率偏高 2–8%（高 PWV 时 >10%）→ LWIR 识别距离偏乐观；单向系统偏差，已在不确定度章节声明。
- **气溶胶相函数/多次散射未建模**：白天路径辐亮度低估 5–15%（夜间为 0）。
- **大气折射未建模**：低仰角几何误差 <1%，已登记。

## 10 主要不确定度与缺口（登记）

| 项 | 影响方向/量级 | 处理 |
|---|---|---|
| 判据口径（NVESD vs Johnson） | R50 相差约 2.06 倍 | 双口径并列输出，不合并 |
| 目标包围盒未几何标定 | 个别目标 R50 可偏大 3–5 倍（爱国者最可疑） | 双尺寸口径 + 登记低置信度 |
| MRTD 系数 k=2.5 | k±20% → R50 ∓10–20%（MRTD 段） | 登记设定值，待观察者实验标定 |
| 水汽连续吸收 MT_CKD 未含 | LWIR τ 偏高 2–8% → R50 偏乐观 | 声明单向偏差；后续接 MT_CKD |
| 气溶胶相函数/多次散射未含 | 白天路径辐亮度低估 5–15% | 声明；夜间影响为 0 |
| 弱吸收物种缺气压节点 | O₃/N₂O/CO 截面按最近气压 | 贡献 <1%，报告声明 |
| 光谱截面数据完整性/丰度口径 | 早期数据缺物种、丰度重复折算使 MWIR τ_band 明显偏高（旧数据 0.6178 → 终版 0.3156，−48.9%；LWIR 0.8142 → 0.7126） | 已修正（终版实测） |
| 灰体发射率假设 | 光谱波动使信号偏 5–15% | 登记；可用光谱库 ε(λ) 替换 |
| 背景温度均一 | ΔT 误差 → R50 ±20–30% | 登记；可用地表温度场替换 |
| 传感器辐射参数为设定组合 | 绝对距离依赖设定值 | 逐项登记，给出敏感性扫描 |
| Cn² 均匀、长曝光、无限外尺度 | 强湍流/低仰角工况偏差 | 登记近似；可用实测 Cn²(h)/r0 替换 |
