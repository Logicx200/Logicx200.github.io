针对 XGGDCOSSim2 光电环境仿真软件的一组自动化与逆向脚本：用窗口截图 + 图像分析操作界面（加载想定、预览窗、仿真启停、红外帧导出），改写 ModelDatabase.xml 注入中波红外传感器并生成 IR 想定，还以与那国机场跑道为基准校核可见光预览窗的几何/分辨率链（实测 GSD 偏差 0.7%）。另整理 V3.0 参数释义手册、参数挖潜笔记与二进制资源扫描记录。

要点

  • 截图 + win32 窗口定位的 UI 自动化流程
  • 注入中波红外传感器并生成 IR 想定
  • 跑道几何/GSD 校核：实测偏差 0.7%
