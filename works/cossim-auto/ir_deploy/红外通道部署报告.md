## 失败点（关键）

- **所有红外帧全黑**（min=max=0），与可见光通道形成对照（可见光预览窗图像正常，非零像素 97.3%）。
- 遥测 CSV 显示辐射链路未计算：`大气透过率=1.000`、`路径辐射=0`、`背景辐射=0`、`太阳辐射=0`。
- 日志无 IR/热特性相关报错，说明不是配置错误，而是**数据缺失**。

## 根因

想定 `WeatherParam` 中三个 MODTRAN 相关文件路径均为空：

```
TranRadAtmModelFile  = ""   # 辐射传输计算大气卡片文件（MODTRAN tape5）
LaserAtmModelFile    = ""   # 激光透过率计算大气卡片文件
BandAtmTranRadFile   = ""   # 波段1大气辐射传输数据文件（MODTRAN 输出）
Band2AtmTranRadFile  = ""
```

`AtmMode` 枚举只提供标准大气/AFGL 五种模式与“自定义大气数据”，没有内置辐射传输求解器；
因此没有这两类数据文件时，波段辐亮度恒为 0 → 红外图像必然全黑。
这与 V2.1 报告“RT 大气卡片未交付”的结论一致，现已在红外传感器注入后得到直接验证。

## 结论与建议

- 红外通道是否可用，**取决于能否拿到软件配套的 MODTRAN 大气卡片与波段辐射数据文件**，而不是配置或传感器模型问题。
- 若厂家能提供上述数据文件，本报告的注入方案（传感器模型 + 波段 + 插件开关）可直接复用，改动量仅 2 个文件。
- 若拿不到，则该软件在本机只能做可见光成像仿真；红外部分只能用本项目 V3.0 的 HITRAN 自建链路。
