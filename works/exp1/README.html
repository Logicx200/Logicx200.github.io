EXP-1 可学性分析

空间碎片清除目标函数的 AI 可预测性实验

针对卫星解体碎片清除轨道设计问题做的 EXP-1 可学性实验：按赛题动力学（中心引力 + J2，碎片用一阶长期根数漂移）实现母器与碎片演化，评估「有解集」比例、相关长度、代理模型可预测性与廉价几何 gate 的效率。run_exp1.py 跑 E1–E5 五项实验并输出 results.json 与 4 张图，结论包括判据对时间步长不敏感、聚合标签高度可学。

要点

  • E1–E5：数值可信性 / 结构 / 相关长度 / 可预测性 / 预算效率
  • 代理模型对聚合标签 R² ≈ 0.79–0.88
  • 同预算下几何 gate 事件密度 1.8× 随机采样
