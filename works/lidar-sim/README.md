# lidar-sim —— 最小可运行的激光雷达点云仿真

只依赖 `numpy`（画图额外需要 `matplotlib`），用几百行代码演示一帧点云是怎么「算」出来的。

## 运行

```bash
cd lidar-sim
python run.py
```

输出到 `outputs/`：

| 文件 | 内容 |
|------|------|
| `pointcloud.csv` | 点云，每行 `x,y,z,intensity,is_mixed` |
| `fig_3d.png` | 三维点云（按距离着色，红=混合像素）+ 俯视图（按强度着色，青×=混合像素） |
| `fig_range_image.png` | 距离图 + 强度图（像相机一样看雷达） |

## 这个仿真实现了什么

1. **射线求交**：`lidar_sim.py` 里的 `ray_box_hit`（ray-AABB slab 法）和
   `ray_ground_hit`（无限平面），全部 numpy 向量化，一条指令同时算几万条射线。
2. **光束足迹 + 混合像素**：每个扫描方向用 5×5 束子射线模拟有限发散角的光斑。
   当子射线命中不同距离的面（如物体边缘 vs 背景墙）时，取**功率加权平均距离**，
   这正是真实雷达「边缘悬浮点」的来源。这类点在图里标红/标青×。
3. **测距噪声**：高斯噪声 `σ = σ0 + k·R`，远端信噪比低、噪声更大。
4. **强度 / 丢点**：`强度 = 反射率 × cos(入射角) × (R_ref/R)² × 斑点`；
   强度过低（黑色目标、镜面、超量程）→ 丢点，形成点云里的「黑洞」。

## 关键文件

- `lidar_sim.py`：核心库（场景、求交、传感器模型、单帧仿真）。
- `run.py`：示例场景 + 可视化 + 保存 CSV。

## 想改点什么

- 场景在 `run.py` 的 `build_scene()`：加一个 `ls.AABB(lo, hi, reflectance)` 就是加一个盒子，
  把 `reflectance` 调低（如 0.05）就能看到丢点黑洞。
- 传感器在 `run.py` 的 `LidarSensor(...)`：改 `beam_div`（光斑大小）看混合像素变多变少，
  改 `range_noise` 看噪声，改 `H/V` 看分辨率。
- 混合像素判据是 `simulate_frame(..., mixed_threshold=0.5)` 里的距离极差阈值。

> 想理解背后的物理，见对话里的《激光雷达仿真原理讲解》：飞行时间测距、
> LIDAR 测距方程（扩展目标 `1/R²`、点目标 `1/R⁴`）、三级保真度模型等。
