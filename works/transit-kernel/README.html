凌日 / 凌月几何内核

飞机穿越日月的精确判定库

实验脚本 · 杂项3 个文件44.9 KB天文几何Meeus凌日零依赖
← 返回作品列表GitHub 源码 ↗

零依赖纯 ES module 的凌日/凌月几何内核：处理儒略日与 TT-UTC 时标，按 Meeus 算法算太阳与月球视位置、月球地面视差与 Bennett 大气折射，还包含带机身姿态三维投影的飞机方向与角尺寸，最后用时间扫描 + 二分求极小值做穿越判定。verify-kernel.js 按权威算例、几何恒等式、端到端三层自检。

要点

  • 太阳/月球视位置 + 视差 + 大气折射
  • 带姿态的飞机角尺寸与穿越判定
  • verify-kernel.js 三层自检，零依赖 ES module

技术栈

JavaScript Node.js
