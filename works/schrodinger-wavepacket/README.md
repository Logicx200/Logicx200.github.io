# 含时薛定谔方程：波包演化

一维含时薛定谔方程（TDSE）的数值模拟脚本：高斯波包撞击矩形势垒后的透射/反射演化，含自定义远场开放边界（吸收层）抑制边界反射伪影，最后导出动画。

## 怎么跑
- `wavepacket.py`：完整脚本（原文件 `F:\123123.py`，内容未做任何修改）；
- 依赖：numpy、scipy、matplotlib（导出 GIF 需 Pillow）；运行 `python wavepacket.py` 会开启动画并尝试导出 GIF；
- 参数：ħ=1、m=0.5、势垒 V0=6.0 / 宽 2.0、空间域 [-60,60]（6000 点）、Δt=0.001、t_max=15。
