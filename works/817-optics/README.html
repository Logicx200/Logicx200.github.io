1. 为什么要用 Python 学光学

考研复习的三大痛点，仿真恰好都能治：

痛点传统做法仿真做法
公式记混反复抄写、靠"感觉"让程序算一遍，与课本数值对不上就是记错了
物理图像模糊盯着一张静态插图想象调参数看曲线怎么变（这就是"参数地图"）
不会估数量级算完了也不知道对不对用数量级是否合理反向检验自己的答案
抽象概念（相位、频谱、光瞳）死记定义画出来看，反而不用背

但要先说清楚边界：

  • 仿真不能替代推导。考研大题考的是"从公式 A 推到结果 B"，程序只能验证结果。
  • 仿真不能替代做题。它的定位是校验器和直觉来源。
  • 本指南的建议比例：推导与做题 70%，仿真 30%。仿真省下来的时间应该还给刷题。

4. 四个必须会的 Python 工具

4.1 numpy：广播与网格

光学仿真 90% 的工作量是「在一个网格上算一个公式」。

import numpy as np
x = np.linspace(-1e-3, 1e-3, 2000)          # 一维屏坐标
X, Y = np.meshgrid(x, x)                     # 二维网格
r = np.hypot(X, Y)                           # 对每个点求半径（广播）

记住三条：

  1. 一切用数组，不要写循环 —— 循环慢 100 倍，且容易写错。
  2. np.sinc(x) 的定义是 $\sin(\pi x)/(\pi x)$，带 π！所以 $\sin\beta/\beta = \texttt{np.sinc}(\beta/\pi)$。这是最容易踩的坑。
  3. 复数就是光学：np.abs(U)**2 得强度，np.angle(U) 得相位。

4.2 matplotlib：三行出图

import matplotlib; matplotlib.use("Agg")   # 只存图不弹窗，脚本里更快
import matplotlib.pyplot as plt

axes[0, 0].plot(x*1e3, I)

4.3 sympy：符号推导（第 7.1 节的主角）

用来验证你自己推的解析式，而不是代替你推。

import sympy as sp
n1, n2, i, t = sp.symbols("n1 n2 i t", positive=True)
# 斯涅尔定律 + 菲涅耳 rp，验证布儒斯特角
rp = (n2*sp.cos(i) - n1*sp.cos(t)) / (n2*sp.cos(i) + n1*sp.cos(t))
sol = sp.solve(sp.Eq(n1*sp.sin(i), n2*sp.sin(t)), t)[0]
print(sp.simplify(rp.subs(t, sol)))        # 观察什么条件下为 0
print(sp.solve(sp.tan(i) - n2/n1, i))      # 得出 i_B

4.4 scipy：特殊函数与 FFT

from scipy.special import j1, fresnel   # 贝塞尔函数、菲涅尔积分
S, C = fresnel(v)          # 注意！scipy 返回的顺序是 (S, C)，别写反
from scipy.fft import fft2, ifft2, fftshift, ifftshift

FFT 是仿真利器：菲涅耳衍射、夫琅禾费衍射、4f 系统、光栅，全都是一两个 FFT。

6. 分章精讲：公式 → 仿真 → 考点

6.1 第一章 光的电磁理论基础

考点：光波表示、频谱、菲涅耳公式、布儒斯特角、全反射、偏振态。

必背公式

$$r_s=\frac{n_1\cos i-n_2\cos t}{n_1\cos i+n_2\cos t},\qquad r_p=\frac{n_2\cos i-n_1\cos t}{n_2\cos i+n_1\cos t}$$

$$R_s=|r_s|^2,\quad R_p=|r_p|^2,\quad \tan i_B=\frac{n_2}{n_1},\quad \sin i_C=\frac{n_2}{n_1}\ (n_1>n_2)$$

跑这个：python demos/d01_fresnel.py

应该看到

  • 正入射 $R=0.04$（空气→$n=1.5$ 玻璃），所以未镀膜镜片双面反射损失约 8%；
  • $r_p$ 在某角降为 0 —— 那就是布儒斯特角；此处反射光是完全线偏振的；
  • 全反射区 $R\equiv1$，但相位在变，且 $\delta_p\neq\delta_s$，最大差约 45°；
  • 部分反射区 $r_s$ 恒有 π 相位跃变，$r_p$ 在布儒斯特角处从 0 翻到 π（穿过零点）。

易错点

  • "半波损失"只对反射光、且是光疏→光密时才有（$n_1<n_2$）；
  • $r_p$ 与 $r_s$ 的定义里 $\cos i$ 与 $\cos t$ 谁配 $n_1$ 谁配 $n_2$，不同教材符号约定不同，做题时先写出你用的约定；
  • 全反射时折射角是虚数，不能写 $\sin t>1$ 就完事，要说明"折射波沿界面传播、振幅指数衰减（隐失波）"。

6.2 第二章 光的干涉

考点：相干条件、双光束、多光束、薄膜、干涉仪。

必背公式

$$\Delta x=\frac{\lambda D}{d}\quad(\text{双缝}),\qquad T=\frac{1}{1+F\sin^2(\delta/2)},\ F=\frac{4R}{(1-R)^2}$$

$$F^*=\frac{\pi\sqrt R}{1-R},\qquad FSR=\frac{\lambda^2}{2nd},\qquad r_m=\sqrt{m\lambda R}\ (\text{牛顿环暗环})$$

跑这个：d03 d04 d05 d06

应该看到

  • 双缝条纹间距与 λ、D 成正比、与 d 成反比；单缝包络会"削掉"某些级次；
  • 多光束干涉条纹随 R 增大迅速变尖，$T_{\min}/T_{\max}=1/(1+F)$；
  • 1/4 波长增透膜在设计波长处 $R=0$，偏离 50 nm 就明显退化；
  • 牛顿环中心是暗斑（反射光），亮环半径 $\sqrt{(m+\tfrac12)\lambda R}$。

易错点

  • 牛顿环反射光中心暗、透射光中心亮，别写反；
  • 迈克尔逊干涉仪"移动 $\lambda/2$ 条纹过一条"，$d$ 与条纹移动数 $N$ 关系是 $d=N\lambda/2$；
  • 多光束干涉的相位差是 $\delta=\frac{4\pi}{\lambda}nd\cos\theta$（有两倍）；
  • 薄膜干涉要同时考虑两个界面的半波损失是否抵消。

6.3 第三章 光的衍射

考点：夫琅禾费（单缝、圆孔、多缝、巴俾涅）、菲涅耳（圆孔、直边）、光栅、波带片。

必背公式

$$a\sin\theta=k\lambda,\qquad \theta_{\text{中央}}=\frac{\lambda}{a},\qquad \theta_{\text{艾里}}=1.22\frac{\lambda}{D}$$

$$d\sin\theta=m\lambda,\qquad R=\frac{\lambda}{\Delta\lambda}=mN,\qquad \text{缺级}:\ \frac{d}{a}=\frac{m}{k}$$

$$N=\frac{a^2}{\lambda z},\qquad \frac{I}{I_0}=4\sin^2\frac{\pi N}{2},\qquad f_m=\frac{a^2}{m\lambda}$$

跑这个：d07 d08

应该看到

  • 单缝缝越窄，中央亮纹越宽（衍射越显著）；
  • 圆孔第一个暗环在 $u=3.832$，对应角半径 $1.22\lambda/D$；
  • 多缝条纹位置由 $d$ 定、尖锐程度由 $N$ 定、强度包络由 $a$ 定；
  • 菲涅耳圆孔轴上强度随距离振荡：$N=1$ 亮 4 倍，$N=2$ 全暗；
  • 直边阴影边界恰好 $I=I_0/4$，照明区第一极大 $1.37I_0$。

易错点

  • 光栅题里 $d$ 是光栅常数（相邻缝距），$a$ 是缝宽，两者别混；
  • 分辨本领 $R=mN$ 中的 $N$ 是参与衍射的总缝数，不是刻线密度；
  • 菲涅耳半波带：$N$ 可以是小数，"奇数亮、偶数暗"只对整数成立；
  • 巴俾涅原理说的是振幅互补相加等于自由场，不是强度相减。

6.4 第三章第 5 节 傅里叶光学

考点：频谱、阿贝成像、空间滤波、传递函数。

必背结论

$$\text{谱面坐标}\ x_f=\lambda f\cdot f_x,\qquad \text{截止频率}\ f_c=\frac{D}{2\lambda f},\qquad OTF\ \text{截止}=2f_c$$

跑这个：python demos/d09_fourier_optics.py

应该看到

  • 透镜后焦面上出现的是物的傅里叶频谱（低频在中心）；
  • 挡掉高频 → 图像变模糊；只留高频 → 勾边；
  • 相干照明用 CTF（0/1 型），非相干照明用 OTF（三角形/圆型），后者截止频率是前者的 2 倍。

易错点

  • 物面空间频率与谱面坐标不是一回事，换算要乘 $\lambda f$；
  • 相干成像系统对振幅线性，非相干对强度线性——卷积的对象不同。

6.5 第四、五章 各向异性介质与感应双折射

考点：单轴晶体、双折射、波片、偏振棱镜、偏光干涉、旋光、电光、声光、法拉第。

必背公式

$$\frac{1}{n_e^2(\theta)}=\frac{\cos^2\theta}{n_o^2}+\frac{\sin^2\theta}{n_e^2},\qquad \delta=\frac{2\pi}{\lambda}|n_o-n_e|d$$

$$T=\sin^2 2\varphi\cdot\sin^2\frac{\delta}{2}\ (\text{正交偏振器}),\qquad V_\pi=\frac{\lambda}{2n_o^3r_{63}},\qquad \sin\theta_B=\frac{\lambda}{2\Lambda}$$

跑这个：python demos/d12_crystal_optics.py

应该看到

  • 沿光轴（$\theta=0$）传播时 $n_e(\theta)=n_o$，没有双折射；
  • 方解石（负晶体）e 光走离角在 45° 附近最大，约 6.2°；
  • 波片只改变偏振态，正交偏振器 + 波片才把相位变成强度；
  • KDP 纵向半波电压约 7.5 kV（550 nm）。

易错点

  • 正负晶体判据是 $n_e$ 与 $n_o$ 谁大，石英是正晶体（$n_e>n_o$）；
  • "1/4 波片"是对特定波长成立的，换波长就变成其他延迟量；
  • 偏光干涉 $\varphi=0$ 或 90° 时无论相位延迟多少都消光（这是常考的"陷阱"选项）；
  • 自然旋光与法拉第旋光的方向性不同：法拉第旋转方向由磁场定，与光传播方向无关（光隔离器的原理）。

6.6 第七、八章 几何光学与理想光学系统

考点：符号规则、单球面、平板棱镜、基点基面、双光组组合。

必背公式

$$\frac{n'}{l'}-\frac{n}{l}=\frac{n'-n}{r},\qquad \beta=\frac{nl'}{n'l},\qquad \frac{1}{l'}-\frac{1}{l}=\frac{1}{f'},\qquad xx'=ff'$$

$$\Delta=d-f_1'+f_2,\qquad f'=-\frac{f_1'f_2'}{\Delta},\qquad l_F'=f'\left(1-\frac{d}{f_1'}\right)$$

跑这个：python demos/d10_geometrical.py

应该看到

  • 单球面 $l=-300,r=100,1\to1.5$ 时 $l'=900$、$\beta=-2$；
  • 双光组组合公式与近轴矩阵给出的结果逐位相同（我把它做成了自检项）；
  • 物在 2F 处像在 2F'，$\beta=-1$。

易错点

  • 符号规则必须先声明：$l$、$y$、$u$ 的正负方向；
  • 双光组组合里 $f_2$ 是物方焦距，与 $f_2'$ 差一个负号，这是最常见的翻车点；
  • 当 $d=f_1'+f_2$ 时 $\Delta=0$，系统无焦（望远镜），不能直接套焦距公式。

6.7 第九章 像差与光路计算、光阑

考点：$y$-$u$ 递推、子午面实际光线、球差、孔径光阑/视场光阑/光瞳/窗。

核心判据

$$u_i=\frac{D_i/2}{|B_i|}\ \xrightarrow{\ \min\ }\ \text{孔径光阑}$$

其中 $B_i$ 是「物面 → 第 $i$ 个光阑所在面」的累计近轴矩阵的 $(0,1)$ 元素。

跑这个：python demos/d11_aperture_stop.py

应该看到

  • 各光阑按物方孔径角排序，最小者就是孔径光阑；
  • 入射光瞳 = 孔径光阑经前面系统的像，出射光瞳 = 经后面系统的像；
  • 球差曲线：边缘光线交点比近轴焦点更近（正透镜球差为负）。

易错点

  • 入射光瞳是虚像时位置可以是负的（在物面右侧），不要以为算错了；
  • 视场光阑用主光线（过入射光瞳中心）判定，不要用边缘光线；
  • 近轴光路计算和实际光线追迹是两套算法，球差就是两者之差——这个理解比背公式更重要。

6.8 第十章 光学仪器

考点：眼睛、放大镜、显微镜、望远镜。

必背公式

$$\Gamma_{\text{放大镜}}=\frac{250}{f},\qquad \Gamma_{\text{显微镜}}=\left|\beta_{obj}\right|\cdot\frac{250}{f_e'},\qquad \Gamma_{\text{望远镜}}=\frac{f_o'}{f_e'}$$

$$d_{\min}=\frac{0.61\lambda}{NA},\qquad \theta_{\min}=1.22\frac{\lambda}{D}$$

跑这个（无图，直接算）：

from optics817 import instruments as ins
print(ins.microscope_resolution(550e-9, 0.9))         # 显微镜最小分辨距离
print(ins.telescope_resolution_arcsec(550e-9, 0.1))   # 望远镜最小分辨角(角秒)
print(ins.telescope_magnification(1.0, 0.02))         # 望远镜放大率

易错点

  • 显微镜放大率与分辨本领无关：NA 决定能分辨多细，放大率只决定看起来多大；
  • 望远镜物镜口径决定分辨本领，放大率只决定出瞳直径匹配人眼；
  • 明视距离是 250 mm，别记成 25 cm 以外的数。

6.9 第六章 光的吸收、色散、散射

考纲要求"了解"，做简答题准备即可：

  • 吸收：$I=I_0e^{-\alpha l}$（朗伯定律），$\alpha$ 与波长有关 → 选择吸收；
  • 色散：$n=n(\lambda)$，正常色散 $dn/d\lambda<0$；用 $n=A+\frac{B}{\lambda^2}+\frac{C}{\lambda^4}$；
  • 散射：瑞利散射 $I\propto1/\lambda^4$（天空蓝、夕阳红）；米氏散射（颗粒尺寸接近波长）；拉曼散射（频率改变）。

7. 三种核心学习方法

7.1 方法一：公式—仿真互验（最重要）

selfcheck.py 里有 79 项断言，每一项都是"课本公式 vs 数值计算"的正面对撞。它就是你复习时的裁判。

# 例：验证爱里公式的两个极值
r = 0.5
F = 4 * r**2 / (1 - r**2) ** 2
assert np.isclose(itf.airy_transmission(0.0, r), 1.0)          # Tmax = 1
assert np.isclose(itf.airy_transmission(np.pi, r), 1/(1+F))    # Tmin = 1/(1+F)

你要养成的习惯：每学完一节，自己往 selfcheck.py 里加 3–5 条断言。加不出来的地方，就是你没学懂的地方。

一条好的自检断言长这样：

check("光栅方程 d sin(theta) = m lambda",
      d * np.sin(dif.grating_angle(m, 550e-9, d)), m * 550e-9)

它把公式的两边分别用不同代码路径算出来，任何一边写错都会报错。

7.2 方法二：参数地图

不要只算一组数。把参数扫一遍，看趋势和临界行为：

import numpy as np
from optics817 import interference as itf

# 缝宽 a 从 0.02 mm 扫到 0.5 mm，看条纹可见度如何变化
for a in np.linspace(0.02e-3, 0.5e-3, 10):
    I = itf.double_slit_intensity(np.linspace(-6e-3, 6e-3, 4001),
                                 600e-9, 0.5e-3, a=a, z=1.0)
    print(f"a={a*1e3:.3f} mm  可见度 V={(I.max()-I.min())/(I.max()+I.min()):.3f}")

考场上你没法跑程序，但趋势已经在你脑子里了： "缝越宽、包络越窄、可见度越低" —— 这句话能帮你秒判选择题。

7.3 方法三：错题反演

错题不要只抄一遍答案，要做反演：

  1. 写下你的错误答案；
  2. 用仿真算出正确答案；
  3. 找出你的错误对应哪个物理量的偏差（少乘 2？用了 $\sin$ 而不是 $\tan$？漏了半波损失？）；
  4. 把这条经验写成一句话，加进 selfcheck.py。

例如，如果你做牛顿环时忘了半波损失：

# 错误模型：I = cos²(πr²/(λR))  →  中心是亮的（错！）
# 正确模型：I = sin²(πr²/(λR))  →  中心是暗的
check("牛顿环中心必须为暗斑（反射光）",
      itf.newton_rings_intensity(0.0, 600e-9, 1.0), 0.0)

这条断言会永远替你记住这个坑。

8.2 简答题模板

问"为什么"：现象 → 原理（写公式）→ 结论。

例：为什么反射光在布儒斯特角完全偏振？ 答：自然光可分解为 $s$、$p$ 两个分量。由菲涅耳公式 $r_p=(n_2\cos i-n_1\cos t)/(n_2\cos i+n_1\cos t)$，当 $i+t=90°$ 时分子为零，即 $r_p=0$，故反射光中只剩 $s$ 分量，成为完全线偏振光。

问"区别与联系"：列表对比 + 一句话总结。

例：菲涅耳衍射与夫琅禾费衍射的区别 → 从"光源/观察屏是否在有限远""能否用半波带法""数学上是积分还是变换"三点对比。

8.3 计算题模板（万能的五步）

  1. 画图，标出所有已知量和未知量；
  2. 写公式（原式，不要直接代数）；
  3. 统一单位（全部换 SI，或全部用 mm）；
  4. 代入计算，保留 4 位有效数字；
  5. 检验：量纲对不对？数量级合不合理？（比如可见光波长必然是几百 nm 量级）

8.4 单位与有效数字

  • 波长：$550\,\text{nm}=5.5\times10^{-7}\,\text{m}$；换算时先化成米再代入公式，最不容易错；
  • 角度：公式里的 $\sin\theta\approx\theta$ 只在弧度下成立；
  • 答案一般保留 4 位有效数字；角度用度或弧度都写清单位。

8.5 高频考点清单（考前一周只看这个）

9. 常见错误清单

第一章

  1. 把 $R=|r|$ 当成反射率（应为 $|r|^2$）
  2. 忘记正入射时 $R_s=R_p$、斜入射时 $R_s>R_p$
  3. 认为全反射没有波进入第二介质（有隐失波）
  4. 半波损失适用条件搞错（只对反射光、光疏→光密）

第二章

  1. 牛顿环反射光中心记成亮斑
  2. 多光束相位差漏掉因子 2（应为 $4\pi nd\cos\theta/\lambda$）
  3. 迈克尔逊 $d$ 与条纹数的关系少乘 $1/2$
  4. 增透膜条件写成 $n=n_0n_s$（应为平方根）
  5. 条纹可见度公式写成 $I_{\max}/I_{\min}$

第三章

  1. np.sinc 的定义里自带 π，直接传 $\beta$ 会错
  2. 光栅的 $d$ 与 $a$ 混用
  3. 分辨本领 $R=mN$ 中的 $N$ 用成刻线密度
  4. 艾里斑角半径系数写成 1.0（应为 1.22）
  5. 菲涅耳圆孔轴上强度直接写 $I_0$（实际随 $N$ 振荡）
  6. 单缝衍射极小条件写成 $a\sin\theta=(k+\tfrac12)\lambda$

第四章、第五章

  1. 正负晶体的判据记反
  2. 认为沿光轴也有双折射
  3. 波片厚度公式漏掉 $|n_o-n_e|$
  4. 偏光干涉中 $\varphi=0$ 时以为仍有调制
  5. 法拉第旋转方向与光传播方向有关（实际无关）

第七~九章

  1. $1/l'-1/l=1/f'$ 的符号写错
  2. 双光组组合里 $f_2$ 与 $f_2'$ 混用
  3. 入射光瞳位置算成负的就以为错了（虚像很正常）
  4. 用边缘光线而不是主光线判定视场光阑
  5. 球差正负号记反

通用

  1. 小角近似 $\sin\theta\approx\theta$ 在度数下使用
  2. nm 没换算成 m 直接代入
  3. 结果不检查量纲
  4. 复数振幅直接相加却忘了取模平方
  5. 只算数值不写公式，步骤分全丢
