## 一、光的电磁理论基础

| 量 | 公式 |
|---|---|
| 介质中波长 / 相速 | $\lambda_n=\lambda_0/n$ ，$v=c/n$ |
| 菲涅耳系数 | $r_s=\dfrac{n_1\cos i-n_2\cos t}{n_1\cos i+n_2\cos t}$ ，$r_p=\dfrac{n_2\cos i-n_1\cos t}{n_2\cos i+n_1\cos t}$ |
| 反射率 / 透射率 | $R=\lvert r\rvert^2$ ，无吸收时 $T=1-R$ |
| 正入射 | $R=\left(\dfrac{n_1-n_2}{n_1+n_2}\right)^2$（空气→$n{=}1.5$ 玻璃：**4%**） |
| 布儒斯特角 | $\tan i_B=n_2/n_1$ ，此处 $r_p=0$，反射光**完全线偏振** |
| 临界角 | $\sin i_C=n_2/n_1$（仅 $n_1>n_2$） |
| 全反射相移 | $\tan\dfrac{\delta_s}{2}=-\dfrac{\sqrt{\sin^2 i-n^2}}{\cos i}$，$\tan\dfrac{\delta_p}{2}=-\dfrac{\sqrt{\sin^2 i-n^2}}{n^2\cos i}$，$n=n_2/n_1$ |
| 马吕斯定律 | $I=I_0\cos^2\theta$ |

- ⚠ **半波损失**：只对**反射光**、且**光疏→光密**时才有（$r_s<0$ 即相位跃变 π）。
- ⚠ $R_s\ge R_p$ 恒成立（除正入射相等、布儒斯特角处 $R_p=0$）。
- 全反射相移最大差 $\delta_p-\delta_s\approx45°$ → 菲涅耳菱体两次反射得 90° → 圆偏振。
- 琼斯：线偏振 $\begin{pmatrix}\cos\alpha\\\sin\alpha\end{pmatrix}$；1/4 波片 $\delta=\pi/2$；圆偏振 $S_3/S_0=\pm1$。

## 二、光的干涉

| 装置 | 条件 / 公式 |
|---|---|
| 杨氏双缝 | 光程差 $\Delta=d\sin\theta\approx dx/D$；明纹 $d\sin\theta=m\lambda$；**条纹间距 $\Delta x=\lambda D/d$** |
| 双缝含包络 | $I=I_0\cos^2\alpha\cdot\mathrm{sinc}^2\beta$，$\alpha=\pi d\sin\theta/\lambda$，$\beta=\pi a\sin\theta/\lambda$ |
| 平行平板多光束 | 爱里公式 $T=\dfrac{1}{1+F\sin^2(\delta/2)}$，$F=\dfrac{4R}{(1-R)^2}$，$\delta=\dfrac{4\pi}{\lambda}nd\cos\theta$ |
| 精细度 / 分辨本领 | $F^*=\dfrac{\pi\sqrt R}{1-R}$，$\dfrac{\lambda}{\Delta\lambda}=mF^*$ |
| F-P 自由光谱范围 | $FSR=\dfrac{\lambda^2}{2nd}$ |
| 牛顿环（反射光） | **暗环** $r_m=\sqrt{m\lambda R}$，亮环 $r_m=\sqrt{(m+\frac12)\lambda R}$ |
| 劈尖等厚 | $\Delta x=\dfrac{\lambda}{2n\alpha}$ |
| 迈克尔逊 | $\Delta=2d\cos\theta$；$d$ 变 $\lambda/2$ → 移一条条纹 |
| 单层增透膜 | $n=\sqrt{n_0n_s}$，$d=\dfrac{\lambda_0}{4n}$；$R=\left(\dfrac{n_0n_s-n^2}{n_0n_s+n^2}\right)^2$ |
| 可见度 | $V=\dfrac{I_{\max}-I_{\min}}{I_{\max}+I_{\min}}$，两光束 $V=\dfrac{2\sqrt{I_1I_2}}{I_1+I_2}$ |

- ⚠ 多光束相位差有**两倍**：$\delta=4\pi nd\cos\theta/\lambda$。
- ⚠ 牛顿环**反射光中心是暗斑**，透射光中心才是亮斑。
- ⚠ 迈克尔逊 $d=N\lambda/2$，别忘 2 和 1/2。
- ⚠ 增透膜折射率是**平方根**，不是乘积。
- 相干长度 $L_c=\lambda^2/\Delta\lambda$，相干时间 $\tau_c=L_c/c$。

## 三、光的衍射

| 内容 | 公式 |
|---|---|
| 单缝（夫琅禾费） | 暗纹 $a\sin\theta=k\lambda$；中央亮纹半角宽 $\lambda/a$；$I=I_0\,\mathrm{sinc}^2(\pi a\sin\theta/\lambda)$ |
| 圆孔（艾里斑） | 角半径 $\theta_1=1.22\dfrac{\lambda}{D}$；$I=I_0\left[\dfrac{2J_1(u)}{u}\right]^2$，$u=\pi D\sin\theta/\lambda$ |
| 光栅方程 | $d\sin\theta=m\lambda$ |
| 缺级 | $\dfrac{d}{a}=\dfrac{m}{k}$（整数比） |
| 光栅分辨本领 | $R=\dfrac{\lambda}{\Delta\lambda}=mN$（$N$ 为**总缝数**）；最高级次 $\left\lfloor d/\lambda\right\rfloor$ |
| 菲涅耳数 | $N=\dfrac{a^2}{\lambda z}$；轴上 $\dfrac{I}{I_0}=4\sin^2\dfrac{\pi N}{2}$ |
| 菲涅耳半波带 | $r_m=\sqrt{m\lambda z}$；$N$ 为奇数→亮，偶数→暗（仅整数） |
| 波带片 | $f_m=\dfrac{a^2}{m\lambda}$，$m=1,3,5,\dots$ |
| 直边衍射 | $v=x\sqrt{2/(\lambda z)}$；边界 $I=I_0/4$；第一极大 $1.37I_0$ |
| 巴俾涅原理 | 互补屏**振幅**之和 = 自由场 |
| 傅里叶光学 | 后焦面坐标 $x_f=\lambda f f_x$；$f_c=\dfrac{D}{2\lambda f}$；OTF 截止 $=2f_c$ |

- ⚠ 光栅：**位置由 $d$ 定、锐度由 $N$ 定、包络由 $a$ 定**。
- ⚠ 单缝极小是 $k\lambda$（不是半整数倍）。
- ⚠ 分辨本领与放大率无关，只与口径/NA 有关。

## 四、晶体光学与感应双折射

| 内容 | 公式 |
|---|---|
| 单轴晶体 e 光 | $\dfrac{1}{n_e^2(\theta)}=\dfrac{\cos^2\theta}{n_o^2}+\dfrac{\sin^2\theta}{n_e^2}$ |
| 正 / 负晶体 | 石英 $n_e>n_o$ **正**；方解石 $n_e<n_o$ **负** |
| 走离角 | $\tan\rho=\dfrac{(1-(n_o/n_e)^2)\tan\theta}{1+(n_o/n_e)^2\tan^2\theta}$（方解石最大 ≈6.2°） |
| 波片相位延迟 | $\delta=\dfrac{2\pi}{\lambda}\lvert n_o-n_e\rvert d$；1/4 波片 $d=\dfrac{\lambda}{4\Delta n}$ |
| 偏光干涉 | 正交：$T=\sin^22\varphi\sin^2\dfrac{\delta}{2}$；平行：$T=1-\sin^22\varphi\sin^2\dfrac{\delta}{2}$ |
| 旋光 / 法拉第 | $\theta=\rho d$（自然）；$\theta=VBd$（法拉第，方向与光传播方向**无关**）|
| 电光（KDP 纵向） | $V_\pi=\dfrac{\lambda}{2n_o^3r_{63}}\approx7.5\ \mathrm{kV}$（550 nm） |
| 声光布喇格 | $\sin\theta_B=\dfrac{\lambda}{2\Lambda}=\dfrac{\lambda f}{2v}$ |
| 喇曼-纳斯判据 | $Q=\dfrac{2\pi\lambda L}{n\Lambda^2}$；$Q\ll1$ 为喇曼-纳斯衍射 |

- ⚠ 沿光轴 $\theta=0$ 时 $n_e(\theta)=n_o$ → **无双折射**。
- ⚠ $\varphi=0$ 或 90° 时偏光干涉**永远消光**，与 $\delta$ 无关。
- ⚠ 波片改变了偏振态，**不改变光强**（理想情况）。

## 五、应用光学

| 内容 | 公式 |
|---|---|
| 单球面 | $\dfrac{n'}{l'}-\dfrac{n}{l}=\dfrac{n'-n}{r}$，$\beta=\dfrac{nl'}{n'l}$，$f'=\dfrac{n'r}{n'-n}$ |
| 高斯 / 牛顿 | $\dfrac{1}{l'}-\dfrac{1}{l}=\dfrac{1}{f'}$；$xx'=ff'$ |
| 球面镜 | $\dfrac{1}{l'}+\dfrac{1}{l}=\dfrac{2}{r}$，$f=r/2$ |
| 平行平板 | 轴向位移 $\Delta l'=d\left(1-\dfrac{1}{n}\right)$；侧移 $\Delta=d\dfrac{\sin(u_1-u_1')}{\cos u_1'}$ |
| 双光组组合 | $\Delta=d-f_1'+f_2$，$f'=-\dfrac{f_1'f_2'}{\Delta}$，$l_F'=f'\left(1-\dfrac{d}{f_1'}\right)$ |
| 无焦系统 | $d=f_1'+f_2$ → $\Delta=0$（望远镜） |
| 孔径光阑判据 | 物方孔径角 $u_i=\dfrac{D_i/2}{\lvert B_i\rvert}$ 最小者 |
| 光瞳 | 入瞳＝光阑经**前面**系统的像；出瞳＝经**后面**系统的像 |
| 视场光阑 | 用**主光线**（过入瞳中心）判定 |
| 球差 | $\delta L'=l'_h-l'_{\text{近轴}}$ |
| 显微镜 | $\Gamma=\left\lvert\beta_{obj}\right\rvert\dfrac{250}{f_e'}$，$d_{\min}=\dfrac{0.61\lambda}{NA}$，$NA=n\sin u$ |
| 望远镜 | $\Gamma=\dfrac{f_o'}{f_e'}$，$\theta_{\min}=1.22\dfrac{\lambda}{D}$，出瞳 $D'=D/\Gamma$ |
| 人眼 | 明视距离 **250 mm**，最小分辨角 ≈ **1′** |

- ⚠ 双光组里的 $f_2$ 是**物方**焦距（$f_2=-f_2'$）。
- ⚠ 入射/出射光瞳可以是**虚像**，位置为负很正常。
- ⚠ 折射球面 $f'$ 的分子是 $n'$（像方折射率）。

## 六、吸收 / 色散 / 散射

- 吸收：$I=I_0e^{-\alpha l}$
- 色散：$n=A+\dfrac{B}{\lambda^2}+\dfrac{C}{\lambda^4}$，正常色散 $dn/d\lambda<0$
- 瑞利散射：$I\propto\lambda^{-4}$（天空蓝、夕阳红）；米氏散射；拉曼散射

## 八、万能检查清单（交卷前 3 分钟）

1. **量纲**对吗？（长度 / 角度 / 无量纲）
2. **数量级**合理吗？（可见光波长几百 nm；干涉条纹间距 mm 级）
3. **角度用了弧度**吗？（小角近似只在弧度下成立）
4. **半波损失**计入了吗？（薄膜、牛顿环、迈克尔逊）
5. **因子 2** 有没有漏？（光程差、多光束相位、迈克尔逊 $d$）
6. **小角近似**成立吗？（$x\ll D$ 才可用 $\sin\theta\approx x/D$）
7. 结论写**单位**了吗？保留 **4 位有效数字**。
