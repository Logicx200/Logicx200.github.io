食物链生态模拟

昆虫—鸟—鹰三级食物链与种群曲线

网页 · 创意工具2 个文件32 KB生态模拟食物链Canvas单文件

单文件食物链生态模拟：昆虫、鸟、鹰三类个体在 Canvas 上按捕食关系、能量与寿命演化，饿死、老死与繁殖都计入种群曲线（底部实时折线图）。右侧配置抽屉可改物种参数与初始数量，改动即时生效，「数量上限」只限制新增个体、不强制移除已存在个体。

要点

  • 昆虫 → 鸟 → 鹰三级捕食 + 能量/寿命机制
  • 底部实时种群曲线（线性坐标）
  • 参数抽屉即时生效，可重置初始数量

技术栈

JavaScript Canvas
