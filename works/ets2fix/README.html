ETS2 存档解密与补丁工具

BSII 二进制格式解析 + AES 解密 / 重加密

逆向 ETS2（欧洲卡车模拟 2）存档的 BSII 二进制格式，写出一套「解密 → 改字节 → 重新加密」的 Python 补丁链路（AES-256 CBC + zlib，保留原头部校验区），并用官方 decrypt_truck.exe 回读验证改动生效。Rust 部分实现了 BSII 段结构、类型映射、u64 字符串编码与序列化的完整编解码，配套存档备份与往返（round-trip）一致性检查。

要点

  • BSII 解密/重加密完整链路，官方工具回读验证
  • Rust 实现段解析、类型映射与序列化
  • 含存档备份与往返一致性检查

技术栈

Python Rust cryptography zlib
