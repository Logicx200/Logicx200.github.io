## 五、环境坑（务必先看，否则会重复踩）

### 1. 中文路径传给子进程会被按 GBK 误编码 ★最坑

PowerShell 的 cwd 是 `F:\DeepSeek工作区\...`，但 Python 里 `os.getcwd()` 拿到的是
`F:\DeepSeek������\whale-chan-research`（`工作区` 3 个字变成 6 个 U+FFFD）。

后果：脚本里任何基于路径的 `os.listdir` / `os.path.isdir` 判断都可能悄悄失败。
**规避办法：需要跑 Python/Node 脚本时切到纯 ASCII 目录**，例如：

```powershell
# workdir 传 F:\whale-chan-research，不要传中文路径
python build_gallery.py
```

### 2. github.com 被 hosts 屏蔽

`C:\Windows\System32\drivers\etc\hosts` 里把一大批 GitHub 域名指向了 `127.0.0.1`：
`github.com`、`raw.githubusercontent.com`、`api.github.com`、`*.githubusercontent.com`、`github.io` 等。

- **浏览器直接点 GitHub 链接会打不开**
- `web_fetch` 工具会报 `resolves to a non-public IP address`（它拒绝内网地址）
- ✅ **但 PowerShell 的 `Invoke-WebRequest` 能正常访问**（实测 200）

所以抓 GitHub 素材要这样：

```powershell
Invoke-RestMethod  -Uri "https://api.github.com/repos/<owner>/<repo>" -Headers @{ "User-Agent"="dsh" }
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/<owner>/<repo>/main/<path>" -Headers @{ "User-Agent"="dsh" } -OutFile "<本地路径>"
```

GitHub 图片 CDN 未走 raw 的可用：`https://bjumymxtfpfswthiusfr.storage.supabase.co/storage/v1/object/public/ai-meme/...`

### 3. 控制台 UTF-8 乱码

Python 输出中文到 PowerShell 会变乱码。跑之前设：

```powershell
$env:PYTHONIOENCODING="utf-8"
```

## 六、已经踩过并修掉的坑（别重犯）

| 坑 | 表现 | 正确做法 |
|---|---|---|
| **md 表格里塞图片** | 23 张图全部显示失败 | 表格单元格内不要放 `![]()`；改用 HTML 图库 |
| **md 图片路径漏 `img/`** | 引用匹配不到文件 | 写 `img/xxx.png`，且要按 md 所在目录解析 |
| **前缀匹配写错** | `f.startswith("B-")` 永远匹配不上 `B1-xxx.png` | 用 `re.match(r"^\d+-", f[len(prefix):])` |
| **依赖 `__file__` 定位** | 中文路径下 `__file__` 乱码 | 改用 `os.getcwd()`，并配合 ASCII 路径 |
| **`__pycache__` 缓存旧代码** | 改了脚本但行为不变 | 改完删掉 `__pycache__` 再跑 |
