# Whale Chan Research · 鲸娘桌宠调研

围绕 DeepSeek 鲸娘 / Live2D 桌宠候选形象的调研记录与素材汇总（个人研究资料，非官方项目）。

## 怎么看
- `候选图库.html`：候选形象图库（浏览器直接打开）；`README.html`：图库说明页；
- `候选汇总.md`、`交接文档.md`、`协作-看板整合方案.md`：调研汇总与交接/协作记录；
- `tree_*.txt`：候选来源仓库的文件树摘要；`meta_*.json`：候选来源元信息；
- `img/`：候选形象图 28 张（A–F 分组）；`build_gallery.py` / `verify.py`：图库生成与校验脚本。
