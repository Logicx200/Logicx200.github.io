# 传感器参数说明（红外建模视角）

> 目的：把 `XGGDCOSSim2` 里"传感器"相关参数整理成**红外传感器建模**可用的输入，并明确哪些参数软件里**有**、哪些**必须外部设定**。
> 依据：`Data\SystemBaseFile\DefaultPlanFile.xml`（SensorParam / SensorEffect / SceneGenEffect / DYTParam）、`Data\SystemBaseFile\{DefaultModelDatabase,ModelDatabase}.xml`（SensorModel）、`Data\config\SystemConfig.ini` + `SystemConfig.description`（InjectModeCfg、HTGTCard、RenderCfg）、`Data\Assets\System\Setting.ini`。
> 只读解析，未修改源文件。

---

## 1. 核心结论：默认传感器是"渲染/显示链路参数"，不是完整辐射传感器模型

判断依据（来自软件自身字段语义）：

1. 默认传感器参数集中在 `SensorEffect`（"传感器**效应**参数"）与 `SceneGenEffect`（"场景产生器效应参数"）两节，其输出端是 `ImgOutModeInjection`（显卡/注入/模拟器/电阻阵）与 `ImgOutModeRadiant`（默认 **3=模拟器**）——描述的是**图像往哪里送**，不是辐射量如何测量。
2. `ResCoefficient=1746`、`ResBias=1733` 与 `TextureLightMin=0`、`TextureLightMax=60` 配合，作用是把**温度/纹理亮度**线性映射成灰度，属于显示/注入链路标定；`ModelDatabase.xml` 里同为 `int` 类型的"响应系数/响应偏置"进一步说明它是**整数灰度映射**，而非物理响应率（V/(W/cm²)）。
3. 位宽默认 **8 位**（`BitWidth=1`），并配有 `ImgScale`（截图制备倍率）、`RecPath`（截图路径）——典型"生成图像给被试设备"的注入式仿真链路。
4. 噪声/弥散模型（`IsNoise/IsDisperse`）默认关闭且文件为空，`ReviseType` 只有"非均匀性校正/固定样式噪声"两种二选一——没有探测器物理噪声模型。
5. 在 `SensorParam`（默认传感器）整节内，**没有 NETD、探测率 D\*、量子效率、积分时间、F 数、口径、像元尺寸、光谱响应**等辐射传感器核心参数；对全部文本配置（XML/INI/description/txt，共 20+ 个文件）做关键词检索：`NETD`、`噪声等效`、`探测率`、`量子效率`、`光谱响应`、`D*` **命中数均为 0**；`焦距`/`口径`/`积分时间`/`像元` 仅出现在 `DefaultPlanFile.xml` 的**导引头模板**（`DYTParam/OptImagGuidMod`，默认值全 0，见 §5）。也就是说这些概念软件预留了字段，但**默认传感器链路里没有**。

因此：**这套参数可以作为"几何+波段+显示"约束直接复用，但不能当作红外传感器辐射模型；NETD/口径/IFOV/积分时间等必须由升级仿真的外部模型设定。**

## 3. 由现有参数可派生的几何/信息量（可直接用于升级仿真）

| 派生量 | 计算式 | 结果 |
|---|---|---|
| 水平瞬时视场 IFOV_H | `FovH / DpiH` | 3.75° / 1024 = 0.0036621° = **63.92 μrad** |
| 垂直瞬时视场 IFOV_V | `FovV / DpiV` | 3.0° / 768 = 0.0039063° = **68.18 μrad** |
| 像元非方形度 | IFOV_V / IFOV_H | **1.067**（垂直像元比水平大 6.7%，非正方形像元/或视场显示口径不一致） |
| 8000 m 下天底地面分辨率 GSD | `h × IFOV` | 水平 **0.511 m/px**、垂直 **0.545 m/px** |
| 8000 m 下视场地面足迹 | `2·h·tan(FOV/2)` | 水平 **523.7 m** × 垂直 **419.0 m**（下视时） |
| 帧周期 | `1/FPS` | **20 ms** |
| 原始数据率（8 位） | `DpiH·DpiV·位宽·FPS` | 1024·768·8·50 = **314.6 Mbit/s ≈ 39.3 MB/s** |
| 原始数据率（14 位，若升级） | 同上 | 550.5 Mbit/s ≈ 68.8 MB/s |

**与 Q2 查找表采样率的量级差**：Q2 俯仰角步长 1°（17453 μrad）是 IFOV（64~68 μrad）的 **约 260 倍**；1024×768 画幅里每个 Q2 网格点要撑起约 273×273 像素。⇒ Q2 表只能给出"慢变化的大气路径项/背景项"，逐像元的辐射差异必须由场景渲染（几何+材质温度）提供，不能在 Q2 网格上直接查逐像元值。

**与注入链路角度分辨率的一致性检查（重要冲突）**：`SystemConfig.ini / [InjectModeCfg] AngRes = 0.012`（单位应为 °/像素，即 **209.4 μrad**），是传感器 IFOV_H 的 **3.28 倍**、IFOV_V 的 3.07 倍。若升级仿真按 `AngRes` 做注入，1024×768 的画面会被放大到约 3.3×FOV（或视场被压缩），**必须确认 AngRes 的物理含义（°/像素？mrad？）后再复用**。同时 `PointTargetWidth=15`（点目标宽高，实际宽高为该值 2 倍 = 30 像素）、`InjectMul=1`、`PixelByteCount=1`、`IsLSB=1`、`FrameAngleSize=1` 也是注入链路参数。

## 4. 缺失参数清单（升级仿真必须在外部设定）

| # | 缺失项 | 为什么必须要 | 建议取值/方法 |
|---|---|---|---|
| 1 | **NETD / NEI（噪声等效温差/噪声等效辐照度）** | 决定最小可分辨温差、作用距离、图像噪声水平 | 按探测器规格给定（典型 MWIR 制冷型 15~30 mK）；或由噪声模型反推 |
| 2 | **入瞳直径 / 口径（D）** | 决定入瞳辐射通量与信噪比 | 与 F 数、焦距联合设定；软件无此字段（导引头模板里有 `EntraPupDiam`，默认 0） |
| 3 | **焦距 f / F 数** | 决定 IFOV 与像面照度，是光学系统核心 | `f = 像元尺寸 / IFOV`；软件无此字段（模板 `FocalLength` 默认 0） |
| 4 | **像元尺寸（pitch, μm）** | 与焦距互推 | 需外部给定（主流 MWIR 15~30 μm） |
| 5 | **积分时间 / 曝光时间（μs）** | 决定信号量与运动模糊 | 软件模板字段 `IntegralTime` 存在但默认 0 |
| 6 | **光学系统透过率 τ_o、冷屏效率、F 数渐晕** | 影响到达焦平面的辐射量 | 外部标定 |
| 7 | **光谱响应曲线（相对响应 vs λ）** | 波段积分需加权；软件只有 3.7~4.8 硬边界 | 外部提供；Q2 表为波段积分值，无光谱分辨率 |
| 8 | **探测器类型/材料/制冷温度** | 决定暗电流、响应率、1/f 噪声 | SensorClass=1/2 隐含制冷型，但无具体温度 |
| 9 | **响应非线性与动态范围** | 灰度-辐射量映射的非线性 | 软件只有一对线性系数（1746/1733），不足以描述；导引头模板提供 4 段折线（RadBright1~4 + Sect1~4RespRatio/Bias），默认全 0，可作参考结构 |
| 10 | **非均匀性（FPN）/固定图案噪声（空间噪声）** | 影响图像质量与小目标检测 | 软件仅 `ReviseType` 二选一开关 + 空文件 |
| 11 | **噪声模型（时域 3D 噪声、NETD 相关）** | 同上 | `IsNoise=0` 且 `NoiseFile` 空 |
| 12 | **MTF / PSF / 弥散（光学+探测器+运动）** | 影响边缘、小目标能量扩散 | `IsDisperse=0`；导引头模板有气动热 PSF/抖动 PSF 开关，默认不考虑 |
| 13 | **抖动/稳像（视线稳定精度）** | 影响运动模糊与跟踪 | 无字段；只能借导引头模板 `MovVibEffSimFlag`（默认 0） |
| 14 | **黑电平/白电平/γ/自动增益** | 显示链路量化 | 只有 ResCoefficient/ResBias 线性映射 + 8 位量化 |
| 15 | **作用距离/探测概率指标** | 仿真校验目标 | 需外部给出（可与 NETD+目标辐射对比推算） |

## 5. 软件内已有的"完整红外导引头参数模板"（最值得复用的结构）

`DefaultPlanFile.xml / MissileWeapon/.../DYTParam/OptImagGuidMods/OptImagGuidMod` 定义了**红外成像导引头**的完整参数集（结构上远超默认传感器参数），但默认值全为 0（空模板）：

| 类别 | 字段 | 单位 | 默认 | 说明 |
|---|---|---|---|---|
| 波段 | `StartWavelength` / `CutOffWavelength` | μm | 0 / 0 | 起始/终止波长 |
| 视场 | `FieldYaw` / `FieldPitch` | ° | 0 / 0 | 方位/俯仰视场 |
| 光学 | `EntraPupDiam` 入瞳直径 / `FocalLength` 焦距 | mm / mm | 0 / 0 | 决定集光与 IFOV |
| 探测 | `YawPixelNum` / `PitchPixelNum` 像元数 | — | 0 / 0 | 焦平面规模 |
| 时间 | `IntegralTime` 积分时间 / `FrameFreq` 帧频 | μs / Hz | 0 / 0 | — |
| 量化 | `GrayScale` 灰度等级 | 位 | 0 | 8~16 |
| 响应 | `RadBright1~4` 四个响应特性点辐射亮度 | W/(sr·m²) | 0 | 折线节点 |
| 响应 | `Sect1~4RespRatio` / `Sect1~4RespBias` | (sr·m²)/W / 灰度 | 0 | 每段线性系数/偏置 |
| 噪声 | `GrayVariance` 噪声灰度方差 | 灰度 | 0 | 噪声强度 |
| 效应 | `AerHeatRadSimFlag` / `AerHeatPSFSimFlag` / `MovVibEffSimFlag` | — | 0 | 气动热辐射 / 气动热 PSF / 运动抖动 |

同理 `LaserGuidMod`（激光制导模块）有 `AllField` 全视场、`Wavelength` 工作波长、`Sensitivity` 灵敏度(fJ/cm²)、指示器位置、激光能量/束散角/脉宽/重频/编码、跟瞄精度等字段（默认 0）。

**建议**：升级仿真如要补全红外传感器，可**沿用这套字段做接口对齐**（波长、视场、入瞳、焦距、像元数、积分时间、帧频、灰度、四段辐射-灰度响应、噪声方差、效应开关），把默认值 0 的项用外部规格填上；这样与原软件的想定格式天然兼容。

## 6. 从"入瞳辐射亮度"到"灰度"的推荐链路（供升级仿真实现）

软件默认链路（据字段推断，非官方文档）：

```
温度/材质 → 纹理亮度 → [ResCoefficient, ResBias] 线性映射 → 8 位灰度 → 注入/显示
```

升级仿真建议的物理链路（外部补齐缺失参数后）：

```
目标/背景辐亮度 L(λ) [W/(sr·m²)]        ← 场景渲染 + Q2 表（透过率 τ、路径辐射 L_path）
  → 波段积分（配合光谱响应 R(λ)）：L_band = ∫L(λ)·R(λ)dλ / ∫R(λ)dλ
  → 大气修正：L_at_sensor = L_scene·τ + L_path                ← Q2 表直接提供 τ 与 L_path
  → 入瞳辐照度：E = L_at_sensor · A_o · τ_o / f² · cos⁴θ      （A_o=πD²/4，θ 为离轴角）
  → 像元信号：V = E · A_pix · η · t_int · R_det + V_dark      （A_pix 像元面积，t_int 积分时间）
  → 量化：DN = round(V / V_LSB)，V_LSB = V_FS / 2^N
  → 噪声：加 NETD 等效噪声、FPN、1/f 噪声                     ← 软件缺失，需外部设定
```

其中 **Q2 查找表能直接提供 τ 与 L_path（波段积分、单点单条件）**，其余光学/探测/量化/噪声环节都需要外部参数。

## 7. 使用限制小结

| 项 | 可直接用 | 需注意 | 需外部设定 |
|---|---|---|---|
| 波段 3.7~4.8 μm | ✅ | 与 Q2_M 一致；长波 8~12 vs Q2_L 7.7~10.3 冲突 | — |
| FOV 3.75°×3° | ✅ | 与 1024×768 组合后像元非方形（IFOV 63.9 vs 68.2 μrad） | 若换焦平面需重算 |
| 分辨率 1024×768 | ✅ | — | — |
| 帧率 50 Hz | ✅ | 帧周期 20 ms | — |
| 高度 8000 m / 俯仰 -90° | ✅ | **Q2 表视点高度只到 5000 m**，8000 m 需外推 | — |
| 8 位量化 + ResCoefficient/ResBias | ⚠️ | 显示链路标定，不是物理响应 | 建议换成真实响应率/NETD |
| 温度映射 0~60 ℃ | ✅ | 与模型 Config.ini 一致 | — |
| 噪声/弥散/非均匀性 | ❌ | 默认关闭且无数据文件 | NETD、FPN、PSF、抖动 |
| 光学/探测/时间参数 | ❌ | 默认传感器无这些字段（导引头模板有但全 0） | 口径、焦距、像元尺寸、积分时间、光谱响应 |
| 波段定义一致性 | ⚠️ | 默认想定 `ImagBand1Class=1`（可见光成像）却配中波红外传感器，且 `BandAtmTranRadFile` 为空 ⇒ 默认想定并不加载 Q2 表 | 实际使用需在界面指定波段类型与 Q2 文件 |
| 注入角度分辨率 | ⚠️ | `AngRes=0.012`（°?）与 IFOV 差 3.3 倍 | 需确认单位/含义 |
