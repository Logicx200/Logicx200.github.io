Help for BBBike extracts

The BBBike extract service lets you download free OpenStreetMap data for any area of the world: for Garmin GPS devices, smartphone apps, GIS software, web maps and your own projects.

Quick start

  1. Choose your area. Move the map to your desired area and click create. Adjust the bounding box or add points to define the area you want.
  2. Set up your extract. Select a Format, then enter the Name of area to extract and Your email address.
  3. Download your map. Click extract to start processing. You'll receive an email with the download link when your extract is ready.
  • ⏱ An extract usually takes 2–7 minutes.
  • ✉ We'll send the download link by email.
  • ▢ Up to 24 million km² per extract. File size limits vary by format (128 MB to 1,500 MB).
  • ↻ The OpenStreetMap data is updated every day.

Select an area

Move the map to the area you want, or use or search next to the name field to find a place. Then click the create button to create a bounding box on the map. To move or resize it, choose resize or drag polygon and click on the box. Drag the box to move it, or drag its corners to resize it.

Want a polygon instead of a box?

First create a bounding box as described above. Then choose add points to polygon and click on the box. Drag the small handles in the middle of each edge to add new points. You can add as many points as you want:

A polygon usually produces only a half to a third of the data of a rectangle covering the same area. Here is an example for a trip along the East Coast from New York City to Boston:

Need exact coordinates? Check show lng/lat and enter them directly. Valid values for longitude are -180 to 180, and for latitude -90 to 90.

Which format should I choose?

Choose the format by what you want to do with the data. The size column shows the approximate file size relative to the PBF extract of the same area (PBF = 1): if your area is 100 MB as PBF, it is about 43 MB as Garmin OSM and about 150 MB as Shapefile. Actual sizes vary by region and data content. The extract page shows the estimated size of your area for the selected format.

After you click extract

  • You will get an email with the download link when your extract is ready, usually within 2–7 minutes. The extract system runs in a shared batch mode. If there are too many requests, it may take longer to process yours. Please be patient!
  • You can see the status of your extract requests on the status page.
  • Please use a meaningful name for the extract, so you can find it later in your inbox or on your computer.
  • Older extracts expire and are deleted from the server after some time. If a download link no longer works, just request the extract again.

Check your download

You can verify a download with its MD5 checksum. Run one of these commands and compare the result with the checksum on the download page:

$ md5sum file.osm.pbf (Linux)
$ md5 file.osm.pbf (FreeBSD, macOS)
> certutil -hashfile file.osm.pbf MD5 (Windows)

Frequently asked questions

I didn't get an email.
Please check your spam folder first. You can also find your extract on the status page.
I don't have a working email address, or can't access my email right now.
Enter nobody as your email address, and find your extract on the status page.
My area is too big.
An extract can cover up to 24 million km². The maximum file size depends on the format (128 MB to 1,500 MB). Try a polygon instead of a rectangle, or a format with a smaller file size. Need even larger areas? See the extract pro service.
My Garmin says "cannot unlock map".
Some Garmin devices or firmware versions can't read maps with the Unicode (UTF-8) character set. The known workaround: choose the same Garmin format with "latin1" in its name. See the Garmin help page for details.
How up to date is the data?
The planet.osm database is updated every day, for all users. For details, see the BBBike planet.osm mirror.
Do the extracts contain metadata?
No, the extracts don't contain metadata such as version numbers, authors or timestamps. If you need to edit OSM data, please go to the OpenStreetMap website. Extracts with full metadata are available with the extract pro service.
Are there ready-made extracts for countries or cities?
Yes, see other extract services below.

Supported browsers

Any modern browser that follows the W3C standards:

  • Firefox
  • Safari, including mobile Safari (iOS)
  • Google Chrome, Microsoft Edge, Opera and other Chromium-based browsers

JavaScript is required for the map and the place search. Cookies are optional and only used to save your preferences.
